# 4×7：全面理解与定义

> 写于 2026-06-03 | 作者：唐文莉 | 版本：v1.0

---

## 一、一句话定义

> **4×7是一张坐标纸——横轴是经纪人服务消费者的7个业务时刻，纵轴是4类判断能力；每个格子里写的，是"一个顾问型经纪人在这个时刻，应该做什么、怎么判断、怎么被评价"。填满这张纸，就等于把经纪人从"信息播报机"训练成"顾问"的路径图搭好了。**

---

## 二、来源：它从哪里来？

贝壳总裁彭永东（大S）在AI时代提出的核心判断：

> **"AI时代，消费者需要的不是信息播报机，而是能理解处境、做出判断、提供路径、承担立场的顾问型服务者。"**

**背景逻辑**：

- AI工具正在取代经纪人的信息搜集与播报功能
- 消费者决策越来越复杂，越来越需要"有人帮我看懂、帮我选、帮我做"
- 经纪人的核心不可替代价值，在于**顾问型服务能力**
- 因此，花桥学堂接到的命题是：**构建经纪行业服务者的底层能力体系——4×7**

---

## 三、结构：4是什么？7是什么？

### 3.1 "4"：四类核心能力（纵轴）

大S用"电脑升级"来比喻四类能力的递进关系：

| 能力维度 | 本质 | 大S的比喻 | 对经纪人意味着什么 |
|---|---|---|---|
| **理解** | 读懂消费者的真实处境和需求 | 内存从16兆→512兆（信息容量） | 不只听客户说什么，能感知客户的未说出口的需求、焦虑和处境 |
| **判断** | 基于信息做出准确的分析和评估 | 从奔腾到i9（处理能力） | 能分析客户的真实决策逻辑，做出有依据的专业判断，而不是猜 |
| **路径** | 提供清晰可执行的解决方案 | 导航从2D→3D→实景（可操作性） | 能把判断落地成"你现在该做什么、下一步怎么走"的具体路径 |
| **立场** | 敢于承担责任，给出明确建议 | 从顾问到"敢帮你做决定的人" | 不只说"各有优劣"，能站在消费者立场表明态度，帮助做决策 |

> 💡 **关键提示**：四类能力不是顺序递进的层级——同一个服务场景下，理解、判断、路径、立场可以同时发生、相互支撑。四者共同构成"顾问型服务能力"的完整图像。

---

### 3.2 "7"：七个服务流程节点（横轴）

经纪人服务过程中，存在两条并行的赛道，每条赛道各有7个关键节点：

#### 客户赛道（买方视角）

| 节点编号 | 流程阶段 | 核心任务描述 |
|---|---|---|
| C1 | **寻找客户** | 主动触达潜在买方，建立初步联系 |
| C2 | **客户面访** | 深度了解客户需求、预算、决策逻辑 |
| C3 | **首看** | 带客户完成第一次实地看房 |
| C4 | **多看** | 陪伴客户多次比较筛选，帮助收窄选择 |
| C5 | **探盘** | 深入了解目标房源，辅助客户决策 |
| C6 | **正签** | 引导客户完成签约决策 |
| C7 | **售后** | 签约后跟进服务，维系信任关系 |

#### 业主赛道（卖方视角）

| 节点编号 | 流程阶段     | 核心任务描述              |
| ---- | -------- | ------------------- |
| S1   | **寻找业主** | 主动开拓卖方资源，发现潜在委托方    |
| S2   | **获取委托** | 与业主建立合作关系，拿到独家或普通委托 |
| S3   | **初次面访** | 了解业主预期，建立信任，收集信息    |
| S4   | **深度面访** | 深入沟通房屋情况、定价逻辑、出售动机  |
| S5   | **带看反馈** | 陪同买方带看后，向业主传递真实买方反馈 |
| S6   | **谈判正签** | 代表各方进行价格谈判，推动达成成交   |
| S7   | **售后**   | 成交后跟进交割，维护长期信任关系    |

---

### 3.3 "4×7"：交叉形成的能力单元矩阵

两轴交叉 = **每条赛道28个能力单元**，双赛道合计 **56个能力单元**：

```
         C1寻找客户  C2客户面访  C3首看  C4多看  C5探盘  C6正签  C7售后
理解     C1-理解     C2-理解    C3-理解  C4-理解  C5-理解  C6-理解  C7-理解
判断     C1-判断     C2-判断    C3-判断  C4-判断  C5-判断  C6-判断  C7-判断
路径     C1-路径     C2-路径    C3-路径  C4-路径  C5-路径  C6-路径  C7-路径
立场     C1-立场     C2-立场    C3-立场  C4-立场  C5-立场  C6-立场  C7-立场
```

**每个格子 = 一个能力训练节点**，包含三层内容：

1. **能力解读**：在这个场景下，"理解/判断/路径/立场"具体指什么？
2. **经纪人动作**：什么样的行为/动作，证明经纪人达到了该能力标准？
3. **评价标准**：如何判断经纪人做到了/没做到？

## 四、本质：4×7真正要解决什么问题？

4×7的本质不是课程框架，而是**经纪人能力差距的扫描仪**。

**它真正要回答的核心问题是**：

> **我们知道经纪人哪里不行，但我们说不清楚"什么叫行"——4×7要做的，就是把"行"的标准，拆进每一个真实的业务场景里，让能力差距变得可见、可训练、可评价。**

**三个关键词**：

| 关键词 | 含义 |
|---|---|
| **可见** | 不再只是模糊说"沟通能力差"，而是能精确定位：在C2客户面访中，判断能力不足，体现在无法识别客户真实预算动机 |
| **可训练** | 每个格子都对应具体的训练内容和训练方式，不是抽象的"提升能力" |
| **可评价** | 每个格子都有明确的行为标准，可以用来评估经纪人是否达到该场景下的能力要求 |

## 五、常见误解澄清

| 常见误解                | 真实理解                                            |
| ------------------- | ----------------------------------------------- |
| 4×7是28门课            | ❌ 不是课程，是28个能力训练节点；"格子"才是训练对象，课程是填格子的手段之一        |
| 4是顺序递进的层级（先学理解再学立场） | ❌ 不完全是——同一场景下，四类能力可以同时发生；它们是能力的四个维度，不是线性学习顺序    |
| 7个流程是培训的模块顺序        | ❌ 7个流程是业务发生的真实节点，培训不必按这顺序上，而是按能力差距来选            |
| 能力标准由总部专家拍脑袋定       | ❌ 标准必须来自一线真实场景和TOP经纪人的真实动作——这是联动深圳城市客赋中心的核心原因   |
| 4×7做完就是终态，用一辈子      | ❌ 这是持续迭代的图谱，随业务场景、市场环境、消费者需求变化而更新               |
| 4×7是花桥的培训课件体系       | ❌ 4×7是能力标准体系；基于4×7开发的TGC内容，才是课件。两者是底层逻辑与上层应用的关系 |

## 六、4×7与相关概念的关系

```
4×7能力图谱（底层标准体系）
    │
    ├── 能力单元（28/56个格子）→ 每格填入：能力解读 + 经纪人动作 + 评价标准
    │
    ├── First Sample（首批真实案例）→ 从一线提取，验证和校准能力标准
    │
    ├── TGC内容（糖果厂）→ 基于能力图谱产出的经纪人真实案例/故事/课件
    │
    ├── BOX（课程盒子/AI陪练场）→ 把能力图谱转化为可交付的训练产品
    │
    └── 城市复制路径 → 深圳试跑 → 跑通SOP → 复制到其他城市
```

## 七、为什么这件事非做不可？

从大S的判断往回推：

1. **AI替代威胁**：AI能做的信息搜集、房源匹配、价格对比，都将被工具化；只有"顾问能力"是AI无法完全替代的
2. **消费者升级**：当下消费者更聪明、更挑剔，他们需要的不是"带我去看房的人"，而是"帮我做对决策的人"
3. **能力黑箱问题**：目前没有一套体系能清晰描述"好经纪人到底好在哪"——4×7要把这个黑箱打开
4. **培训效果问题**：没有清晰标准的培训，只能靠讲师的经验和感觉；有了4×7，培训内容有锚点，效果有评价维度
