## 二、底层设计：4×7能力图谱

### 2.0 重新理解：4×7是什么？

> 在拆解框架之前，先把一个核心认知对齐：**4×7不是一套课程，是一张让经纪人"被看见能力差距"的坐标系。**

#### 来源：它从哪里来？

大S在研讨会上提出的核心判断是：

> **"AI时代，消费者需要的不是信息播报机，而是能理解处境、做出判断、提供路径、承担立场的顾问型服务者。"**

这就是4×7的原点。AI时代，经纪人如果只会"播报信息"，价值会被替代；只有具备**顾问型能力**的经纪人，才有不可替代性。

#### 结构：4是什么？7是什么？

- **"4"** 是纵轴——经纪人服务消费者的4类核心能力（理解 → 判断 → 路径 → 立场）
- **"7"** 是横轴——从开拓到成交的7个业务流程节点
- **两轴交叉** = **28个能力单元**（每格是一个可训练、可评价的训练节点）
- **双赛道（客户+业主）合计** = **56个能力单元**

#### 本质：它真正要解决什么？

4×7真正要解决的问题是：**我们现在知道经纪人哪里不行，但我们说不清楚"什么叫行"。**

4×7要做的，就是把"行"和"不行"的标准，拆进每一个真实的业务场景里，让能力差距变得**可见、可训练、可评价**。

> 💡 用一句话说：4×7是一张坐标纸——横轴是经纪人服务消费者的7个业务时刻，纵轴是4类判断能力；每个格子里写的，是"一个顾问型经纪人在这个时刻，应该做什么、怎么判断、怎么被评价"。填满这张纸，就等于把经纪人从"信息播报机"训练成"顾问"的路径图搭好了。

#### 容易搞混的几个点

| 常见误解 | 真实理解 |
|---|---|
| 4×7是28门课 | 不是课程，是28个能力训练节点，每格才是一个训练对象 |
| 4是顺序递进的层级 | 不完全是——同一场景下，理解/判断/路径/立场可以同时发生 |
| 7个流程是培训的模块顺序 | 不是——7个流程是业务发生的真实节点，不代表培训要按这顺序上 |
| 能力标准由总部专家定 | 标准必须来自一线真实场景——这是联动深圳的核心原因 |
| 4×7完成后就是终态 | 不是——这是一个持续迭代的图谱，随业务场景变化而更新 |

### 2.1 框架总览

**4×7 = 4类核心能力 × 7个服务流程节点**

#### 4类核心能力定义

| 能力维度   | 核心含义                     | 判断标准                 |
| ------ | ------------------------ | -------------------- |
| **理解** | 真正读懂消费者的处境与真实需求，不是听完就走   | 能复述客户/业主真实困境，而非表面诉求  |
| **判断** | 帮消费者筛选选项、做出专业建议，不是单纯播报信息 | 能主动给出"建议你不选XX，原因是……" |
| **路径** | 为消费者设计下一步行动方案，不是等对方问     | 能说清"你下一步这样做，我来配合"    |
| **立场** | 与消费者站在同一侧，敢于承担专业责任       | 能说"我建议你选A，出了问题我来担"   |

> 💡 S的比喻：这是从内存16兆（只会听）→ 到奔腾CPU（能判断）→ 到负责任的顾问（敢承担）的四层跃迁。

#### 客户赛道：7个服务流程节点

| 序号  | 流程节点     | 核心任务             |
| --- | -------- | ---------------- |
| C1  | 寻找客户     | 识别潜在购房意向，建立初步连接  |
| C2  | 客户面访     | 深度了解需求，建立信任关系    |
| C3  | 首看（首次带看） | 展示房源，验证需求，激发购买兴趣 |
| C4  | 多看（多次带看） | 通过比对帮助客户缩小选择范围   |
| C5  | 探盘       | 协助客户验证意向房源，推动决策  |
| C6  | 正签（签约）   | 引导谈判，推动成交，保护客户权益 |
| C7  | 售后       | 交付后续跟进，建立长期服务关系  |

#### 业主赛道：7个服务流程节点

| 序号 | 流程节点 | 核心任务 |
|---|---|---|
| O1 | 寻找业主 | 识别委托意向，建立接触 |
| O2 | 获取委托 | 争取独家/合作委托，签约 |
| O3 | 初次面访 | 了解业主诉求，建立信任 |
| O4 | 深度面访 | 深挖卖房动机，挖掘真实底线 |
| O5 | 带看反馈 | 传递市场真实信息，管理业主预期 |
| O6 | 谈判正签 | 引导业主做出决策，推动成交 |
| O7 | 售后 | 交付后续服务，维护长期关系 |

### 2.2 28个服务场景能力图谱（客户赛道示意）

> 下表展示客户赛道 28 个能力单元，每格 = 1个可训练、可评价的能力单元

|             | **理解**            | **判断**             | **路径**           | **立场**               |
| ----------- | ----------------- | ------------------ | ---------------- | -------------------- |
| **C1 寻找客户** | 理解潜在客户的购房出发点与生活处境 | 判断客户是否真实购房意向、预算匹配度 | 设计接触路径与初次建联的动作逻辑 | 以客户长期利益为导向，不急于推销     |
| **C2 客户面访** | 精准识别显性需求背后的隐性诉求   | 判断客户当前处于决策哪个阶段     | 规划下一步推进节点与带看方案   | 承诺"我会帮你找到真正适合你的房子"   |
| **C3 首看**   | 感知客户现场的真实反应与情绪变化  | 判断此房源是否匹配客户真实需求    | 设计带看讲解逻辑，引导重点关注  | 对房源优缺点直接表态，不回避       |
| **C4 多看**   | 识别客户内心的取舍权重与真实顾虑  | 判断哪套房最接近客户核心需求     | 主动收窄选项，给出推荐理由    | 敢于说"我建议你不考虑XX，原因是……" |
| **C5 探盘**   | 读懂客户对意向房源的真实态度    | 判断谈判时机与价格预期差       | 设计价格谈判策略与推进步骤    | 帮客户争取最合理的交易条件        |
| **C6 正签**   | 理解客户签约顾虑与最后的心理障碍  | 判断哪些顾虑是真实的，哪些是情绪性的 | 设计签约推进话术与应急预案    | 明确承诺"合同里你的权益我负责守住"   |
| **C7 售后**   | 理解客户交付期的期望与担忧     | 判断哪些问题需要主动介入协调     | 制定售后跟进节点与沟通计划    | 主动承担中间人角色，不推卸责任      |

> **注**：业主赛道28个能力单元另行同步呈现，逻辑与上表一致。两个赛道合计 **56个能力单元**。

### 2.3 能力单元的三层拆解逻辑

每个能力单元（格子）按三层展开，形成**可学、可练、可评**的训练闭环：

```
Layer 1 能力解读 — "这个场景下，什么叫做到了理解/判断/路径/立场？"
       ↓
Layer 2 经纪人动作 — "什么样的具体动作，代表他达到了这个能力标准？"
       ↓
Layer 3 评价标准 — "什么是优秀动作，什么是及格动作，什么是不合格动作？"
```

**示例：C1 寻找客户 × 理解**

- **能力解读**：在寻找客户阶段，"理解"意味着经纪人不只是识别"有没有购房意向"，而是能感知潜在客户当前的生活处境——是改善型需求还是刚需？有没有隐藏的紧迫性？背后是否有决策影响人？
- **经纪人动作标准**：
  - 优秀：初次沟通时主动问出"您现在的出行/工作/孩子上学"等生活状态，从生活场景倒推真实需求
  - 及格：能问出预算区间和大概区域，但停留在信息收集层
  - 不合格：直接介绍房源，未做任何需求了解
- **评价方式**：AI 模拟客户对话，事后自评+AI评价，Gap识别

## 三、2件重要事件

### 3.1 事件一：4×7能力解读共识会

#### 目标
联动花桥学堂 + 深圳城市客赋中心，完成28个（先跑客户赛道）能力单元的标准解读，形成**共同认可的能力标准基准版**。

#### 为什么要联动深圳？
- 深圳客赋有大量在当下拿到一线结果的**TOP经纪人**
- 有每天运营一线的**平台运营管理者**
- 他们提供的能力解读来自真实业务场景，避免总部视角的"空中楼阁"
- 深圳客赋高意愿度参与，后续会主动认同这套标准，执行阻力小

#### 参与方及角色（城市具体数据后期再定）

| 参与方                       | 角色          | 核心贡献                 |
| ------------------------- | ----------- | -------------------- |
| 花桥学堂（讲师发展）                | 主导框架设计与会议组织 | 提供4×7框架、能力解读初稿、共识会设计 |
| 深圳TOP经纪人（2-3位）            | 一线实践验证者     | 验证能力标准的真实性，提供真实经纪人动作 |
| 深圳平台运营管理者（1-2位）           | 业务视角补充者     | 从城市管理视角补充能力差距和高频失误   |
| 花桥讲师（预计参与的TOP经纪人及城市运营管理者） | 课程化转化者      | 把共识结果转化为可训练、可评价的课程内容 |

#### 交付物
- 4×7能力标准解读文档 v1.0（28个单元，每单元三层拆解）
- 共识会纪要 + 各方认可的能力标准基准版
- 经纪人动作case库（初始版，来自深圳一线）

#### 建议时间节点
- **T+1周**：完成能力解读初稿，发深圳预读
- **T+2周**：线上/线下共识会，深圳TOP经纪人+管理者参与
- **T+3周**：修订完成，交付能力标准v1.0

### 3.2 事件二：标杆产出经纪人能力动作 + TGC内容积累

#### 目标
基于能力标准，在真实的消费者服务故事中找到**经纪人优质服务动作**，形成：
1. 4×7能力图谱的"活"内容填充（经纪人动作标准样本）
2. **TGC内容语料**的同步积累

#### 核心逻辑

这批内容不是坐在办公室里写出来的，而是**从真实的消费者服务案例和故事中生长出来的**。

```
找到能力标准
    ↓
找到符合标准的城市标杆（一线经纪人/管理者）
    ↓
产出经纪人在特定场景下的动作（消费者叙事+案例/故事）
    ↓
能力图谱填充+ TGC内容
```

#### 谁来产出？

这里有一个关键设计：**产出TGC内容的人，最好同时具备两个身份：**
- **TOP经纪人 / 城市平台运营管理者**（保证内容来自真实一线）
- **花桥讲师**（保证内容质量和输出能力）

**四种人员情况与对应路径：**

| 人员情况                | 路径设计                         | 激励机制            |
| ------------------- | ---------------------------- | --------------- |
| 既是TOP经纪人/管理者，又是花桥讲师 | 直接参与能力图谱共创 + 内容产出            | 内容产出课酬 + 讲师序列保级 |
| 是TOP经纪人/管理者，但不是花桥讲师 | 参加花桥城市实战赋能课 → 认证为花桥讲师 → 参与产出 | 讲师认证荣誉 + 后续课酬资格 |
| 已是花桥讲师，未直接参与内容产出    | 通过培育新讲师产出内容，作为老讲师的保级路径       | 培育贡献计入序列评级      |
| 已是花桥讲师，深入一线拿到实践经验   | 拿到符合能力图谱的实践，产出内容             | 同上，课酬 + 讲师保级    |

> 💡 **核心设计亮点**：新的讲师保级本身就要求产出TGC内容——这意味着4×7的内容产出不是额外任务，而是**把保级要求和4×7建设打通**，形成自发的内驱动力，而不是下指令。

#### 花桥 vs 深圳城市分工

| 工作板块    | 花桥学堂负责            | 深圳城市客赋中心负责            |
| ------- | ----------------- | --------------------- |
| 整体框架与标准 | 4×7能力框架设计 + 共识会组织 | 提供一线验证视角              |
| 标杆筛选    | 提供筛选标准（基于能力图谱）    | 按标准找到城市标杆候选人          |
| 内容产出    | 叙事提取方法指导 + 内容质量把关 | 组织城市资源、提交案例故事、产出TGC内容 |
| TGC内容审核 | 内容标准审核，纳入TGC语料库   | 内容产出主力                |
| 讲师认证    | 花桥城市实战赋能课设计+交付    | 推荐城市候选讲师参加认证          |

## 四、落地运营：三阶段推进

### 4.1 三阶段总览

```
第一阶段（当下优先）
能力图谱建设 + TGC内容产出
→ 以深圳为样板城市，跑通全流程
    ↓
第二阶段（内容落地应用）
TGC内容在城市/花桥/北京链家落地
经纪人能力诊断与差距训练
    ↓
第三阶段（规模化复制）
以深圳模式为范例
花桥联动其他城市滚动推进
能力图谱持续迭代丰富
```

### 4.2 第一阶段：重点方向（当前主攻）

#### 花桥的核心工作

**任务1：4×7的运营规划**
- 输出4×7能力框架文档（含能力定义、服务流程、28/56个能力单元）
- 制定第一阶段工作计划（时间节点、交付物、协同方式）
- 牵头设计能力解读共识会方案

**任务2：与深圳城市的任务分配 + 共创流程设计**
- 设计花桥↔深圳的协同工作流：谁做什么、何时交付、如何评审
- 明确深圳的资源边界（TOP经纪人数量、管理者配合时间）
- 设计内容产出的标准化模板（案例叙事格式、动作描述格式）

#### 深圳城市的核心工作

**任务1：协同能力解读共识**
- 找到 2-3 位 TOP 经纪人参与共识会（筛选标准：最近6个月在一线持续拿到结果）
- 找到 1-2 位平台运营管理者参与共识会（筛选标准：积极主动，深入一线，了解城市经纪人能力差距）
- 共识会前提前预读能力框架初稿，带具体一线案例参会

**任务2：找到城市标杆，产出内容**
- 基于共识后的能力标准，找到不同流程节点下的城市标杆经纪人
- 组织城市资源、提交案例故事、产出TGC内容/课件
- 产出：经纪人动作案例 + TGC内容初稿

#### 第一阶段关键设计：花桥下城市不是"下任务"，而是"带着价值来"

这是整个合作能否落地的关键心法：

**花桥要给到城市的价值**：
1. **讲师认证机会**：把花桥讲师认证场搬到深圳，本地化交付城市实战赋能课
2. **讲师序列晋升**：参与4×7内容共创，直接计入讲师M序列保级/晋级
3. **城市赋能资源**：花桥课程资源下城市，提升深圳城市讲师能力池
4. **内容课酬**：产出TGC内容可获得相应课酬

**换句话说**：城市（深圳）不是在帮花桥干活，而是在享用花桥带来的资源，同时顺便把4×7的内容做出来。

---

### 4.3 第二阶段：内容落地应用（预期目标）

- 基于第一阶段产出的能力图谱和TGC内容，在深圳/花桥/北京链家进行首次落地
- 经纪人能力诊断：基于28个能力单元，识别当前经纪人的能力差距（哪些格子是薄弱的）
- 针对性训练：基于差距，用已产出的TGC内容开展定向训练
- Practice Box（如条件成熟）：在特定场域试点AI模拟训练

### 4.4 第三阶段：规模化复制

- 以深圳为范例，输出"4×7城市落地标准包"（含共创流程、讲师认证方案、内容产出模板、评价标准）
- 花桥联动其他城市，滚动推进
- 能力图谱持续迭代丰富（不同城市、不同场景补充更多案例）
- 形成正向飞轮：**能力图谱丰富 → 训练更精准 → 经纪人能力提升 → 消费者服务体验提升**
