## 三、完整视频剪辑策略

### 3.1 完整视频结构逻辑

**总时长参考：约5~6分钟**

完整视频 = 切片1 + 切片2 + 切片3 顺序拼接，逻辑递进：

```
【入口】为什么知识课不够用了？（痛点共鸣）
    ↓
【翻转】投稿不是任务，你是知识的共创者（认知翻转）
    ↓
【落地】一颗真实的糖：六年级小姑娘改变了爸爸的购房决策（行动召唤）
```

### 3.2 剪辑逻辑说明

> **为什么这样排？**

访谈原文的时间顺序是：TGC是什么 → 讲师发展 → 平台vs业务讲师 → 邓鹏的糖 → 后台/心理 → 不是任务 → 男孩女孩

但视频号的传播逻辑需要：**先制造痛点共鸣 → 再翻转让你觉得"原来如此" → 最后用故事让你想行动**

所以剪辑的逻辑是：
- **切片1**取了访谈开头的"为什么"（Q1+Q2），因为这是所有后续讨论的前提——经纪人到底需要什么？
- **切片2**取了访谈后半段的"心态翻转"（Q8），因为先理解"为什么"再讲"不是任务"才顺。同时穿插Q3中培训人核心竞争力的段落，让"你是知识共创者"有具体支撑
- **切片3**取了访谈中间的"真实故事"（Q4+Q9），放在最后是因为：故事是最好的行动召唤——听完"不是任务"的翻转后，再看到一颗真实的糖，投稿意愿最强

> **为什么不用Q3完整段？**

Q3（平台讲师vs业务讲师）内容很长（约6分钟），且话题偏向讲师内部分类讨论，对普通视频号受众吸引力有限。只取其中"听得懂故事、讲明白故事、总结方法论"这一句作为切片2的支撑，点到即止。

> **为什么不用Q5、Q6、Q7？**

- Q5（要后台是为了积累案例库）和Q6（生产案例的心理过程）信息密度不够高，且Q6的"约到熟人聊"细节偏内部
- Q7（客户为什么选这个经纪人）只有1分钟，信息量少，且内容（"特别时称""信任邓鹏推荐"）不够有传播力

这些内容可以在完整视频的加长版中使用，但在5-6分钟的版本中优先级不高。
