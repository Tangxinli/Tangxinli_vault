## 写在前面：什么样的互动能出好成果？

这份文档不是"AI使用说明书"，而是**一个真实的产出路径复盘**。

经过近期密集与AI的合作，我发现两个最满意的成果——**糖果厂第二周推文** 和 **陈荣老师先行者访谈视频** ——它们能出好结果，不是因为AI很厉害，而是因为**我们之间的对话方式对了**。

核心规律只有一条：
> **"先给AI足够的背景和判断标准，再给它明确的产出格式，然后你负责审阅与精调——别把决策权全交给它。"**

---

## 路径一：公众号推文产出路径

### 适用场景

- TGC糖果厂项目推文
- 面向讲师群体的内容传播
- 需要"有温度、有感染力、有策略"的图文

---

### 整体流程图

```
战略背景输入 → AI读取素材/策略文档 → 确定选题方向 → 确认四段式框架 
→ AI生成初稿 → 你审阅+精调 → 定稿
```

---

### 分步操作路径

#### 第一步：喂进去"背景包"

在开口让AI写之前，先把这些东西告诉它：

| 输入内容 | 说明 |
|---|---|
| **TGC的定位与目标** | 讲师是战略翻译官，案例是IP支点等核心主张 |
| **当期运营目标** | 比如：本周目标是让讲师觉得"投稿有价值、被看见" |
| **已有素材** | 案例内容（Excel/MD）或采访片段提炼 |
| **受众画像** | 面向讲师，信息克制，轻触发而非重报名 |

> 💡 提示：如果Obsidian vault里有相关策略文档，直接告诉AI文件路径，让它读取，效率最高。

---

#### 第二步：锁定"四段式"写作框架

在糖果厂推文实践中，验证有效的结构是：

```
① 戳痛点  → 讲师的真实困境/疑虑（共鸣入口）
② 轻翻转  → 一个认知的小扭转，不说教（制造好奇）
③ TGC变有趣 → 具体案例或行动让抽象变具体（建立信任）
④ 人出现   → 有名有姓的讲师故事或行动邀约（情感落地）
```

**对AI说这句话：**
> "请基于四段式框架写这篇推文：戳痛点→轻翻转→TGC变有趣→人出现。标题要有标题党感、有锋芒，不要正式腔。正文信息克制，每段控制在100字以内。"

---

#### 第三步：给标题明确的"禁忌"和"偏好"

AI写标题容易犯的错：太正式、太平、像通知。

告诉它你的偏好：

```
偏好：标题党式开场、有锋芒、有温度
禁忌：不要"赋能"、"助力"、"打造"这类词
示例参考：《他讲了8年课，终于想明白一件事》《这件事做了3年，我才看懂它值什么》
```

---

#### 第四步：审阅时用"三个问题"快速定位问题

- ❓ 第一句话能不能让目标讲师停下来看？
- ❓ 有没有具体的人或具体的案例出现？
- ❓ 整篇读完，行动信号是轻触发还是高压迫？

用这三个问题告诉AI哪里需要改，比说"再优化一下"准确10倍。

---

#### 第五步：精调迭代（不超过2轮）

实践规律：
- **第1轮**：AI出初稿，你给结构和方向反馈（"第二段太说教了""人没出现"）
- **第2轮**：AI修改，你做文字级微调即可

> ⚠️ 注意：超过2轮还不满意，说明第一步的背景输入不够，回去补材料，别反复改字。

---

### 完整Prompt模板（可直接复用）

```
背景：我在做TGC糖果厂项目，面向花桥学堂的讲师群体。
TGC定位：讲师是战略翻译官，叙事核心是真实选择（择）。
本期目标：让讲师感受到"投稿是被看见的"，轻触发报名，不是动员大会。

素材：[粘贴案例内容或采访片段]

请基于四段式写一篇公众号推文：
①戳痛点（讲师真实困境）→②轻翻转（认知扭转）→③TGC变有趣（案例佐证）→④人出现（真实故事/行动邀约）

标题要求：
- 有标题党感，有锋芒，不要正式腔
- 不使用"赋能""助力""打造"等词

正文要求：
- 每段100字以内
- 有温度，活泼，信息克制
- 至少出现一个有名字的讲师
```

## 路径二：视频号内容产出路径

### 适用场景

- 先行者访谈系列（完整版 + 短视频矩阵）
- 讲师采访素材 → 视频号发布
- 配合公众号推文同步发布

---

### 整体流程图

```
采访视频 → 转录字幕 → AI提炼核心观点/金句 
→ 确定剪辑框架（6幕/4段结构）→ AI生成分镜表 
→ 剪映执行剪辑 → AI辅助标题与字幕卡 → 发布
```

---

### 分步操作路径

#### 第一步：拿到原始素材包

需要准备的材料：

| 材料 | 获取方式 |
|---|---|
| 原始视频文件 | 采访录制（MP4格式，建议1080p） |
| 字幕/转录文本 | AI转录（提供视频路径，AI生成SRT字幕） |
| 受访者背景 | 讲师名字、身份、核心主张 |

> 💡 提示：字幕文件可直接导入剪映，大幅提升剪辑效率。

---

#### 第二步：让AI提炼"核心骨架"

把转录文本发给AI，用这个指令：

```
请阅读以下访谈转录文本，提炼：
1. 核心观点（3-5个，每个一句话概括）
2. 金句（可直接用作字幕卡或标题的原话，5-8句）
3. 重要案例（有细节有数字的具体事件）
4. 按话题分类整理（如：认知转变/具体案例/行动建议）
```

这一步产出的内容是后续所有视频和推文的"素材库"。

---

#### 第三步：确定剪辑框架（先想清楚，再让AI出脚本）

**陈荣老师视频验证有效的6幕结构：**

```
第1幕：TGC是什么（10-20s，定调）
第2幕：核心痛点（讲师面对的真实困境）
第3幕：认知转变（TGC带来的思维扭转）
第4幕：案例价值（具体案例+数据）
第5幕：AI与IP（延伸价值，建立期待）
第6幕：结尾隐喻（情感升华，如"糖果厂是调色盘"）
```

**短视频4段结构（60-90s）：**

```
第1段：钩子（前5秒，用金句或问题开场）
第2段：冲突（讲师的困境/认知卡点）
第3段：转折（具体行动/案例）
第4段：收尾（行动邀约或升华一句话）
```

---

#### 第四步：AI生成可执行分镜表

框架确定后，让AI生成分镜表：

```
请基于以下访谈转录（[粘贴文本]），
按照6幕结构生成一份可执行分镜表：

每幕包含：
- 幕名与时长建议
- 具体使用的原始片段（标注大致时间戳）
- 字幕卡内容（如需要）
- 视觉处理建议（特写/全景/叠加文字等）

风格参考：鲁豫访谈风格，极简沉浸，镜头感强，聚焦受访者本人。
```

---

#### 第五步：剪映执行（AI辅助不了的环节，但可以问它）

- 将SRT字幕文件导入剪映
- 按分镜表时间戳找对应片段
- 字幕卡内容由AI提供，直接复制到剪映文字模板

> 💡 遇到技术问题（格式、编码）可以直接问AI，它能给操作步骤。

---

#### 第六步：标题与封面文案

让AI出3个备选标题，你选一个：

```
请为这段视频出3个标题备选，风格要求：
- 有吸引力，用数字或悬念感
- 突出主角（受访者姓名+核心行动）
- 不超过20字
- 避免"赋能""突破"等空洞词
```

---

### 完整Prompt模板（短视频版，可直接复用）

```
我有一段访谈视频，受访者是[姓名]，身份是[花桥学堂讲师/职位]。
核心主张：[一句话概括，如"案例是讲师的IP支点"]

以下是转录文本：[粘贴文本]

请生成一个90秒短视频分镜表：
- 结构：钩子（0-5s）→冲突（5-30s）→转折（30-75s）→收尾（75-90s）
- 每段标注：使用的原始片段内容（时间戳范围）、字幕卡文字、视觉处理建议
- 风格：鲁豫访谈极简风，聚焦受访者，字幕卡控制在15字以内
- 同时给出3个备选标题
```

## 通用的AI互动原则（让成果质量稳定的关键）

| 原则 | 具体做法 |
|---|---|
| **先背景后任务** | 不要上来就"帮我写篇推文"，先给项目定位、目标受众、本期重点 |
| **给格式约束** | 字数限制、结构框架、禁忌词——约束越具体，初稿越能用 |
| **审阅用问题不用感觉** | 不说"感觉不好"，说"第二段没有具体案例" |
| **迭代控制在2轮** | 超过2轮说明素材不够，补素材比改字有效 |
| **把AI当编辑助理** | AI负责结构和初稿，你负责决策和精调，不要让它替你做内容判断 |
| **素材越结构化产出越好** | 给AI的素材如果已经按"人-境-择-果-思"整理过，产出质量会高很多 |

## 附：两个满意成果的关键节点复盘

### 糖果厂第二周推文 ✅

**成功的关键动作：**
- 把Obsidian里的运营策略文档路径给AI读取（不是手动粘贴）
- 明确告诉AI"邓鹏+陈荣双线"组织内容
- 对标题不满意时，给出了具体的"不通顺""不适配"反馈，而不是泛泛的"再改改"

**可复用的动作：** 让AI读取vault文件 → 结合OKR判断内容方向 → 四段式框架 → 精调标题

---

### 陈荣老师先行者访谈视频 ✅

**成功的关键动作：**
- 提供了完整的视频+字幕文件，让AI基于真实素材工作
- 定义了清晰的6幕剪辑框架（不是让AI自己设计框架）
- 明确指定了"鲁豫风格"这个具体的参考坐标
- 去掉了时长硬性约束，强调"内容完整和逻辑闭合"

**可复用的动作：** 原始素材 → 转录 → AI提炼骨架 → 框架确认（人来做）→ AI出分镜 → 剪映执行
