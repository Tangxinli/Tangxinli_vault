# 3D 时间幅度：能力的成长曲线

> 前三层都是"切片"——这一刻、这一单看一个经纪人的能力。
> 但能力会随时间变化。同一个人在不同时间尺度上有完全不同的样貌。

---

## 为什么要加时间这条轴

L2 水位标尺是张二维的快照。但你看一份评估只看到这一次的水位——

- 一个人这次表现 L2，下次还是 L2，3 年后还是 L2 → 这是"水位稳定的 L2"
- 一个人这次 L1，下个月 L2，半年后 L2 稳住，一年后偶尔 L3 → 这是"在变强的 L1"

**评 L2 这件事一样，但他们是完全不同的人。**

3D 模型 = 把时间叠加到 2D 平面上。Z 轴往后延伸，看的是**水位的稳定性 + 上升速度 + 顶端高度**。

---

## 三个时间尺度

### Z1 单次接触（一次面访 / 一次带看）

**问题**：这一次他做得怎样？
**用什么测**：2D 水位标尺，给一次定级
**重点指标**：
- 这一次给出了判断吗？
- 这一次排出了路径吗？
- 这一次有没有反向建议的瞬间？

这是评估资料库里每份报告解决的问题——颗粒度最细，样本最多。

---

### Z2 单单成交（从需求到签约）

**问题**：贯穿 7 阶段，他能不能不掉链子？
**用什么测**：4×7 矩阵，看哪几格做了、哪几格断了
**重点指标**：
- 7 个阶段中有几个阶段是他在主动驱动？
- 客户在第几阶段开始信任他？
- 是不是只有"看房带看"这一阶段亮眼，其他全靠流程托？

这一层暴露的是**完整服务链路的能力**。资料库里很多 L2 选手，是"单点亮眼但全程拼凑"——只有看了完整一单才看得出来。

---

### Z3 多年陪伴（5 年 / 10 年）

**问题**：长期看，这个人在不在变强？客户回不回头？
**用什么测**：很难直接测——靠"客户回头率 / 转介绍率 / 多年案例库的水位曲线"
**重点指标**：
- 5 年前的客户今天还会找他吗？
- 朋友买房第一个想到的是他吗？
- 他说话的水位有没有逐年上升？还是 3 年前 L2、现在还是 L2？

这一层在资料库里几乎看不到——单次评估不可能告诉你 5 年后这个人怎么样。需要跨越多年的纵向数据。

---

## 三种典型成长曲线

把同一个人在 Z1 / Z2 / Z3 上画出来，会得到三种典型轨迹：

### 类型 A：水位稳定型（多数 L2）
```
Z1 单次：L2
Z2 单单：L2
Z3 多年：还是 L2
```
**特征**：三年前会的现在还会，三年前不会的现在还不会。
**判别**：看他这两年新案例和老案例的水位，没区别。
**培训策略**：识别天花板原因——多半是 8 项根能力里的 4 或 8（勇气 / 诚实）卡住了，技巧训练没用。

### 类型 B：上行型（潜力股）
```
Z1 单次：L1（一年前）→ L2（半年前）→ 偶尔 L3（最近）
Z2 单单：上行
Z3 多年：3 年内从入门到稳定 L2，能看到 L3 趋势
```
**特征**：每次的"最低下限"都在抬高；偶尔的高光时刻在变多。
**判别**：拿他 12 个月前的案例和最近案例对比，水位有显性提升。
**培训策略**：维持反馈强度，给他更难的客户练手——他能消化。

### 类型 C：下沉型（最危险）
```
Z1 单次：偶尔有 L2 高光
Z2 单单：L1
Z3 多年：水位下降
```
**特征**：单次面访能装出 L2，但完整一单看下来掉链子；时间越久越糊。
**判别**：客户回头率断崖、转介绍归零、老客户对他的评价跟新客户差很多。
**培训策略**：培训救不了——可能是身份认同已经从"专业服务者"漂移到"成交工具"。

## L3 选手的真正定义

> **L3 不是"一次做对"，是"多年里持续做对"。**

把这个 3D 模型套在 L3 上：

- Z1 上稳定 L3（每次都给得出判断和路径）
- Z2 上稳定 L3（一单从头到尾不掉链子）
- Z3 上稳定 L3（5 年回头看，水位不下沉，反而在升）

资料库里 4 个 L3 案例只能证明 Z1 这一层。**Z2、Z3 需要更长周期的数据才能验证。**

这也是为什么"看一次案例就拍 L3"是危险的——它可能只是 Z1 的高光。

---

## 用法

### A. 培训设计
按 Z 轴定课程粒度：
- **Z1 课程**——单次面访 / 带看 / 报价的微技巧（最容易设计，资料库直接产出）
- **Z2 课程**——一单的完整推进训练，跨阶段的协同（中等，需要案例陪跑）
- **Z3 课程**——身份认同 / 价值观训练（最难，更像导师制而非培训）

**多数培训公司只有 Z1 层课程**——这是为什么"上完课没用"的根因。

### B. 人才识别 / 晋升评定
- 升 L2 → 看 Z1（一次面访能稳住）
- 升 L3 → 看 Z2（完整一单不掉链）
- 升合伙人 / 内训师 → 看 Z3（多年水位上行 + 老客户口碑）

**短时间无法识别 L3+ 的人**——必须看时间。

### C. 自我评估
- 翻自己一年前 vs 最近的录音 / 评估报告——水位有没有变？
- 5 年前的客户还有联系吗？
- 现在敢说的话，3 年前敢说吗？

---

## 一句话压缩

> **L1 / L2 / L3 是一刻的切片，真正的等级是看时间——能稳住的水位才是你的水位。**
