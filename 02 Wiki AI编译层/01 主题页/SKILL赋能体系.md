# SKILL赋能体系

> 课研能力沉淀为可复用Skill，让讲师自产课件，长期降低课研负担。
> 来源：用户思考 + [[会议纪要_0625_BL1×TGC沟通（鑫久+新月+文莉）]]

---

## 核心逻辑

```
发现优秀 → 萃取优秀 → 生成课件 → 赋能讲师 → 经纪人练习 → 产出新优秀 → 循环
    ↑                                                              |
    └──────────────── Skill 赋能 ──────────────────────────────────┘
```

4×7是"寻找优秀→学习优秀→成为优秀"的循环，Skill是把课研能力沉淀下来让循环可复制的工具。

---

## Skill 定义

**Skill = 标准化课研能力的封装**

一个Skill解决一个具体的课研问题，使用者不需要理解底层方法论，按照Skill流程操作就能产出合格内容。

## Skill 与绘练的分工

| 维度 | Skill | 绘练 |
|------|-------|------|
| 对象 | 讲师 | 经纪人 |
| 定位 | 生产端工具 | 消费端工具 |
| 作用 | 帮他寻找优秀→萃取优秀→生成赋能课件 | 帮他基于课件不断练习 |
| 产出 | 课件/赋能内容 | 练习记录/能力提升 |

两端配套才能跑通：Skill产出课件 → 绘练基于课件设计练习 → 经纪人练习后产出新优秀 → Skill再萃取。

## BL1工作坊的Skill模式

来自 [[会议纪要_0625_BL1×TGC沟通（鑫久+新月+文莉）]]：

**传统模式**：课研萃取老师 → 老师输出 → 课研做课件
**新模式**：课研产出工作坊课件（流程+Skill体系）→ 评价讲师OK → 讲师用工作坊课件自产课件

工作坊课件 = **流程框架**（课研做）+ **Skill体系**（每页配一个Skill，讲师输入素材→生成内容）

**长期价值**：
- 标准化产出：不同讲师按同一流程产出，保证质量底线
- 降低课研依赖：讲师可自行迭代，与Skill对话即可产课件
- 可复用扩展：内容实践Skill做好后，增长/经营实践可沿用框架调整

## 与4×7项目的关系

4×7是Skill赋能体系的业务场景和验证场：
- 4×7萃取Skill已在重庆共创中验证（v0.3）
- 4×7标杆访谈是Skill的语料来源
- 4×7共创是Skill的验证场景
- Skill赋能体系的成熟度决定4×7能否从"项目驱动"升级为"机制驱动"
