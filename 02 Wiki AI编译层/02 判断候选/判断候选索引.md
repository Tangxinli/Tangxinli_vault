### 项目判断

**TGC运营**：激活讲师内容价值飞轮

**核心问题**：内容如何产生价值

**解决路径**：
1. 命题优选 → 解决"生产什么"
2. 讲师生态 → 解决"由谁生产"
3. 场景运营 → 解决"在哪里深化价值"
4. 渠道运营 → 解决"如何放大价值"

---

**4×7项目**：构建经纪人服务能力体系

**核心问题**：我们知道经纪人哪里不行，但说不清"什么叫行"

**关键判断**：框架是通用的，内容是本土的
- 通用层（不变）：4×7结构、L1/L2/L3标准、8项根能力、成长曲线类型
- 本土层（变）：28格内的具体内容、案例、优先提升项、培训课件

**交付范围**：4×7 + First sample（唐文莉主责）；BOX由宗菲负责

**4×7 → BOX承接接口**：
- 28格矩阵 → 训练模块输入
- 水位标准 → 诊断工具
- 8项根能力 → 训练路径设计依据
- 案例萃取 → 教学素材

**解决路径**：
1. 定义能力图谱（4类能力 × 7个流程）
2. 填充能力单元（解读 + 动作 + 评价标准）
3. 城市试点验证（重庆首城）
4. 复制推广（深圳二城 → 全国）
