## 二、S开场：AI对学习和培训的冲击

### 2.1 亲身案例：女儿AP考试与AI辅助学习

S的女儿考AP美国历史，考前压力极大，基本没有复习时间。

**S用AI做了一系列迭代：**

| 迭代  | 女儿需求                  | S的方案                               |
| --- | --------------------- | ---------------------------------- |
| V1  | 换个方式学习，不想看书           | 把知识点生成播客音频（对接Fish Audio语音）         |
| V2  | 讲得更有趣 + 人名中英文对照 + 压考点 | 重新生成，更有趣、重复英文名、标注考点                |
| V3  | 按章串讲主线，方便记忆           | 生成9章串讲音频                           |
| V4  | 模拟押题对话                | 用三个不同声音（姑姑、知性女性、主持人）模拟师生对话，每章10分钟内 |
| V5  | 全篇最后讲解+鼓励             | 生成15分钟总复习音频，开头叫名字、结尾大量鼓励           |

**核心数据：**
- 总花费：约150元人民币（语音5美金+Claude费用），而传统请老师上课约1万元 → **成本差50倍**
- 效果：模考从错14道到只错8道（满分5分，错14道是5分线） → **效果提升2-3倍**

> 💡 **关键洞察**：经过这件事，女儿对AI的威力"一下子特别清楚了"，对S的认可度也大幅上升。S的老婆也从"不用"到"上瘾"，开始自建知识库。

### 2.2 AI模拟述职：与广州老杨的真实演练

S用AI模拟了一场述职演练：
- 让AI先学习老杨的知识库
- AI每轮提问题前，先给S两个选项，并说明为什么这么问
- S选择方向后，AI继续追问

**AI的追问特点：**
- **问得很宽，也很细** — 老杨提到过三个店东，AI立刻追问细节，验证老杨是否真的掌握
- **不放过任何一点** — 发现老杨"四个模式"是设想而非实际案例，直接指出
- **给出深层建议** — 点出老杨的思维方式主要在解决问题，但广州新房领域"破题"才是未来关键

> 💡 **关键洞察**：S认为AI的判断力"比我强多了"，而且"问的问题藏在很深的地方"。

### 2.3 AI时代培训的底层变化

S提出了一个核心判断：

> **以前培训是功能不足时代的产物。** 学和练不得不分开（500人上课，讲师盯不过来；仿真条件不够；标准化导致信息丢失）。现在AI围着你走，完全个性化、即时反馈。

**传统培训 vs AI时代培训对比：**

| 维度   | 传统培训            | AI时代        |
| ---- | --------------- | ----------- |
| 学与练  | 分开（先学后练）        | 融合（边学边练）    |
| 反馈   | 延迟（练完等讲师点评）     | 即时（AI当场评判）  |
| 个性化  | 标准化（500人听一样的内容） | 完全个性化（围着你走） |
| 培训角色 | 课程供应商           | 赋能平台搭建者     |

> 📌 **S的原话**："你们以前干的所有方式，在我看来都是旧的。"

## 三、核心框架：4×7能力矩阵

### 3.1 消费者需要的不是"播报机"

S提出，消费者需要的不是信息播报机，而是能**理解处境、做出判断、提供路径、承担立场**的顾问型服务者。

### 3.2 四维能力

| 能力维度 | 含义 |
|----------|------|
| **理解（Understanding）** | 理解客户的处境、场景、真实需求 |
| **判断（Judgment）** | 帮客户筛掉不靠谱的选项，给出理由 |
| **路径（Path）** | 告诉客户下一步怎么走 |
| **立场（Stand）** | 时时刻刻跟客户站在一起，敢说"出了事我担着" |

### 3.3 七个业务阶段

买房全流程的七个关键阶段（信息查询 → 看房比较 → 谈判……）。

### 3.4 28个能力单元

四维能力 × 七个阶段 = **28个能力单元（格子）**。

> 📌 **S的要求**："培训应该在每个框里面怎么花功夫？理解、判断、路径、立场分别能干什么、不能干什么？如果在28个框里面能把这些东西搞出来，通过不同的形式、方式、方法，大家不就有路径了吗？"

## 四、服务者能力的四个层次

S用了一个"电脑硬件"的比喻来描述服务者的能力分层：

| 层次              | 比喻           | 表现                              |
| --------------- | ------------ | ------------------------------- |
| **第一层**-理解      | 内存16兆都不够     | 连基本信息都不知道，不想背                   |
| **第二层**-判断      | 内存到512兆了     | 能背出信息量，但只是播报                    |
| **第三层**-路径      | CPU不行 → 需要奔腾 | 不仅是背，还能给判断——"我建议你不选这几条路，原因是这样的" |
| **第四层**（最顶级）-立场 | 能承担责任        | "我建议你选A。出了事我担着。"靠信誉担，不是嘴上说      |

> 💡 **S的场景比喻**：你去医院问医生问题，医生说"等会，我翻翻书"——你会觉得不靠谱。中国消费者判断专业性，就是看你能不能"张口就来"。

## 五、关于培训变革的核心讨论

### 5.1 北链总监自媒体项目的冲击

小花（花桥学堂）提到，北京总监自媒体项目对培训团队的冲击很大——改变了原来的培训方式。

**S的回应方向：**
- "大概有个思路，去干。干完之后有什么点再跟大家聊"
- 培训实际上是"给他搭了一个场，让他在那玩"，关键是"持续让他受益的环境"
- **培训的角色**：制造氛围价值，就像唱卡拉OK，你唱的时候别人嗷嗷叫，你才有劲

> 📌 S明确说："你们原来干的方式一定要承认，那是旧的。"

### 5.2 AI使用节奏：从"先动起来"开始

小花提出一个实操问题：大家AI使用水平不同（没用过 → 聊天阶段 → 建了知识库当文档库用 → 在做训练），节奏怎么把握？

**S的三步建议：**

1. **第一步：被触动（邀请函）**
   - "体感来自于震惊" — 知识传递不了这种力量
   - 必须自己先被触动，才能传递给别人
   - "如果你从来没有被触动过，说明你还没有经历过"

2. **第二步：反观自我**
   - AI不是跟你PK的，也不是让你臣服的
   - "它是让你看到你还有很多种可能"

3. **第三步：燃起期待**
   - "我想成为一个更好的自己" → 所有东西都端正了

> 💡 **S的经典比喻**："烧水烧开了第一个泡，不代表只有一个泡，而是你已到99度，快到100度了。如果你连一个都煮不熟，然后说'我得让100个鸡蛋同时煮熟'，你的思维逻辑有问题。"

### 5.3 2.5%的先行者策略

- 只要有**2.5%的人先行动起来**就很好
- 目标可以设得很小：只要让一个人发生变化
- 让做得好的人影响下一波 → 正循环、正激励

### 5.4 "磨方"栏目计划

S提出一个具体方案：

> **栏目名**：「磨方」— 琢磨方法
> **频率**：每季度一期，共10期（到2028年10月）
> **形式**：每期3人，每人分享20分钟最佳实践 + 1小时圆桌对谈 + S分享1小时
> **第一期嘉宾**：北京明熹（AI工具）、队长（城市总队AI）、张刚（学院总监自媒体）
> **产出**：把过程中用到的工具方法打包成固定SKU，供下载使用

## 六、文化如何借助AI建设

### 6.1 宝倩的困惑

宝倩提出：培训场景可以用AI快速提效，但**文化怎么借助AI去建场**？一直没找到切入点。

### 6.2 S与AI关于"以消费者为中心"的深度对话

S分享了自己和AI的一段走心对话：

**AI追问S：**
1. "假设组织并没有因此活得更久，甚至更早死，你还做不做？"
2. "你把组织活下去和以消费者中心绑定了，如果抽掉这个前提呢？"
3. "不做组织越来越差，做了可能变好。你说的'必须做'，绕开了'愿不愿意'——就没有主动性的空间了"
4. "把组织活不活抽掉，只剩消费者在你经手的场景里面拿到评价权，此外什么都没有，你愿意做吗？"

**S最终回答：愿意。**

> 💡 **S的反思**：绕了三轮才说出"愿意"两个字本身，就说明了这件事的稀缺。"文化是活出来的，不是讨论出来的。"
>
> 📌 S的建议：不要让AI无成本输出一堆东西，而是**"逼AI把你内心里面的纠结逼出来"**。这才是AI应用的更高层次。

## 七、现场演示：客户沟通模拟演练

### 7.1 演练设置

- **经纪人**：宗飞（产品经理，第一次做业务模拟）
- **客户（AI扮演）**：宝倩扮演"张伟"，30岁程序员，首套房，预算500万，朝阳区
- **流程**：第一次见面沟通 → 宗飞复盘 → 客户（AI）点评反馈

### 7.2 宗飞复盘

宗飞自我评估：
- 建立了轻松愉快的信任关系
- 但忽略了核心实际问题（出资人是谁？隐形决策人还有谁？学区规划？）
- 预设了较长时间的交流，但实际信息量不多
- 对程序员客户而言，亲和力建立关系的方式可能不如高效精准更适配

### 7.3 S的点评

> **"先不问对不对，先能有一个就已经很不错了，这以前连这个都没有。"**

S强调：
1. 东西最后都会被内化成在场景下的**及时反应**
2. 分析模型可以想很多，但一对话就全靠当时的反应
3. **先启动第一步，再去迭代优化**

### 7.4 花桥ML课程的AI Role Play实践

花桥的ML课程已经尝试了"人跟AI的演练"：
- 三人一组：客户（带脚本）、经纪人、旁观者
- 使用5W1H和SPIN模型准备提问
- AI给出整体分析和评分
- 旁观者从自己视角提建议
- 扮演客户的人给出第一感受反馈
- 三个典型场景：首套刚需、置换改善、养老

## 八、Practice Box（练习箱）概念

S在演练基础上提出了一个具体的培训产品构想：

**核心概念**：一个物理的小隔间（类似卡拉OK包厢），经纪人进去后：
- **两块屏幕**：一块是AI对话客户，一块是AI观察者/导师
- **真实场景**：加载该经纪人所在商圈的真实客户通话记录、IM记录、在售房源
- **即时反馈**：练完当场评分，AI指出差距，给出Tips，可以重来
- **自评 + 他评**：5颗星自评 → AI评分 → 差距分析 → 建议改善 → 再来一遍
- **内容复用**：每次训练本身就在生产内容，可以线上复用
- **认证体系**：在4×7的28个模块中，逐个通关认证

> 📌 S说："以前你们要成立的是开发一个小Box……以后成为培训的标配。你进去之后，学、习、评全部完成。"
>
> **时间差消失了** — 当场学、当场习、当场评，没有以季度为单位的迭代周期。

## 九、其他重要讨论片段

### 9.1 个人成长 vs 组织能力

有人提出：服务于个人成长和服务于组织能力，如何取舍？

**S的回应：**
- "这个对立是极小的"
- "先干再说。你先把自己实力搞上去，搞完了如果你能让别人变强，那你就有能力"
- "你是为组织好？你看你搂着干，没怎么使劲。你使劲，那不得了，但又怕让组织完蛋"

> 💡 S尖锐地指出了一种常见陷阱：**"我是为组织好"的发心，实际上达成了阻碍组织变革的效果**。"你没有一个环节不合理，合理完之后结果达到了一个不合理的效果。"

### 9.2 AI是平权工具还是分化加速器？

有人担心AI会让强者更强，加速分化。

**S的回应：**
- "进步是以拉大方差为代价的。文明最大的问题是贫困"
- "不要想尾部赋能 — 你赋能，他本身就不想学、不想往长期发展"
- "渡有缘人" — 让好的变得更好
- "先想想怎么让做得好的人变得更好"

### 9.3 上海豪宅经纪人培训讨论

上海链家王浩平提出豪宅经纪人流失率超10%、市占下降5%的问题，想做基于板块的客户画像（20个画像/板块）。

**S的建议：**
- "向好的人学习" — 找做得最好的人，近身观察、记录、拆解
- 给新人"三个锦囊" — 具体到动作（如"前30天死磕三件事：10个标杆小区、30套房源、三类客户"）
- 锦囊要能用 — "你见到老师鞠躬，这个指令听完就能干"

### 9.4 培训价值是什么？

郑楠提出：培训到底要交付什么？如何评估培训的价值？

**多方观点汇总：**
- 小花：培训给了人**容错的机会** — 真实面对客户没有容错空间，但培训可以错了再复盘
- 袁磊：培训的最大价值是"帮解业务题"，不是教AI，是用AI解业务题
- 文娟：不再被困在教室里了 — "以往做课程、做讲师、做七件套，今天就发现大家不会干，这不就是培训机会吗？"
- 花桥：坚定"像训练AI一样去训练服务者" — 构建input、think、output三套系统

## 十、AI的本质与Context理论（S收尾）

### 10.1 AI的本质

S提问：AI大模型的本质是什么？

- 有人答"下一个概率" — S认可
- **S的答案："放大器" — 生产放大器**

### 10.2 Context（情境/上下文）理论

S提出了一个核心框架：

> **人和人之间的差别就是Context大小。** 你对行业的把握、对公司的理解、对业务的认知，构成了你的"概率云"。

- **Context越大、维度越多、质量越高** → 对世界的把握越真实 → 判断和行动的成功概率越高
- **AI时代最大的变化**：从"想到做"之间变容易了 — Context大的人的优势被极大放大
- **人的成长 = Context不断提升**（更真实、更善、更美）

### 10.3 培训的本质闭环

**传统培训路径：**
识别优秀 → 萃炼原因 → 形成概念 → 加工想象 → 命名传播 → 传递给他人 → 他人行动 → （循环极慢）

**AI时代培训路径：**
**学 → 习 → 评 → 形成差距 → 再学 → 再习 → 再评（高速旋转）**

> "时间在这个地方没有了。当场学，当场习，当场评，全部完成。"

## 十二、旁观者观察笔记

> 以下是整理者基于理解所做的标注，非原文内容。

### 🔴 需要关注的核心张力

1. **培训"为组织好"还是"让人变强"？** — S多次尖锐指出，"我是为组织好"可能变成阻碍变革的借口。培训团队应该"玩命让人变强"。

2. **追头部还是补尾部？** — S态度明确：让好的变得更好，不要在尾部耗费精力。"渡有缘人"。

3. **怕人变强就走了？** — S认为这不归培训管，归战略管。"培训的刀从来不出鞘，你说我是为组织好，所以搂着干"。
