# 0526_培训研讨收获总结

这次研讨不是一次普通培训交流，而是一次对“AI时代培训到底还怎么存在”的现场重构。

## 一句话总结

AI时代的培训，不再是简单把知识讲给人听，而是搭建一套让人在真实业务场景中扩大 Context场景/下上文、完成学-习-评闭环、最终变强的系统。

## 核心判断

### 1. 培训的本质没变，但方式变了

培训仍然解决“能力差距”问题，但过去是先学、再练、再反馈；现在AI让“学、习、评、改”可以在同一个场景里即时发生。

### 2. 学员从接受者变成设计者

过去学员只能听老师讲什么；现在每个人都可以基于自己的问题、场景和水平，让AI生成个性化内容、陪练、反馈和迭代。

### 3. 培训团队的新价值，是让人变强

不要过度纠结“组织能力 vs 个人成长”。培训团队最直接的目标，是让服务者、管理者和业务伙伴变得更强，让人成为更好的自己。

### 4. 能力提升的核心是扩大 Context

人与人的差异，本质是对行业、客户、业务、组织和场景的 Context 差异。AI时代，培训要帮助人扩大 Context，提高判断质量。

### 5. 消费者为中心，要落到服务者动作里

消费者为中心不是口号，而是让经纪人真正理解客户、给出判断、设计路径、承担立场。专业不是“背很多信息”，而是能帮客户判断、筛选、承担责任。

## 重要场景启发

### 1. AP考试案例

AI把知识变成播客、串讲、押题和情绪支持，说明学习内容可以高度个性化，成本大幅下降，体验大幅提升。

对培训的启发是：知识内容可以从“统一课件”转向“个性化生成”。例如每日要闻、业务思想、战略解读、知识卡片，都可以由讲师和培训团队结合AI设计成可听、可问、可练的内容。

### 2. AI模拟述职案例

AI可以追问细节、验证真实理解、识别未经验证的想法，适合管理者训练、业务复盘和战略项目推演。

### 3. 客户沟通演练案例

AI可以模拟客户、观察对话、即时反馈，训练需求挖掘、情绪理解和沟通判断。

### 4. Practice Box设想

花桥或城市可以建设“练习/认证小场”，让经纪人进入真实感场景，与AI客户演练，由AI导师点评，形成认证、内容和样板沉淀。

## 对贝壳培训的启发

### 1. 知识库仍然重要，但生产方式变了

新人训、融合训、行业知识、消费者理解，仍然需要知识底座。不同的是，这些知识不应只做成课程，而要进入AI知识库，变成可问、可听、可练、可测的学习资源。

### 2. 训练要围绕真实业务场景展开

客户深聊、商圈讲盘、豪宅客户画像、业主沟通、整装设计师工具使用、总监业务复盘，都应该变成真实任务和AI陪练场景。

### 3. 培训要从课程供应商转向赋能场景开发者

培训人要设计场景、任务、标准、反馈、激励和样板，而不是只组织课程、安排讲师、看满意度。

### 4. AI学习系统要尽快壳内化

大量客户录音、案例、知识库如果沉淀在外部工具里，会错过组织资产沉淀窗口。豌豆或内部AI学习系统要尽快承接录音、知识库、陪练、点评、案例沉淀。

### 5. 花桥的价值更清楚了

花桥不是简单集中上课，而是高质量场域：打破惯性、制造沉浸、让人下水完成第一次行动，同时沉淀Practice Box、认证场、样板场。

## 培训新模型

```text
真实业务场景
  -> 服务者行动
  -> AI记录与反馈
  -> 能力差距识别
  -> 个性化学习
  -> 再演练/再实战
  -> 业务结果验证
  -> 样板沉淀复制
```

## 下半年改进计划：以重点项目跑出AI时代培训新范式

0526研讨对下半年计划最大的校准是：不要只把它看成项目清单和资源安排，而要把它看成一次培训工作方式的重构。下半年要用重点项目跑出一套新的培训范式：从课程交付，转向真实场景中的学、习、评、激励闭环。

核心逻辑是：

```text
战略项目牵引
  -> 真实业务场景
  -> first sample
  -> AI陪练与反馈
  -> 学-习-评闭环
  -> 样板沉淀
  -> 城市复制
  -> 总部统筹资源和预算
```

### 1. 总部牵头 + BG共创重点项目

下半年第一批重点项目包括：北链总监板块专家、CAD/CA训战、惠居资管转型训战、整装设计师线上化工具认证。

其中，CAD/CA训战需进一步形成方案，并由S和峰岩决策；惠居资管转型训战已由博士确认；整装设计师线上化工具认证是整装战略项目中的一环，由文静推进。

这些项目不是单纯培训，而是AI时代培训转型的样板项目。每个项目都要明确真实业务场景、关键服务者动作、AI反馈方式、业务结果验证和样板沉淀。

### 2. BG业务解题项目

北上链家高端区域破局、大租赁、贝壳城市新房等方向具备业务价值，需要BG业务负责人先明确是否立项，以及培训从哪里发力。

先和业务一起回答三个问题：业务要打哪场仗，关键人群是谁，要改变哪些动作。培训的价值，是进入真实业务场，帮助业务找到first sample，并把样板做成可复制方法，不急着先做课程。

### 3. 经纪人专业化及新人训重塑

业务专题和新人训需要从“平台规则、交易知识、信息记忆”转向“消费者理解、专业判断、路径设计、责任立场”。

新人训不只是学知识，而要设计新人90天首单战训：用AI知识库解决基础认知，用AI陪练训练客户沟通，用真实任务推动带看、复盘和成交推进。专业化训练的重点，也要从“会背信息”转向“能帮客户做判断、筛选和承担责任”。

### 4. 讲师与培训人转型

讲师与培训人的转型，从课程供给者转向业务能力建设者。

讲师TGC要重新建立战略牵引，围绕“懂消费者、会用AI解题、有自我最佳实践”推动讲师M序列升级。讲师要先成为业务转型先锋，再成为教练：自己先用AI解业务题，再去辅导别人。

培训人也要同步转型。主线是：在重点项目中设计场景、任务、标准、反馈、激励和样板。

也就是把业务问题转成可训练场景，把能力要求拆成具体任务，把优秀动作定义成评价标准，把AI和教练反馈嵌入过程，把榜单、认证、曝光和资源倾斜设计成激励机制，最后把优秀实践沉淀成可复制样板。

### 5. AI学习系统

AI学习当前既缺内容缺乏有效的知识库，也缺AI系统、协同和运营机制，
下一步要同时解决知识库、AI学习，以及关键业务场景中的AI协同和机制。

系统不要先做大而全平台，而要陪跑重点项目长出来：从客户录音、案例转写、AI复盘、AI陪练、教练点评、能力认证、样板库中长出来。尤其要尽快把外部工具里的客户案例、练习样本和知识库壳内化，形成贝壳自己的组织资产。

### 6. 花桥基地

花桥当前需要进一步明确战略定位及资源投入。它不应只是集中培训场，而应成为战略项目战训场、Practice Box试验场、组织样板孵化场。

下半年花桥可以重点承接三类任务：

- **战略项目**：如惠居资管转型训战。
- **探索产品**：如ML产品，以及向北上链家内化。
- **关键人群**：如全国链家S、BL/ML等关键人群，围绕技能提升、文化价值观、情绪价值、被看见、表彰激励和季度交流形成场域产品。

同时探索超级经纪人孵化box、认证场、样板场，让线下场域真正服务于行为改变和样板沉淀。

### 7. 直管授权与资源统筹

业务培训COE需要直管授权，统筹下半年重点项目、关键人力和预算。否则培训转型会停留在局部创新，无法形成跨BG、跨城市、跨系统的组织级变革。

下半年要同步回答四件事：
重点/战略项目如何排序，关键组织能力如何沉淀，培训人如何在项目中成长，预算和人力资源如何匹配。

### 8. 两个必须补上的机制

第一是first sample机制。
每个重点项目必须先选2-3个first sample，明确对象、场景、任务、AI反馈、业务结果和复盘节奏。先把一个人、一类场景、一个动作跑透，再复制。

第二是学-习-评-激励闭环。
每个项目都要设计“学知识、练场景、AI和教练评价、识别gap、再回到个性化学习”的闭环，同时通过榜单、认证、曝光、资源倾斜建立动力机制。

一句话说，下半年要从“项目清单”升级为“用项目跑出新培训系统”。

## 最触动的点

最触动的不是“AI很厉害”，而是它逼着培训人重新回答一个根本问题：

> 如果知识可以被AI生成，练习可以被AI陪跑，反馈可以被AI即时完成，那培训人还创造什么价值？

答案是：培训人要让服务者变得越来越强，从而服务好消费者。

不是讲得更好，而是让人真的变强；不是课件更完整，而是让业务动作改变；不是培训存在感更强，而是让消费者体验更好、服务者能力更强、组织样板更多。

### 待办补充（26年下半年重点）

1，培训理念传播：花桥学堂业务培训年中会议，6-7-8月分三次推进，形成理念共识；
2，战略项目和业务专题：利用半年度预算的窗口，明确总部和BG重点项目，在真实业务场景中扩大 Context、完成学-习-评闭环；
3，推动基于AI的新人训：结合经纪人专业化内容+AI学习系统，推动新人训试点迭代，建立行业知识库，推动AI个性化学习，

7，北链总监项目时间窗口：6月8日-12日这周，先出日程，再问S。
