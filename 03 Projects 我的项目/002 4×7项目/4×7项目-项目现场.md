## 核心框架

### 4类能力（纵轴）

| 能力  | 本质             | 比喻    |
| --- | -------------- | ----- |
| 理解  | 读懂消费者的真实处境和需求  | 内存升级  |
| 判断  | 基于信息做出准确的分析和评估 | 处理器升级 |
| 路径  | 提供清晰可执行的解决方案   | 导航升级  |
| 立场  | 敢于承担责任，给出明确建议  | 顾问升级  |

### 7个流程（横轴）

**客户赛道**：C1寻找客户 → C2客户面访 → C3首看 → C4多看 → C5探盘 → C6正签 → C7售后

**业主赛道**：S1寻找业主 → S2获取委托 → S3初次面访 → S4深度面访 → S5带看反馈 → S6谈判正签 → S7售后

### 能力矩阵

4×7 = 每条赛道28个能力单元，双赛道合计56个能力单元

## 当前判断

**项目进展**：
- 刚接到的任务
- 里程碑待明确
- 正在出项目方案及规划
- **重庆共创流程已初步明确**

**重庆工作坊流程设计**（来自6.4访谈）：

| 阶段 | 内容 | 目的 |
|------|------|------|
| 1. 背景介绍 | 经纪人能力转型背景、S战略解读 | 统一认知起点 |
| 2. 7个阶段解读 | 消费者视角的7个流程、与业务流程的关系 | 理解"为什么是这7个" |
| 3. 四个能力介绍 | 理解/判断/路径/立场的定义 | 承接能力框架 |
| 4. 案例共创 | 选一个成交案例，基于4×7拆解 | 实战演练 |
| 5. 版本对比 | 各自产出能力图谱版本，对比优劣 | 形成共识版本 |

**共创思路**：
- 先给样本版本（降低从0到1的难度）
- 大家基于案例拆解
- 对比各版本优点
- 融合形成共识版本

**工作坊标题**：以消费者为中心的顾问型服务者能力探索

**团队分工**（来自脑暴会分析）：
- 金燕：方向+节奏+拍板
- 唐文莉：框架+机制+文档
- 邓鹏：翻译+验证+落地
- 马瓜瓜：质疑+免疫+前瞻

**三层分工建议**：
1. 信息整合收敛层：唐文莉（主）、马瓜瓜（质控）、邓鹏（翻译）、金燕（把关）
2. 运营推进层：金燕（主）、邓鹏（一线）、唐文莉（机制）、马瓜瓜（数据）
3. AI融入嫁接层：马瓜瓜（主）、唐文莉（整合）、金燕（决策）、邓鹏（验证）
