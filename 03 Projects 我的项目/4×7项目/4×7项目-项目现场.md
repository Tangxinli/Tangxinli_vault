## 项目定位

**定位**：构建经纪人服务能力体系

**核心问题**：我们知道经纪人哪里不行，但说不清"什么叫行"

**本质**：经纪人能力差距的扫描仪——让能力差距变得可见、可训练、可评价

## 核心框架

### 4类能力（纵轴）

| 能力  | 本质             | 比喻    |
| --- | -------------- | ----- |
| 理解  | 读懂消费者的真实处境和需求  | 内存升级  |
| 判断  | 基于信息做出准确的分析和评估 | 处理器升级 |
| 路径  | 提供清晰可执行的解决方案   | 导航升级  |
| 立场  | 敢于承担责任，给出明确建议  | 顾问升级  |

### 7个流程（横轴）— 消费者决策流程

**客户赛道**：动机形成 → 需求发育 → 聚焦收敛 → 精准匹配 → 签约成交 → 交付流程 → 售后服务

**业主赛道**：卖房动机 → 理解市场 → 确认方案 → 定价 → 售房追踪 → 确认价格 → 置换

### 能力矩阵

4×7 = 每条赛道28个能力单元，双赛道合计56个能力单元

## 当前判断

**项目进展**：
- 方案已进入v2.0版本
- 语言统一完成（理解/判断/路径/立场；消费者决策流程）
- 阶段性目标明确：共识框架 + 一个赛道 + 建立关系
- **重庆共创方案v2.0已输出**
- **工作坊课件v0.3已输出**

**v2.0核心变化**：

| 变化项 | v1.0 | v2.0 |
|--------|------|------|
| 流程框架 | 大S经纪人服务流程 | 消费者决策流程（客户/业主双赛道） |
| 阶段性目标 | 完整共识4×7 | 共识框架 + 一个赛道 + 建立关系 |
| 案例应用 | 未明确 | 混合模式：付振博示范 + 重庆案例共创 |
| 后续合作 | 未明确 | 多轮共创模式 |

**重庆共创阶段性目标**：

| 层面 | 目标 |
|------|------|
| 认知层面 | 理解框架逻辑（消费者决策流程 + 四类能力） |
| 产出层面 | 完成一个赛道的能力拆解雏形 |
| 关系层面 | 建立协作信任，约定后续合作方式 |

**共创思路**：
- 以消费者决策流程为主轴（避免经纪人陷入"动作思维"）
- 付振博案例作为示范样本（教方法）
- 重庆案例作为共创主体（实战产出）
- 阶段性目标，后续持续迭代

**工作坊标题**：以消费者为中心的顾问型服务者能力探索

**团队分工**（来自脑暴会分析）：
- 金燕：方向+节奏+拍板
- 唐文莉：框架+机制+文档
- 邓鹏：翻译+验证+落地
- 马瓜瓜：质疑+免疫+前瞻

**三层分工建议**：
1. 信息整合收敛层：唐文莉（主）、马瓜瓜（质控）、邓鹏（翻译）、金燕（把关）
2. 运营推进层：金燕（主）、邓鹏（一线）、唐文莉（机制）、马瓜瓜（数据）
3. AI融入嫁接层：马瓜瓜（主）、唐文莉（整合）、金燕（决策）、邓鹏（验证）
