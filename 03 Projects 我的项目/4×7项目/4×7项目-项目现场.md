## 核心框架

### 四层结构

| 层 | 回答的问题 | 工具 | 核心逻辑 |
|---|---|---|---|
| **L1** 矩阵 | 服务者知道要做什么？ | 4×7矩阵（28格） | 4类能力×7阶段=28个能力单元 |
| **L2** 水位 | 评估服务者做的有多好？ | 2D水位标尺 | Y轴(能力深度)×X轴(立场强度)，短板决定 |
| **L3** 根能力 | 为什么能做到？ | 8项底层能力 | 横切28格的根因 |
| **L4** 时间 | 长期能不能持续？ | 3D时间幅度 | Z1单次/Z2单单/Z3多年 + 成长曲线 |

**核心判断**：
- **L1+L2 = 做判断（诊断）**：做什么、做多好
- **L3+L4 = 出结论（处方）**：为什么好、能不能持续
- 光诊断不开方，萃取就是不完整的

### 4类能力（纵轴）

| 能力 | 本质 | 检验 |
|---|---|---|
| 理解 | 读懂消费者没说出口的 | 他说了什么客户没说出口的？ |
| 判断 | 给出明确结论，敢拍板 | 他有没有给"你应该选X"的判断？ |
| 路径 | 提供清晰可执行的下一步 | 客户走出后能复述"接下来三件事"吗？ |
| 立场 | 站在客户长期利益那边 | 有没有给过反向判断？ |

### 7个流程（横轴）— 消费者决策流程

**客户赛道**：动机形成 → 需求发育 → 聚焦收敛 → 精准匹配 → 签约成交 → 交付流程 → 售后服务

**业主赛道**：卖房动机 → 理解市场 → 确认方案 → 定价 → 售房追踪 → 确认价格 → 置换

### 框架通用 vs 内容本土

| 层 | 通用（不变） | 本土（变） |
|---|---|---|
| L1 | 28格结构 | 格内交付物、关键动作、案例 |
| L2 | Y轴/X轴定义、L1/L2/L3标准 | 城市经纪人典型分布比例 |
| L3 | 8项根能力定义和数量 | 哪些根能力是城市最缺的 |
| L4 | A/B/C三种曲线类型 | 具体经纪人的成长路径 |

## 当前判断

**聚焦方式演变**：
1. v0.3：聚焦1个格子（C2×判断）→ 看不到因果链
2. v0.4-v0.5：聚焦1个阶段4种能力 → 只做到L1+L2（诊断），缺L3+L4（处方）
3. v0.5+：**1个阶段四层跑通** → L1+L2深拆共创50min + L3快跑共创10min + L4引导者演示5min

**核心洞察**：L1+L2=做判断（诊断），L3+L4=出结论（处方）。光诊断不开方，共创就是不完整的。
