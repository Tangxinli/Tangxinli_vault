## 第一部分：以消费者为中心的解读

> **时间**：60分钟
> **形式**：讲授+小组讨论
> **核心问题**：消费者到底发生了什么变化？

### 1.1 时代背景

**S的战略判断**：

> "AI时代，消费者需要的不是信息播报机，而是能理解处境、做出判断、提供路径、承担立场的顾问型服务者。"

**为什么现在要提"以消费者为中心"？**

- AI工具正在取代经纪人的信息搜集与播报功能
- 消费者决策越来越复杂，越来越需要"有人帮我看懂、帮我选、帮我做"
- 经纪人的核心不可替代价值，在于**顾问型服务能力**

---

### 1.2 消费者变了

**【互动提问】**：大家最近遇到的最"难搞"的客户是什么样的？他为什么难搞？

---

#### 变化一：从"买到房"到"买对房"

过去消费者买房的核心诉求：买到房、卖出去。
- 上行周期，房少客多，买到就是赚到
- 经纪人的核心价值是**信息差**——我知道哪里有房，你不知道

现在消费者最怕的是：**买错**。
- 买家最怕几十万、上百万的损失
- 卖家最在意的是你有没有真正理解我这套房
- **信任成了新的稀缺资源**

---

#### 变化二：每个人买房，都是人生叙事的转折点

**【案例分享】**

| 消费者 | 表面需求 | 底层叙事 | 真正在买什么 |
|--------|----------|----------|--------------|
| 汪女士 | 婚前全款买房 | 保护叙事 | 不依附于任何人的安全感 |
| 袁姐 | 儿子婚房 | 分离叙事 | 下半生的自由，跟下一代拉开恰到好处的距离 |
| 李先生 | 国贸豪宅 | 身份叙事 | 配得感——我花了这么多钱，就该得到这些 |

**【关键洞察】**：
- 需求清单是表面的——600万预算、130平、哪个区域
- 但需求清单的更底层是**叙事类型**
- 理解客户的叙事类型，比需求清单重要100倍

---

#### 变化三：三种"为孩子买房"的人

看起来一样，底下藏了三种完全不同的人：

| 类型 | 底层逻辑 | 经纪人该怎么服务 |
|------|----------|------------------|
| 真刚需 | 孩子要上学了，必须买 | 方向明确，高效匹配 |
| 焦虑驱动 | "别人都买了，我是不是亏待了孩子" | 帮他确认"这个决定对不对" |
| 自身改善 | 现在的房子配不上对生活的想象 | 看到真实需求，不要被"孩子"误导 |

**三种人，用同一套方式接待，能成交吗？不可能。**

---

### 1.3 从信息播报机到顾问型服务者

**【讨论】**：如果消费者不再需要"信息"，他们需要什么？

**答案**：**决策支持**。

**旧世界 → 新世界**：

| 过去 | 未来 |
|------|------|
| 卖"房源信息" | "决策支持" |
| 管指标的管理者 | 懂消费者的专家 |
| 标准化复制 | 一线个性化 |
| 短期指标驱动 | 长期信任经营 |
| 数据里找答案 | 现场找答案 |

**核心问题**：
> 我们知道经纪人哪里不行，但说不清"什么叫行"——4×7要做的，就是把"行"的标准，拆进每一个真实的业务场景里。

---

**【小组讨论】**（10分钟）：
1. 你最近接待的客户，他的"叙事类型"是什么？
2. 你是怎么发现他的真实需求的？
3. 如果重来一次，你会问什么不同的问题？

## 第二部分：消费者决策流程拆解

> **时间**：60分钟
> **形式**：讲授+互动
> **核心问题**：消费者做决策，要经历哪些阶段？

### 2.1 为什么是7个阶段

**【引导问题】**：一个消费者从"想买房"到"买到房"，中间会经历什么？

**关键区分**：
- 我们熟悉的：经纪人作业流程（需求探访、约看、带看、谈判、签约）
- 今天要讲的：**消费者决策流程**

**为什么需要升维？**

以前我们关注的是"经纪人做什么"——动作、指标、流程。
今天我们要往上溯源——"消费者在这个阶段，在想什么、在纠结什么、需要什么支持"。

**7个阶段，是消费者做决策的7个关键节点**，不是经纪人的KPI节点。

---

### 2.2 客户赛道（C1-C7）

**买方视角的7个决策节点**：

| 节点 | 阶段名称 | 消费者在想什么 | 关键决策点 |
|------|----------|----------------|------------|
| C1 | 寻找客户 | "我该不该买房？买还是租？" | 是否进入市场 |
| C2 | 客户面访 | "我的真实需求是什么？预算够吗？" | 需求校准 |
| C3 | 首看 | "这房子给我的第一感觉对吗？" | 初步判断 |
| C4 | 多看 | "这几套怎么选？哪个更适合我？" | 比较筛选 |
| C5 | 探盘 | "这套房子到底值不值？有没有坑？" | 深度验证 |
| C6 | 正签 | "我确定了吗？会不会后悔？" | 最终决策 |
| C7 | 售后 | "买对了没有？以后还找不找他？" | 关系维系 |

---

**【互动】**：请大家回想最近一个成交客户，他在哪个阶段卡得最久？为什么？

---

### 2.3 业主赛道（S1-S7）

**卖方视角的7个决策节点**：

| 节点 | 阶段名称 | 消费者在想什么 | 关键决策点 |
|------|----------|----------------|------------|
| S1 | 寻找业主 | "现在该不该卖？找谁卖？" | 是否委托 |
| S2 | 获取委托 | "这个经纪人靠谱吗？签独家还是普通？" | 委托方式 |
| S3 | 初次面访 | "他能帮我卖多少钱？" | 预期管理 |
| S4 | 深度面访 | "我的房子有什么问题？怎么定价？" | 定价策略 |
| S5 | 带看反馈 | "市场反应怎么样？要不要降价？" | 价格调整 |
| S6 | 谈判正签 | "这个价格能接受吗？要不要再等等？" | 成交决策 |
| S7 | 售后 | "卖得对不对？以后还找他吗？" | 关系维系 |

---

### 2.4 与业务流程的关系

**【图示】**：

```
消费者决策流程（7个阶段）
    ↓ 指引
经纪人业务动作（做什么）
    ↓ 支撑
能力要求（怎么做）
```

**关键理解**：

1. **消费者决策流程是"为什么"**：解释经纪人为什么要做这些动作
2. **业务流程是"做什么"**：具体的动作和指标
3. **4×7是"怎么做"**：每个阶段需要什么能力

**【讨论】**：
- 你平时做的"面访"，是在完成指标，还是在帮业主做决策？
- 如果站在消费者视角，面访这个环节，他真正需要的是什么？

---

### 2.5 四类能力承接

在每个阶段，经纪人需要四类能力：

| 能力 | 本质 | 比喻 |
|------|------|------|
| **理解** | 读懂消费者的真实处境和需求 | 内存升级——能装更多信息 |
| **判断** | 基于信息做出准确的分析和评估 | 处理器升级——算得更快更准 |
| **路径** | 提供清晰可执行的解决方案 | 导航升级——知道怎么走 |
| **立场** | 敢于承担责任，给出明确建议 | 顾问升级——敢帮你做决定 |

**【关键提示】**：四类能力不是顺序递进的，同一场景下可以同时发生、相互支撑。

---

**【互动练习】**（10分钟）：

请选择一个你熟悉的阶段（如C2客户面访），回答：
1. 在这个阶段，"理解"能力具体指什么？
2. 如果经纪人只有"理解"没有"判断"，会怎样？
3. 如果有"判断"没有"立场"，消费者会怎么想？

## 第三部分：标杆案例拆解与共创

> **时间**：90分钟
> **形式**：小组共创
> **核心产出**：基于真实案例的4×7能力图谱雏形

### 3.1 共创设计思路

**为什么要共创？**

- 每个人从0到1是非常难的
- 看过一个样子，大概知道该怎么做，降低门槛
- 一版叠一版，越叠越好

**共创流程**：

```
案例呈现 → 小组拆解 → 版本呈现 → 对比讨论 → 形成共识
```

---

### 3.2 案例呈现（15分钟）

**【案例选择】**：选取一个真实的成交案例（建议提前准备）

**案例呈现要素**：
1. 客户/业主背景
2. 关键互动节点
3. 最终成交结果
4. 可复盘的关键决策点

**【引导话术】**：

> "现在请大家听这个案例。听的时候，请关注：
> - 消费者在每个阶段在想什么？
> - 经纪人做了什么动作？
> - 哪些动作是有价值的，哪些是例行公事？
> - 如果你是这个经纪人，你会怎么做？"

---

### 3.3 小组拆解（40分钟）

**分组规则**：
- 每组4-6人
- 建议混合不同岗位背景
- 选出记录员和汇报人

**拆解任务**：

**Step 1：还原流程（10分钟）**
- 这个案例经历了哪几个阶段？
- 每个阶段发生了什么关键互动？

**Step 2：能力拆解（20分钟）**
- 在每个阶段，经纪人展现了什么能力？
- 用"理解/判断/路径/立场"四类能力来拆解
- 填入下表：

| 阶段 | 理解 | 判断 | 路径 | 立场 |
|------|------|------|------|------|
| C1 | <!-- 经纪人做了什么 --> | | | |
| C2 | | | | |
| ... | | | | |

**Step 3：发现差距（10分钟）**
- 这个案例中，经纪人哪些能力做得好？
- 哪些能力有提升空间？
- 如果重来一次，可以怎么做更好？

---

### 3.4 版本呈现与对比（25分钟）

**呈现规则**：
- 每组5分钟汇报时间
- 展示你们的拆解版本
- 说明：哪个能力判断最有把握？哪个最难判断？

**对比讨论**：

**【引导问题】**：
1. 各组的版本有什么不同？
2. 哪一组的拆解方式最清晰？为什么？
3. 有没有争议点？为什么会有争议？

**【关键洞察】**：
- 每一版有每一版的好
- 这个版本的优点是什么？不足是什么？
- 我们要的共识版本，是融合各版优点

---

### 3.5 形成共识版本（10分钟）

**共识不是"统一答案"，而是**：
1. 对框架理解一致
2. 对争议点有讨论
3. 有可迭代的版本

**产出物**：
- 各组的拆解版本（留存对比）
- 共识版本的雏形
- 待讨论/待验证的问题清单

---

**【收束引导】**：

> "今天我们产出了几个版本。这不是终点，而是起点。
> 接下来我们会有更多案例、更多共创，不断迭代这个图谱。
> 每个人都可以在自己的工作中去验证、去补充。
> 这是大家一起建设的体系，不是总部发下来的标准答案。"

### 常见疑问回应

**Q：4×7是28门课吗？**
> 不是课程，是28个能力训练节点。"格子"才是训练对象，课程是填格子的手段之一。

**Q：四类能力是顺序学的吗？**
> 不是。同一场景下，四类能力可以同时发生、相互支撑。它们是能力的四个维度，不是线性学习顺序。

**Q：标准谁来定？**
> 标准必须来自一线真实场景和TOP经纪人的真实动作。这就是为什么要共创。

**Q：4×7做完是终态吗？**
> 不是。这是持续迭代的图谱，随业务场景、市场环境、消费者需求变化而更新。
