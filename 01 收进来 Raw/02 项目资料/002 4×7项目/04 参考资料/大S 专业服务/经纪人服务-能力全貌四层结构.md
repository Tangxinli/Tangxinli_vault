# 经纪人能力全貌：四层结构

> 一张能力地图回答不了所有问题。
> 不同的问题需要不同的视角——所以我们用四层结构看经纪人的能力，每一层回答一个不同的问题。

---

## 为什么要分四层

很容易把"能力"摊成一张大表，把所有要素塞进去——结果谁都看不懂。

四层不是平行的，是**四个不同的问题**：

| 层 | 工具 | 回答的问题 | 类比（医生） |
|---|---|---|---|
| **L1** | 4×7 矩阵 | 一个完整服务到底要做哪些事？ | 接诊 → 问诊 → 检查 → 诊断 → 处方 → 复诊 的全流程清单 |
| **L2** | 2D 水位标尺 | 这件事做得怎么样？ | 同样一个诊断，实习医生 vs 主治医生水位差在哪 |
| **L3** | 8 项底层能力 | 为什么有人就是做得好？ | 临床思维、沟通能力、共情力等根能力 |
| **L4** | 3D 时间幅度 | 长期看，这个人在不在变强？ | 五年之后这个医生有没有从主治长成主任 |

**先看 L1 知道做什么，再用 L2 量做得多好，钻进 L3 找根因，最后用 L4 看长期——四层各司其职。**

---

## L1：4×7 矩阵（内容地图）

> 回答："一个完整的房产经纪服务，要做哪些事？"

**四个维度**（纵向，做事的"套路"）：
- **视野**——看见客户没看见的（市场全景、可比盘、政策窗口）
- **判断**——给出有立场、有依据的明确结论
- **行动**——把判断落成具体的下一步
- **同盟**——不是技巧维度，是落点维度，决定前三个为谁服务

**七个阶段**（横向，时间流）：

```
1.需求摸底 → 2.看房带看 → 3.报价撮合 → 4.谈判 → 5.签约 → 6.签后服务 → 7.长期陪伴
```

四 × 七 = **28 个格子**，每格写清楚：交付物 / 关键动作 / 所需能力。

## L2：2D 水位标尺（评级框架）

> 回答："同样在做这件事，谁做得好？"

矩阵告诉你"做什么"，水位标尺告诉你"做到什么程度"。

**两条轴**：

- **Y 轴：能力深度**——视野（看得见）→ 判断（敢拍板）→ 行动（能落地）。从下往上，难度递增。
- **X 轴：立场强度**——同盟弱（信息中转）→ 同盟强（敢说违背成交利益的话）。从左往右，可信度递增。

二维平面上，**L1 ○ / L2 ● / L3 ★** 是三条等高线：

- **L1**：能搬运信息，看不见、不敢判、不站位
- **L2**：看得见、敢给判断，但路径模糊、立场温吞
- **L3**：判断锋利、路径具体、立场鲜明（敢说"别买"）

## L3：8 项底层能力（根能力）

> 回答："为什么 28 格里他每格都比别人做得好？"

矩阵里看到的是"行为"，水位看到的是"差距"——但行为和差距背后，是一组**横切所有 28 格**的根能力。

8 项底层能力（横向切穿矩阵）：

1. **信息提取力**——同样一段对话，能不能听出三个未说出口的需求
2. **结构化思考**——把杂乱信息组织成可推导的判断
3. **数据敏感度**——对价格、面积、单价、成交节奏有量级直觉
4. **承担判断的勇气**——敢说"建议 / 不建议"
5. **情绪共感**——读出客户犹豫背后的真实焦虑
6. **时间结构能力**——把模糊的"再聊"变成有节点的路径
7. **冲突中的中正**——业主买方利益冲突时不站偏
8. **诚实**——敢说违背自身短期利益的话

**这 8 项是"为什么 L3 是 L3"的真正答案。** 矩阵和水位是显性测量，根能力是隐性原因。

## L4：3D 时间幅度（成长曲线）

> 回答："五年后他是不是还在原地？"

前三层是"切片"——这一刻、这单生意里看一个经纪人的能力。
但能力是会变化的，**同一个人在不同时间尺度上有不同的样貌**：

- **单次接触**（一次面访 / 一次带看）——敢不敢给判断、能不能排路径
- **单单成交**（从需求到签约）——能不能贯穿七阶段、不掉链子
- **多年陪伴**（5 年 / 10 年）——客户回头率、口碑半径、案例积累深度

把时间轴叠加到 2D 水位上，得到一个 3D 模型——**Z 轴是时间**。

L3 的星标不是"一次做对"，而是**多年里持续做对**。

## 四层之间的关系

不是嵌套，不是平行——是**同一个对象的四种切法**：

```
            L4 时间幅度（看长期）
                  ↑
                  │
            L3 底层能力（钻根因）
                  ↑
                  │
            L2 水位标尺（量水平）
                  ↑
                  │
            L1 内容矩阵（看清单）
```

回答不同问题时，从不同的层进入：

| 你的问题 | 进入哪一层 |
|---|---|
| "这单子接下来要做什么？" | L1 矩阵 |
| "这个新人现在水平怎么样？" | L2 水位 |
| "他为什么总是缺一口气？" | L3 根能力 |
| "他能不能成为合伙人？" | L4 时间 |

---

## 一句话压缩

> **L1 看做什么，L2 看做多好，L3 看为什么做得好，L4 看长期能不能持续做好。**
