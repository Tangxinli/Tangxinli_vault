# 4×7群运营汇报-金燕

金燕，关于4×7群运营，我把思路理了一下，核心想法是：**4×7群运营和TGC不是两件事，合成一件事来做。**

---

## 为什么干：4×7和TGC是同一个飞轮

4×7是生产端（发现优秀→萃取案例），TGC是传播端（案例赋能→传播→激发更多优秀）。案例是连接器，讲师是连接人。

```
发现 → 萃取 → 赋能 → 传播 → 激发 → 发现
 ④✖️7管前两步    TGC管后两步    中间讲师用案例备课讲课
```

之前4×7产案例不知道怎么传播，TGC缺内容源靠讲师自发投稿。现在合成一个活动——讲师找标杆萃取，产出同时进4×7语料库和TGC传播渠道，**一套流程、一份产出、两个用途**。

---

## 干什么：让老师"找标杆聊一次天"，产出两种内容

老师操作就三步：**找标杆聊天 → 录音 → AI转化**。一份录音产出两种内容：

| 产出 | 用途 |
|------|------|
| ① 案主介绍+4×7框架整理 | 4×7语料 / 备课参考 / 讲师赋能 |
| ② 消费者服务故事 | TGC传播 / 视频号素材 / 案例集 |

---

## 怎么干

### 降低萃取门槛：7+2问题

给老师7个核心问题（按消费者决策旅程）+ 2个通用追问（捞判断和立场）。不需要全问，标杆先讲故事，聊到哪问到哪。

### 分两阶段

| | 阶段一（7月，立即启动） | 阶段二（8月+，联同泊宁） |
|---|---|---|
| 怎么转化 | 老师用AI提示词自行转化 | moma平台3种SKILL自动转化 |
| 老师门槛 | 中 | 低（上传录音即可） |
| 核心目标 | 跑通流程+收集语料 | 规模化+稳定产出 |

**阶段二3种SKILL**：
1. 萃取问题提示SKILL——不知道问什么时，SKILL告诉你要问什么
2. 录音→4×7框架SKILL——录音自动生成4×7矩阵案例整理
3. 录音→故事SKILL——案例转化成可读性高的服务故事+启发（读完有个收获，像读绘本）
