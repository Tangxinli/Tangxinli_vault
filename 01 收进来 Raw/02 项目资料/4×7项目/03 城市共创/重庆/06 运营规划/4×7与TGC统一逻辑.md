# 4×7与TGC统一逻辑

> 一句话：4×7是生产端，TGC是传播端，案例是连接器，讲师是连接人。
> 同一个飞轮，不是两个项目。

---

## 一、统一飞轮

```
          发现
         ↗    ↘
    激发        萃取
     ↑    飞轮    ↓
    传播        赋能
         ↖    ↙
```

| 环节 | 做什么 | 谁来做 | 产出 |
|------|--------|--------|------|
| **发现** | 找到身边优秀的服务者 | 讲师/商圈经理 | 标杆人选 |
| **萃取** | 和标杆聊一次，录音，AI转化 | 讲师（用萃取SKILL） | 案例整理+服务故事 |
| **赋能** | 讲师用案例备课/讲课/培训 | 讲师（用内容SKILL） | 课程/课件/训练场景 |
| **传播** | 案例和课程触达更多服务者 | TGC渠道（群/公众号/视频号/短剧） | 更多服务者被影响 |
| **激发** | 被影响的服务者中涌现新标杆 | 自然发生 | 回到"发现" |

**飞轮转起来的标志**：讲师找标杆萃取的案例，通过TGC传播后，被更多服务者看到，其中有人也成为标杆被下一个讲师发现——内容自驱动循环。

## 二、4×7和TGC不是两件事，是同一件事的两个面

| 维度     | 4×7视角          | TGC视角          | 统一后                              |
| ------ | -------------- | -------------- | -------------------------------- |
| **人**  | 找优秀服务者萃取       | 激活讲师产出内容       | 同一群人：讲师找标杆萃取 = 同时在做4×7和TGC       |
| **方法** | 萃取SKILL        | Skill赋能模式      | 同一套SKILL：萃取即生产，生产即赋能             |
| **内容** | 案例整理+4×7框架分析   | 服务故事+内容素材      | 同一份内容：4×7框架整理 = 备课参考，服务故事 = 传播素材 |
| **渠道** | 4×7群运营         | TGC公众号/视频号/糖果厂 | 同一渠道：4×7群 = TGC内容场               |
| **闭环** | 萃取→框架验证→产品化    | 产出→传播→激励→更多产出  | 同一个飞轮：发现→萃取→赋能→传播→激发→发现          |
| **目标** | 让服务者能力差距可见、可训练 | 让讲师内容有价值、能传播   | 让优秀服务的发现-萃取-传播形成自驱循环             |

## 三、从"两件事"变成"一件事"的落地方式

### 之前：分开做

```
4×7：找标杆→萃取→整理案例→验证框架→做产品
TGC：招募讲师→投稿→审核→发布→激励
```

两条线各做各的，4×7产出案例后不知道怎么传播，TGC缺内容源只能靠讲师自发投稿。

### 现在：合成一件事

```
讲师找标杆聊天（发现+萃取）
     ↓
录音→SKILL转化（一份录音，两种产出）
     ├── 4×7框架整理 → 备课参考 / 框架语料
     └── 服务故事     → TGC传播 / 视频号素材
     ↓
讲师用案例备课/讲课（赋能）
     ↓
群/公众号/视频号传播（传播）
     ↓
更多服务者被影响→涌现新标杆（激发→发现）
```

**关键变化**：投稿不再是一个独立动作，而是萃取的自然产出；内容不再需要另找渠道，萃取的产出本身就是TGC的内容源。

## 四、对运营的直接影响

| 之前 | 现在 |
|------|------|
| 4×7群运营和TGC投稿是两套体系 | 合成一个活动：「看见消费者」案例征集 |
| 老师参与4×7不知道产出有什么用 | 产出直接进入TGC传播，价值看得见 |
| TGC缺内容源，靠讲师自发投稿 | 4×7萃取产出 = TGC内容源，不缺素材 |
| 两套激励、两套流程、两套审核 | 一套流程、一份产出、两个用途 |
