# 4×7重庆群运营规划

> 版本：V1.0
> 最近修改时间：2026-06-29
> 本次更新依据：金燕群运营任务 + 文莉运营构想 + 萃取SKILL v0.3 + TGC运营经验
> 状态：候选

## 一、运营目标

**一句话**：让群里的老师愿意且能够"找身边优秀服务者聊一聊"，用萃取SKILL把聊天变成可用的案例内容，形成"发现→萃取→产出→传播"的闭环。

| 目标层 | 目标             | 衡量标准                  |
| --- | -------------- | --------------------- |
| 行为层 | 老师主动找标杆聊天并录音   | 月均3条录音投稿              |
| 内容层 | 产出结构化案例+服务故事   | 每条录音产出2份内容（案例整理+服务故事） |
| 生态层 | 群内形成自驱动的内容生产循环 | 不依赖文莉催稿，老师自发分享        |

**核心假设**：老师不做萃取不是因为不想，是因为"不会+觉得麻烦"。如果萃取变成"找标杆聊聊天+录个音"，SKILL自动产出内容，参与门槛就降下来了。

## 二、参与角色与分工

| 角色 | 人 | 职责 |
|------|-----|------|
| 运营主理 | 文莉 | 制定运营节奏、发布任务、审核内容、发放激励、迭代SKILL |
| 方向把控 | 金燕 | 方向判断、资源协调、关键时刻站台背书 |
| 参与老师 | 群内讲师/商圈经理 | 找标杆、聊标杆、录音投稿 |
| 标杆经纪人 | 各城市优秀经纪人 | 被访谈、分享真实服务案例 |

**老师的参与路径**：

```
Step 1：在身边找1位你认可的服务者（不要求top，只要你觉得"有一手"）
Step 2：约聊1次，用手机录音（30-60分钟即可）
Step 3：把录音发给文莉 / 输入萃取SKILL
Step 4：SKILL自动产出 → 老师确认/修改 → 发布
```

## 三、运营机制

### 3.1 抛砖引玉：冷启动策略

金燕6·22提出的核心策略：**不直接推任务，先抛Skill工具让老师觉得"我也可以试试"**。

| 周次 | 动作 | 目的 |
|------|------|------|
| 第1周 | 发一条萃取SKILL演示：放一段录音→SKILL自动产出案例整理+服务故事 | 让老师看到"原来这么简单" |
| 第2周 | 发第一份标杆案例的服务故事（高可读性版） | 让老师看到产出长什么样、有体感 |
| 第3周 | 正式发布投稿任务+激励规则 | 有了前面两轮铺垫，任务不突兀 |

### 3.2 每周运营节奏

| 节奏 | 内容 | 负责 |
|------|------|------|
| 周一 | 发布本周话题/方向引导（如"这周找一位你佩服的业主维护达人聊聊"） | 文莉 |
| 周中 | 群内互动：回答问题、鼓励晒录音、分享SKILL使用技巧 | 文莉 |
| 周五 | 本周产出汇总+表扬+下周预告 | 文莉 |
| 不定期 | 金燕站台：点评案例、分享方向思考、给标杆反馈 | 金燕 |

### 3.3 投稿流程

```
老师投稿流程：
  找标杆 → 聊天录音 → 发给文莉或直接输入SKILL → SKILL产出初稿 → 老师确认 → 发布

录音要求：
  - 时长：30-60分钟（不要太短，信息量不够）
  - 内容：请标杆讲1个ta印象最深的服务案例（从头到尾讲完一个故事）
  - 引导问题（不需要全问，按聊的方向自然展开）：
    ① 这个客户是什么情况？最需要什么？
    ② 你当时看到了什么客户没说出口的？
    ③ 你给客户什么建议？客户听了没有？
    ④ 你是怎么安排下一步的？
    ⑤ 有没有过客户想做的事你不让他做的情况？
```

### 3.4 凡星辰联动

金燕6·22提到：凡星辰已在视频号发起100天"看见消费者"内容分享活动，结构化思维好，可推动做4×7案例拆解。

| 联动方式 | 说明 |
|----------|------|
| 对齐节奏 | 文莉与凡星辰对齐100天活动的选题方向，引导往4×7案例靠 |
| 内容共享 | 凡星辰的分享内容可以同步到4×7群，作为示范案例 |
| Skill赋能 | 给凡星辰优先提供萃取SKILL，ta用好了就是活广告 |

## 四、萃取SKILL赋能方案

### 4.1 设计理念

**老师只需要做两件事：找人聊、录个音。剩下的事SKILL来做。**

当前萃取SKILL v0.3是面向课研团队的五步法（筛选→信息萃取→能力映射→水位判断→争议处理），对一线老师太重。群运营需要一个**轻量版SKILL**——老师输入录音，自动产出内容。

### 4.2 SKILL分层设计

| SKILL | 输入 | 产出 | 使用者 |
|-------|------|------|--------|
| **轻量萃取SKILL**（群运营用） | 录音/逐字稿 | ① 案主介绍+4×7矩阵案例整理 ② 消费者服务故事 | 参与老师 |
| **完整萃取SKILL**（v0.3，课研用） | 录音/逐字稿 | 完整五步法产出+水位判断+根能力标注 | 文莉/课研团队 |
| **服务故事SKILL**（新增） | 轻量萃取的案例整理结果 | 高可读性的消费者服务故事+服务道理/理念提炼 | 文莉/AI |

### 4.3 轻量萃取SKILL产出规范

**产出①：案主介绍+4×7矩阵案例整理**

| 板块 | 内容 |
|------|------|
| 案主介绍 | 姓名、城市、标签/专长、从业年限、核心特点（1-2句话） |
| 客户画像 | 家庭结构、决策背景、核心需求 |
| 案例概述 | 1-2句话概括案例全貌 |
| 4×7矩阵 | 按7阶段×4能力提取关键行为和原话（类似共创时填写的宫格格式） |
| 案例亮点 | 该案例中最值得学习的1-3个点 |

**产出②：消费者服务故事**

| 板块 | 内容 |
|------|------|
| 故事标题 | 从消费者视角提炼，如"那套所有人都说别买的房子" |
| 故事正文 | 800-1500字，以消费者体验为主线，高可读性叙事 |
| 服务道理 | 这个故事告诉我们什么？（1-3条服务理念或行为改变的底层方法） |
| 金句 | 标杆经纪人的1-2句原话，可独立传播 |

### 4.4 SKILL迭代路径

| 版本 | 时间 | 目标 |
|------|------|------|
| 轻量版V0.1 | 第1周发布前 | 基于现有v0.3简化，跑通录音→产出的基本流程 |
| 轻量版V0.2 | 第3-4周 | 基于前几条投稿反馈，调整产出格式和内容质量 |
| 轻量版V1.0 | 第6周 | 固化为老师可独立使用的稳定版本 |

## 五、内容产出标准

### 5.1 录音质量标准

| 维度 | 合格线 | 说明 |
|------|--------|------|
| 时长 | 30-60分钟 | 太短信息量不够，太长SKILL处理效率低 |
| 内容 | 讲完整1个案例（从客户接触到最终结果） | 不要求覆盖7阶段，但要有完整故事线 |
| 清晰度 | 人声可辨，无明显噪音 | 手机录音即可，不要求专业设备 |
| 真实性 | 标杆原话为主，不要"培训腔" | 越真实越好，不完美的地方恰恰是有价值的 |

### 5.2 案例整理质量标准

| 维度 | 标准 |
|------|------|
| 信息完整 | 案主+客户画像+案例概述+至少3个阶段的能力提取 |
| 有原话支撑 | 每个能力提取至少有1句标杆原话 |
| 有亮点 | 至少识别出1个值得学习的点 |
| 不强行填满 | 覆盖不到的阶段标"缺失"，不编造 |

### 5.3 服务故事质量标准

| 维度 | 标准 |
|------|------|
| 可读性 | 一线经纪人读得进去、读得懂 |
| 有共鸣 | 读者能代入消费者或经纪人的处境 |
| 有收获 | 读完后至少记住1个可借鉴的做法或理念 |
| 传播性 | 有金句、有标题感，适合群内/视频号转发 |
