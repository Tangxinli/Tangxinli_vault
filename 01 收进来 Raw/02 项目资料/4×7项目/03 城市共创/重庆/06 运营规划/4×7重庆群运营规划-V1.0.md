> 版本：V2.0
> 最近修改时间：2026-06-29
> 本次更新依据：V1.0 + 用户优化（两阶段运营、3种SKILL设计、萃取问题优化、激励调整）
> 状态：候选

## 一、运营目标

**一句话**：让群里老师愿意且能够找身边优秀服务者聊一聊真实的消费者服务案例，把聊天录音变成可用案例内容。

| 目标层 | 目标 | 衡量标准 |
|--------|------|----------|
| 行为层 | 老师主动找标杆聊天并录音 | 月均3条录音投稿 |
| 内容层 | 产出结构化案例+服务故事 | 每条录音产出2份内容（4×7框架整理+服务故事） |
| 生态层 | 群内形成自驱动的内容生产循环 | 不依赖文莉催稿，老师自发分享 |

**核心假设**：老师不做萃取不是因为不想，是因为"不会+觉得麻烦"。如果萃取变成"找标杆聊聊天+录个音+AI自动转化"，参与门槛就降下来了。

## 二、两阶段运营路径

### 阶段一：语料收集+人工AI转化（7月，立即启动）

**背景**：moma平台迭代需要1个月+，不等平台，先用AI提示词跑通流程。

| 维度   | 说明                               |
| ---- | -------------------------------- |
| 目标   | 收集优秀服务者语料，跑通"录音→AI转化→产出"的基本流程    |
| 老师操作 | 找标杆聊→录音→自行用AI转化（花桥给提示词）→产出确认     |
| 萃取方式 | 自我萃取（老师讲自己的案例）or 萃取别人（用萃取问题引导访谈） |
| 产出   | ① 案主介绍+4×7矩阵整理 ② 消费者服务故事         |
| 激励   | 贝壳币补贴                            |

**自我萃取流程**（老师讲自己的案例）：
```
老师自己录音 → 用花桥AI提示词转化 → 产出4×7框架整理+服务故事
```

**萃取别人流程**（老师访谈身边标杆）：
```
老师找标杆 → 按萃取问题引导访谈（全程录音） → 用花桥AI提示词转化 → 产出4×7框架整理+服务故事
```

### 阶段二：moma平台3种SKILL上线（8月+，联同泊宁）

**背景**：moma平台完成迭代，3种SKILL内置到平台，老师体验从"手动AI"升级为"一键转化"。

| 维度   | 说明                                 |
| ---- | ---------------------------------- |
| 目标   | 从人工AI提示词升级为平台内置SKILL，老师操作更简单，产出更稳定 |
| 老师操作 | 找标杆聊→录音上传moma→SKILL自动产出            |
| 产出   | 同阶段一，但质量和稳定性提升                     |
| 激励   | 贝壳币补贴逐步退坡，转向署名+案例集+M序列等长期激励        |

**两阶段对比**：

|      | 阶段一（7月）     | 阶段二（8月+）        |
| ---- | ----------- | --------------- |
| 录音转化 | 老师自行用AI提示词  | moma平台SKILL自动转化 |
| 萃取引导 | 文莉给萃取问题清单   | SKILL内置问题提示     |
| 产出质量 | 依赖老师AI使用能力  | 平台统一标准，质量稳定     |
| 老师门槛 | 中（需要会复制提示词） | 低（上传录音即可）       |
| 核心价值 | 跑通流程+收集语料   | 规模化+降门槛+稳定产出    |

## 四、萃取问题设计

### 4.1 设计思路：7个核心问题+2个通用追问

**为什么不用28个问题（7阶段×4能力）？**
- 28个问题像审讯，访谈人和被访谈人都会崩溃
- 4×7框架是课研的分析工具，不是访谈脚本
- 老师不是专业访谈者，问题太多会打断自然聊天节奏

**为什么7个问题够用？**
- 每个阶段1个核心问题，用大白话问，自然就能带出多个能力
- 理解和路径通常在讲故事时自然浮现，不需要专门追问
- 判断和立场是最难自然浮现的，用2个通用追问专门捞

**7+2的逻辑**：7个问题按消费者决策旅程走，聊完就是一个完整故事；2个通用追问兜底，确保判断和立场不被遗漏。

### 4.2 萃取问题清单

**7个核心问题**（按消费者决策旅程）：

| 阶段      | 核心问题                               | 主要带出的能力  |
| ------- | ---------------------------------- | -------- |
| C1 动机形成 | 客户一开始找你的时候，表面上说的是什么？你感觉ta真正想要的是什么？ | 理解       |
| C2 需求发育 | 客户说的需求和真正需要的，有没有不一样的时候？你是怎么发现的？    | 理解→判断    |
| C3 聚焦收敛 | 帮客户缩小选择范围的时候，你给过什么明确建议？客户听了吗？      | 判断→路径    |
| C4 精准匹配 | 推荐房子的时候，你有没有推荐过客户没想到但特别合适的？怎么想到的？  | 理解→判断→路径 |
| C5 签约成交 | 客户犹豫的时候，你是怎么帮ta做决定的？               | 判断→立场    |
| C6 交付流程 | 签完合同之后，你做了哪些让客户觉得"选你没错"的事？         | 路径→立场    |
| C7 售后服务 | 成交之后你还跟这个客户有联系吗？ta现在还找你吗？为什么？      | 立场       |

**2个通用追问**（任何阶段觉得聊得不够深时追问）：

| 追问                      | 目的    | 带出的能力        |
| ----------------------- | ----- | ------------ |
| 有没有过客户想做的事，你建议ta不要做的情况？ | 捞立场   | 立场（X3：敢说不）   |
| 你给客户的建议，客户后来照做了吗？结果怎么样？ | 捞判断链路 | 判断→路径（因果链验证） |

### 4.3 使用建议

- **不需要全问**：让标杆先讲自己印象最深的故事，问题只是聊不下去时补充用的
- **先听故事再追问**：标杆讲完一个完整故事后，对照7个问题看哪些阶段还没聊到，再追问
- **大白话优先**：不要用"理解/判断/路径/立场"这些框架术语问，用上面的大白话版本
- **追问判断和立场**：这两个最容易在故事里被跳过，记得用2个通用追问捞

## 五、3种SKILL设计方案（阶段二，联同泊宁开发）

### 5.1 整体架构

```
录音上传 moma
    │
    ├→ SKILL① 萃取问题提示SKILL ──→ 帮老师更深度地萃取标杆
    │
    ├→ SKILL② 录音→4×7框架SKILL ──→ 录音直接生成4×7矩阵案例整理
    │
    └→ SKILL③ 录音→故事SKILL ──→ 案例表述转化为可读性高的服务故事+启发
```

### 5.2 SKILL①：萃取问题提示SKILL

| 维度 | 说明 |
|------|------|
| 定位 | 访谈时的"问题导航"，帮老师更深度地萃取标杆 |
| 输入 | 老师选择访谈场景（自我萃取/萃取别人）+ 客户类型（自住/投资/业主端） |
| 产出 | 针对性萃取问题清单（基于7+2核心问题，按场景和客户类型个性化调整） |
| 核心价值 | 降低老师的访谈压力——不知道问什么的时候，SKILL告诉你要问什么 |

**个性化示例**：
- 选择"萃取别人+投资型客户"→ 追问C1："投资型客户嘴上说看回报率，你感觉ta真正在意的是什么？"
- 选择"自我萃取+业主端"→ 追问C6："业主交房后，你做了哪些让业主觉得'有你在就放心'的事？"

### 5.3 SKILL②：录音→4×7框架SKILL

| 维度 | 说明 |
|------|------|
| 定位 | moma后台转换引擎，录音直接生成4×7框架案例整理 |
| 输入 | 访谈录音/逐字稿 |
| 产出 | 案主介绍 + 客户画像 + 7阶段×4能力提取（关键行为+原话）+ 案例亮点 |
| 核心价值 | 老师不需要理解4×7框架，上传录音就能得到结构化整理 |

**产出格式**：

| 板块 | 内容 |
|------|------|
| 案主介绍 | 姓名、城市、标签/专长、从业年限、核心特点 |
| 客户画像 | 家庭结构、决策背景、核心需求 |
| 案例概述 | 1-2句话概括案例全貌 |
| 4×7矩阵 | 7阶段×4能力，每格提取关键行为+原话 |
| 案例亮点 | 该案例中最值得学习的1-3个点 |

### 5.4 SKILL③：录音→故事SKILL

| 维度 | 说明 |
|------|------|
| 定位 | 将案例表述转化为高可读性的服务故事，像给宝宝读绘本——一个故事讲完，读完有个启发 |
| 输入 | 访谈录音/逐字稿 或 SKILL②产出的4×7框架整理 |
| 产出 | 故事标题 + 故事正文（800-1500字）+ 这个故事告诉服务者的启发 + 金句 |
| 核心价值 | 让一线经纪人读得进去、读得懂，读完记住1个可借鉴的做法 |

**产出格式**：

| 板块 | 内容 |
|------|------|
| 故事标题 | 从消费者视角提炼，如"那套所有人都说别买的房子" |
| 故事正文 | 800-1500字，以消费者体验为主线，高可读性叙事 |
| 启发 | 这个故事告诉服务者什么？（1-3条服务理念或行为改变的底层方法） |
| 金句 | 标杆经纪人的1-2句原话，可独立传播 |

| 时间 | 交付 | 负责 |

## 六、内容产出标准

### 6.1 录音质量标准

| 维度 | 合格线 | 说明 |
|------|--------|------|
| 时长 | 30-60分钟 | 太短信息量不够，太长SKILL处理效率低 |
| 内容 | 讲完整1个案例（从客户接触到最终结果） | 不要求覆盖7阶段，但要有完整故事线 |
| 清晰度 | 人声可辨，无明显噪音 | 手机录音即可，不要求专业设备 |
| 真实性 | 标杆原话为主，不要"培训腔" | 越真实越好，不完美的地方恰恰是有价值的 |

### 6.2 4×7框架案例整理标准

| 维度 | 标准 |
|------|------|
| 信息完整 | 案主+客户画像+案例概述+至少3个阶段的能力提取 |
| 有原话支撑 | 每个能力提取至少有1句标杆原话 |
| 有亮点 | 至少识别出1个值得学习的点 |
| 不强行填满 | 覆盖不到的阶段标"缺失"，不编造 |

### 6.3 服务故事质量标准

| 维度 | 标准 |
|------|------|
| 可读性 | 一线经纪人读得进去、读得懂 |
| 有共鸣 | 读者能代入消费者或经纪人的处境 |
| 有启发 | 读完记住1个可借鉴的做法或理念 |
| 传播性 | 有金句、有标题感，适合群内/视频号转发 |

## 七、激励体系

### 7.1 贝壳币激励方案

| 行为 | 贝壳币 | 说明 |
|------|--------|------|
| 提交有效录音 | 50币/条 | 投稿即得，降低参与门槛 |
| 案例整理产出确认（两种内容） | +50币，共100币 | 4×7框架整理+服务故事各确认一份 |
| 被评为「精选案例」 | +100币 | 文莉评选，标杆案例重点激励 |
| 月度优质案例Top1-3 | +200币/条 | 文莉+金燕评选 |

**月预算估算**：假设5人参与，月均2000贝壳币

### 7.2 非贝壳币激励

| 激励 | 说明 |
|------|------|
| 花桥公众号/视频号公示 | 优质案例在花桥官方渠道展示 |
| 案例成果署名 | 案例和服务故事署名萃取老师+标杆经纪人 |
| M序列讲师优先推荐 | 优质投稿老师优先纳入M序列候选 |
| 案例集出版署名 | 优质案例进入案例集，萃取老师作为贡献者署名 |

### 7.3 激励设计原则

1. **投稿门槛要低**：录音合格就给贝壳币，不要求产出完美
2. **质量激励要够**：精选案例+月度Top额外激励，拉开差距
3. **长期价值要看得见**：署名+案例集+M序列，让老师知道这事不只是贝壳币

## 八、案例内容的应用路径

案例产出后不是归档，而是进入四条应用路径：

| 优先级 | 应用路径 | 用途 | 具体方式 | 阶段 |
|--------|----------|------|----------|------|
| 1 | **4×7研究语料** | 框架验证和迭代 | 案例作为4×7的研究范本和干净语料，支撑框架优化和水位校准 | 持续进行 |
| 2 | **备课参考** | 产品上课时老师找案例 | 给案例打标签（客户类型/阶段/能力/行业），老师按标签检索匹配案例 | 近期可落地 |
| 3 | **讲师赋能** | 培养讲师时教"怎么结合案例来讲授" | 案例整理成集，讲师组伙伴在讲师赋能时使用 | 中期（案例积累≥20条后） |
| 4 | **TGC内容持续生产** | 讲师内容价值飞轮 | 真实服务故事是「老左奖学金主题营」「4×7项目」「TGC内容生产」的主线；后期探索短视频/短剧形式，将服务理念和方法从花桥课堂延伸到花桥之外 | 中长期 |

### 8.1 标签体系设计（备课参考）

| 标签维度 | 标签示例 |
|----------|----------|
| 客户类型 | 投资型/自住型/置换型/业主端 |
| 核心阶段 | C1动机/C2需求/C3聚焦/C4匹配/C5签约/C6交付/C7售后 |
| 亮点能力 | 理解突破/反向判断/创意路径/强立场/微行动信任 |
| 服务类型 | 新房/二手/租赁/豪宅/刚需 |
| 城市级别 | 一线/新一线/二线/三线 |
| 案例特征 | 争议型/反转型/长期陪伴型/单次突破型 |

### 8.2 案例集规划

| 节点 | 规模 | 形式 |
|------|------|------|
| 10条案例 | 第一册初稿 | 内部PDF，讲师组内部分享 |
| 20条案例 | 第一册正式版 | 按标签分类，含使用指引 |
| 50条案例 | 多册+数字化 | 可检索案例库，支持按标签筛选 |

### 8.3 多元呈现形式探索（中长期）

| 形式 | 说明 | 价值 |
|------|------|------|
| 服务故事图文 | 当前基础形式 | 群内传播、备课参考 |
| 短视频/短剧 | 将消费者服务故事拍成1-3分钟短剧 | 延伸课堂到课外，触达更多服务者 |
| 视频号内容 | 与凡星辰100天活动结合 | 扩大4×7理念传播面 |
| 绘练场景 | 案例转化为训练场景 | 从"看案例"到"练案例" |
