## 正面：四层结构 + 7阶段 + 4能力 + 因果链

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  经纪人顾问型服务能力体系 · 速查卡
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【四层结构】

  L1 矩阵 → 要做哪些事？
  L2 水位 → 做得多好？
     ↕ L1+L2 = 做判断（诊断）
  L3 根能力 → 为什么做得好？
  L4 时间 → 长期能不能持续？
     ↕ L3+L4 = 出结论（处方）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【消费者决策流程（7阶段）】

  客户：动机形成 → 需求发育 → 聚焦收敛
        → 精准匹配 → 签约成交 → 交付流程 → 售后服务

  业主：卖房动机 → 理解市场 → 确认方案
        → 定价 → 售房追踪 → 确认价格 → 置换

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【四类能力】

  理解（Y1）：读懂消费者没说出口的
  判断（Y2）：给出明确结论，敢拍板
  路径（Y3）：提供清晰可执行的下一步
  立场（X轴）：站在客户长期利益那边

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【因果链 + 立场底色】

  理解→判断→路径 = 因果链（断了任何一个都不完整）
  立场 = 底色（横切每一格，每一格都在表达"我站谁"）

  只理解不判断 = 白看
  只判断没路径 = 空判
  有判断没立场 = 温吞

  最锋利的检验：敢不敢给反向判断

  L1+L2 = 做判断（诊断：做什么+做多好）
  L3+L4 = 出结论（处方：为什么好+能不能持续）
  光诊断不开方 = 不完整

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 背面：水位标尺 + 短板决定 + 8项根能力

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  水位标尺 · 速查卡（背面）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【2D水位标尺】

  Y轴（能力深度）：Y1理解 → Y2判断 → Y3路径
  X轴（立场强度）：X1中转 → X2中性 → X3立场鲜明

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【三步判断法】

  第一步 Y轴：能力深度到哪？
    Y1 看见客户没看见的
    Y2 给出明确结论
    Y3 提供可执行下一步

  第二步 X轴：立场强度到哪？
    X1 中转——传话筒，"您再看看"
    X2 中性——摆利弊，"A优点B缺点"
    X3 立场——敢说违背自身利益的话

  第三步 综合 = min(Y, X) 短板决定！

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【三个水位】

  L1 ○  任意一维最低
     Y3+X1=仍L1（视野好但不敢站=没站）
     Y1+X3=仍L1（瞎热情比冷漠更坑）
     → "您看这两个都不错"

  L2 ●  两维都至少中段
     看得见+敢判断，但立场温吞
     → "我觉得您更适合这个"

  L3 ★  两维都到顶端
     因果链完整+立场鲜明+敢说不
     → "你要的不是复式，是带院子的别墅"

  数据：578案例中 68% L1 / 32% L2 / <1% L3

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【8项根能力】

  ① 信息提取力  ② 结构化思考  ③ 数据敏感度
  ④ 承担判断的勇气  ⑤ 情绪共感  ⑥ 时间结构能力
  ⑦ 冲突中的中正  ⑧ 诚实

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【3D时间幅度】

  Z1 单次接触 — 一次客户互动
  Z2 单单成交 — 整个交易周期
  Z3 多年陪伴 — 多个交易周期

  成长曲线：A 稳定型 / B 上行型 / C 下沉型

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 使用说明

**发放时机**：开场前放在每人桌面

- 全程放在桌面，随时查阅

- A5双面打印，正面四层+7阶段+4能力+因果链，背面水位+短板决定+根能力+时间
- 过塑处理，耐用且可重复使用
