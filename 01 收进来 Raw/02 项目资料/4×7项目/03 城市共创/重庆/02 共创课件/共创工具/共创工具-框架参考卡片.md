## 正面：四层结构 + 7阶段 + 4能力

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  经纪人顾问型服务能力体系 · 速查卡
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【四层结构】

  L1 矩阵 → 要做哪些事？
  L2 水位 → 做得多好？
  L3 根能力 → 为什么做得好？
  L4 时间 → 长期能不能持续？

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【消费者决策流程（7阶段）】

  客户：动机形成 → 需求发育 → 聚焦收敛
        → 精准匹配 → 签约成交 → 交付流程 → 售后服务

  业主：卖房动机 → 理解市场 → 确认方案
        → 定价 → 售房追踪 → 确认价格 → 置换

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【四类能力】

  理解：读懂消费者没说出口的
  判断：给出明确结论，敢拍板
  路径：提供清晰可执行的下一步
  立场：站在客户长期利益那边

  关系：理解→判断→路径 = 因果链
       立场 = 底色（每一格都在表达"我站谁"）
  最锋利的检验：敢不敢给反向判断

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 背面：水位标尺 + 8项根能力

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  水位标尺 · 速查卡（背面）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【2D水位标尺】

  Y轴（能力深度）：理解 → 判断 → 路径
  X轴（立场强度）：中转 → 中性 → 立场鲜明

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【三个水位】

  L1 能搬运信息，不敢判、不站位
     → "您看这两个都不错"

  L2 看得见、敢判断，但立场温吞
     → "我觉得您更适合这个"

  L3 判断锋利、路径具体、立场鲜明
     → "你要的不是复式，是带院子的别墅"

  数据：578案例中 68% L1 / 32% L2 / <1% L3

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【8项根能力】

  ① 信息提取力 — 从信息中听出没说出口的
  ② 结构化思考 — 把模糊需求拆成可判断的结构
  ③ 数据敏感度 — 用数据支撑判断
  ④ 承担判断的勇气 — 敢给结论，敢担风险
  ⑤ 情绪共感 — 感知客户没表达的情绪
  ⑥ 时间结构能力 — 看见决策的时间约束
  ⑦ 冲突中的中正 — 两件事矛盾时不回避
  ⑧ 诚实 — 说不出口的真话，说了

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  【3D时间幅度】

  Z1 单次接触 — 一次客户互动
  Z2 单单成交 — 整个交易周期
  Z3 多年陪伴 — 多个交易周期

  成长曲线：A 稳定型 / B 上行型 / C 下沉型

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 使用说明

**发放时机**：开场前放在每人桌面
**使用方式**：
- 全程放在桌面，随时查阅
- 第三部分讲解框架时对照看
- 第四部分共创时对照填
- 引导者提到术语时，参与者可自行翻阅

**打印建议**：
- A5双面打印，正面四层+7阶段+4能力，背面水位+根能力+时间
- 过塑处理，耐用且可重复使用
