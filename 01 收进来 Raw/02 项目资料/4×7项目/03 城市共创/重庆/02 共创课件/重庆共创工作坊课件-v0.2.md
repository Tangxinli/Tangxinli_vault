>

>
> 这个名字有点长，但每个词都很重要：
> - 以消费者为中心：是我们这次变革的起点
> - 顾问型服务者：是经纪人未来的方向
> - 能力探索：我们今天要做的事
>
> 今天不是来听课的，是来共创的。我们想借着今天的讨论，一起探索：**到底什么叫'能力好'？怎么把'好'拆解成可见、可训练、可评价的标准？**"

### 背景介绍

> "先说说为什么要做这件事。
>
> 今年S提出一个核心判断：**AI时代，消费者需要的不是信息播报机，而是顾问型服务者。**
>
> 什么是信息播报机？就是只会告诉你'这套房子多少钱、多大面积、哪个小区'。
> 什么是顾问型服务者？是能帮你理解处境、做出判断、提供路径、承担立场的人。
>
> 我们花桥学堂接到的命题是：构建经纪人的底层能力体系。
>
> 但我们发现一个问题——**我们知道经纪人哪里不行，但说不清'什么叫行'。**
>
> 今天的工作坊，就是想和大家一起，把这个'什么叫行'说清楚。"

## 第一部分：以消费者为中心的解读

> **时间**：40分钟
> **核心问题**：消费者到底发生了什么变化？

### 1.1 消费者变了（15分钟）

**【互动提问】**：大家最近遇到的最"难搞"的客户是什么样的？他为什么难搞？

---

**变化一：从"买到房"到"买对房"**

| 过去 | 现在 |
|------|------|
| 买到就是赚到 | 最怕买错 |
| 信息差是核心竞争力 | **信任成了新的稀缺资源** |
| 经纪人价值：我知道哪里有房 | 经纪人价值：**帮我做决策** |

---

**变化二：每个人买房，都是人生叙事的转折点**

**【案例】三种"为孩子买房"的人**：

| 类型   | 表面需求 | 底层逻辑       | 经纪人该怎么服务         |
| ---- | ---- | ---------- | ---------------- |
| 真刚需  | 孩子上学 | 必须买        | 方向明确，高效匹配        |
| 焦虑驱动 | 孩子上学 | 怕亏待孩子      | 帮他确认"这个决定对不对"    |
| 自身改善 | 孩子上学 | 现在的房子配不上生活 | 看到真实需求，不要被"孩子"误导 |

**三种人，用同一套方式接待，能成交吗？不可能。**

---

### 1.2 顾问型服务者的核心能力（10分钟）

**【关键问题】**：如果消费者不再需要"信息"，他们需要什么？

**答案：判断 + 路径**

| 经纪人类型 | 客户离开时拿到什么 |
|------------|-------------------|
| 信息播报机 | "这套房子多少钱、多大面积" |
| 顾问型服务者 | **一个明确判断 + 一组可执行的下一步** |

**最锋利的检验**：
> 能不能给出**反向判断**——"这套别买""这个价格别出""现在别卖"

---

### 1.3 小组讨论（10分钟）

**讨论问题**：
1. 你最近接待的客户，他的"叙事类型"是什么？
2. 你有没有给过客户"反向判断"？结果怎样？
3. 如果重来一次，你会怎么服务这个客户？

---

### 1.4 过渡

> "刚才我们讨论了'消费者变了'，也讨论了'顾问型服务者需要什么能力'。
>
> 接下来，我们要进入今天的核心内容：**用一套框架，把这些能力拆解清楚。**"

---

## 第二部分：消费者决策流程 + 能力框架

> **时间**：50分钟
> **核心产出**：理解"消费者视角 × 能力要求"的对应关系

### 2.1 为什么需要框架？（5分钟）

**一个核心问题**：

> 我们知道经纪人哪里不行，但说不清"什么叫行"。

**框架的作用**：
- 把"能力好"拆解成**可见、可训练、可评价**的标准
- 让能力差距变得**可定位、可诊断**

---

### 2.2 四层结构：看能力的四个视角（10分钟）

**大S框架的核心洞察**：一个问题一张表，摊平了谁都看不懂。

| 层      | 回答的问题    | 工具         | 一句话  |
| ------ | -------- | ---------- | ---- |
| **L1** | 要做哪些事？   | 4×7矩阵（28格） | 看做什么 |
| **L2** | 做得怎么样？   | 2D水位标尺     | 量做多好 |
| **L3** | 为什么做得好？  | 8项底层能力     | 找根因  |
| **L4** | 长期能不能持续？ | 3D时间幅度     | 看成长  |

**今天重点讲L1**：4×7矩阵——"一个完整的房产经纪服务，要做哪些事？"

---

### 2.3 4×7矩阵：四个能力维度（10分钟）

**四个维度（纵向）**：

| 维度 | 含义 | 因果关系 |
|------|------|----------|
| **视野** | 看见客户没看见的 | 最底层，视野缺位→上层一定塌 |
| **判断** | 给出有立场的明确结论 | 在视野基础上敢拍板 |
| **行动** | 把判断落成具体下一步 | 判断的落地 |
| **同盟** | 站在谁那边 | 横切所有格的底色 |

**关键理解**：
- 视野→判断→行动是**因果链**（看见才能判断，判断才能行动）
- 同盟是**底色**（每一格都在表达"我站谁"）

---

### 2.4 4×7矩阵：七个服务阶段（10分钟）

**客户赛道（C1-C7）**：

| 阶段      | 消费者在想什么    | 关键决策点  |
| ------- | ---------- | ------ |
| C1 寻找客户 | 我该不该买房？    | 是否进入市场 |
| C2 客户面访 | 我的真实需求是什么？ | 需求校准   |
| C3 首看   | 这房子给我什么感觉？ | 初步判断   |
| C4 多看   | 这几套怎么选？    | 比较筛选   |
| C5 探盘   | 这房子值不值？    | 深度验证   |
| C6 正签   | 我确定了吗？     | 最终决策   |
| C7 售后   | 买对了没有？     | 关系维系   |

---

### 2.5 核心工具：消费者视角 × 能力要求对照表（10分钟）

**把"消费者在想什么"和"经纪人需要什么能力"对应起来**：

| 阶段 | 消费者在想什么 | 视野 | 判断 | 行动 | 同盟 |
|------|----------------|------|------|------|------|
| C1 寻找客户 | 我该不该买房？ | 判断客户真伪 | 识别购房动机 | 提供决策依据 | 中性起点 |
| C2 客户面访 | 我的真实需求是什么？ | 听出未说出口的 | 需求排序 | 看房计划 | 站在真实需求一边 |
| C3 首看 | 这房子给我什么感觉？ | 房源全息扫描 | 这套合不合适 | 下一步安排 | 敢说"别买" |
| ... | ... | ... | ... | ... | ... |

**【互动】**：请选择一个阶段，尝试填写这四类能力。

---

### 2.6 过渡

> "刚才我们讲了框架，接下来要进入今天的重头戏：**用这个框架拆解一个真实的案例**。
>
> 不是让大家从零拆解，而是给一个样本版本，让大家挑刺、补充、修改。"

### 3.2 Step 1：案例呈现（15分钟）

**案例：付振博 × 香港客户**

**客户背景**：
- 香港客户，微信后台找到付振博
- 两个儿子（12岁、7岁），7月份公公婆婆从美国回来
- 需求表达简洁："我在香港，想买带装修的别墅或复式，预算1000万，5月份买"

**关键节点**：

| 阶段 | 发生了什么 |
|------|-----------|
| C1 判断真伪 | 多数经纪人会判断为"骗局"，付振博用语音通话验证——是真客户 |
| C2 需求排序 | 客户说"别墅或复式"，付振博判断"你要的是带院子的别墅" |
| C3 带看匹配 | AABC四盘策略，第三个盘客户"不想走" |
| 信任建立 | 客户想买大平层，付振博拦住："这套别买" |
| C6 签约障碍 | 客户没有人民币账户，付振博不催定金，陪着解决问题 |
| 成交 | 1200万精装别墅 |

**【关键原话】**：
> "王小姐，我和一般的经纪人不一样，我不等着开单吃饭。我不能因为想赚佣金，让你把1000多万放在这个不符合你需求的地方。"

**客户后来反馈**：
> "你有两个点让我特别相信你。第一个就是我在那个地方想买的时候你不让我买。"

---

### 3.3 Step 2：个人拆解（15分钟）

**任务**：请用"视野/判断/行动/同盟"四类能力，拆解这个案例。

**填写下表**：

| 阶段 | 视野（看见什么） | 判断（给出什么结论） | 行动（做了什么） | 同盟（站在谁一边） |
|------|------------------|----------------------|------------------|-------------------|
| C1 | | | | |
| C2 | | | | |
| C3 | | | | |
| ... | | | | |

**提示**：
- 视野：经纪人看到了什么客户没看到的？
- 判断：经纪人给出了什么明确结论？
- 行动：经纪人做了什么具体动作？
- 同盟：经纪人站在谁的一边？有没有给反向判断？

---

### 3.4 Step 3：小组讨论（20分钟）

**分组**：每组4-6人，选出记录员和汇报人

**讨论问题**：
1. 你们各自的拆解版本有什么不同？
2. 哪些能力判断是你们共识的？
3. 哪些能力判断有争议？争议点是什么？

**产出**：一份小组共识版拆解表

---

### 3.5 Step 4：版本呈现（20分钟）

**每组5分钟汇报**：
1. 展示你们的拆解版本
2. 说明：哪个能力判断最有把握？
3. 说明：哪个能力判断最难判断？

**引导问题**：
- 各组的版本有什么不同？
- 哪一组的拆解方式最清晰？为什么？
- 有没有争议点？为什么会有争议？

---

### 3.6 Step 5：共识收敛（30分钟）

**展示样本版本**：付振博案例的能力拆解（提前准备）

**对比讨论**：
- 样本版本和各组版本有什么差异？
- 样本版本有哪些可以补充或修正的地方？

**形成共识**：
- 重庆共识版能力图谱雏形
- 待讨论/待验证的问题清单

---

---

### 常见疑问回应

**Q：4×7是28门课吗？**
> 不是课程，是28个能力训练节点。"格子"才是训练对象，课程是填格子的手段之一。

**Q：视野/判断/行动是顺序学的吗？**
> 不是。视野→判断→行动是因果链，不是学习顺序。视野缺位，上层一定塌。

**Q：怎么判断一个经纪人能力好不好？**
> 最锋利的检验：能不能给出**反向判断**——敢说"别买""别卖"。

**Q：标准谁来定？**
> 标准必须来自一线真实场景和TOP经纪人的真实动作。这就是为什么要共创。
