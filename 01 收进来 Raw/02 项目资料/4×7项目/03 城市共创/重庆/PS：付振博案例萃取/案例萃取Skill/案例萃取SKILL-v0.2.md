## 一、为什么需要标准化

| 问题 | 后果 |
|------|------|
| 4个人用的维度不一样 | 无法横向对比 |
| 萃取颗粒度不同 | 有的粗有的细 |
| 水位判断标准不一致 | 你说L3他说L2 |
| 流程阶段命名不统一 | 无法对齐 |

**共识SKILL = 让4个人的萃取结果能放在同一张表上对比。**

## 二、萃取五步法

### Step 1：案例筛选

**什么样的案例值得萃取？**

| 维度 | 标准 | 说明 |
|------|------|------|
| **完整性** | 覆盖3个以上消费者决策阶段 | 能看到链路，不是片段 |
| **能力展现** | 至少有1个"判断"或"立场"时刻 | L1案例（纯信息搬运）价值有限 |
| **真实性** | 有逐字稿或录音可回溯 | 不依赖记忆，要有源文件 |
| **争议性** | 有可讨论的空间 | 完美无缺的案例不如有争议的案例 |

**优先级**：
1. 有反向判断的案例（敢说"别买/别卖"）
2. 有需求排序时刻的案例（C2阶段）
3. 失败案例（同样有价值——"哪里断了"）

---

### Step 2：信息萃取——一个完整的服务要做哪些事？

**从案例萃取（逐字稿/录音）中提取什么信息？**

| 提取项 | 说明 | 格式 |
|--------|------|------|
| **客户/业主画像** | 家庭结构、决策背景、预算约束 | 简单描述 |
| **成交/失败结果** | 最终结果 | 简单描述 |
| **关键互动节点** | 确定本案例属于Z1（单次接触/一次面访或带看）还是Z2（单单成交/从需求到签约），再深入列出消费者的每个决策阶段、该阶段的核心萃取焦点、所对应的4项能力（理解/判断/路径/立场），把不同能力所对应的能力/动作（参考） | 按阶段列出 |
| **经纪人不同决策阶段不同能力展现的原话/案例描述** | 见下方详细说明 | 从不同阶段分别列出 |

**经纪人原话/案例描述的详细萃取要求**：

1. **因果链（理解→判断→路径）**：从不同阶段分别列出该阶段经纪人在因果链上的具体做法的原话/案例描述摘录。判断经纪人的能力深度是否构成因果链，决定Y轴经纪人做到了Y1还是Y2还是Y3。

2. **立场（X轴）**：萃取经纪人在立场上展现的具体做法的原话/案例描述摘录。判断经纪人的立场强度属于：
   - 弱——信息中转（传声筒）
   - 中——中性平衡（摆利弊）
   - 强——敢牺牲短期利益（从客户的长期立意出发）
   - 横轴关键看经纪人是否有反向判断，体现经纪人是否诚实有敢说不的能力，决定经纪人替谁服务。

**每个阶段的萃取结构**：

| 阶段 | 核心萃取焦点 | 理解（Y1） | 判断（Y2） | 路径（Y3） | 立场（X1/X2/X3） |
|------|-------------|-----------|-----------|-----------|-----------------|
| C1 动机形成 | 经纪人如何识别客户真实动机 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 |
| C2 需求发育 | 经纪人如何帮客户理清需求 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 |
| C3 聚焦收敛 | 经纪人如何帮客户锁定核心需求 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 |
| C4 精准匹配 | 经纪人如何精准推荐 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 |
| C5 签约成交 | 经纪人如何推动决策 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 |
| C6 交付流程 | 经纪人如何保障交付 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 |
| C7 售后服务 | 经纪人如何维护长期关系 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 | 原话/案例描述 |

**要求**：萃取的经纪人原话/案例描述摘录尽量完整。

### Step 3：能力映射

**如何把萃取中经纪人聊到的原话/案例描述行为映射到4×7框架？**

**映射规则**：

| 规则 | 说明 |
|------|------|
| **1行为1标签** | 一个具体动作只映射到1个能力维度 |
| **先看动作再归类** | 不是先定义再找例子，是先看做了什么再判断属于哪类 |
| **必须有原话支撑** | 每个映射都要有逐字稿中的原话作为证据 |
| **缺位的也要记录** | 哪个阶段/维度没有展现，也要标注"缺失" |

**映射方法**：

| 你看到的行为 | 归类依据 |
|-------------|---------|
| 经纪人看到了客户没看到的 | → **理解** |
| 经纪人给出了明确结论 | → **判断** |
| 经纪人提供了具体下一步 | → **路径** |
| 经纪人站在客户长期利益 | → **立场** |

**常见争议**：

| 争议 | 处理方式 |
|------|---------|
| "这个动作既是理解又是判断" | 拆成两个动作：看见什么→理解，给什么结论→判断 |
| "判断和立场分不清" | 判断是"结论是什么"，立场是"结论站在谁那边" |
| "某个阶段没有行为" | 标注"缺失"，缺失本身就是信息 |

### Step 4：水位判断——这件事做得怎么样？

**如何给经纪人服务的这一单给出L1/L2/L3综合定级？**

**三步判断法**：

**第一步：Y轴判断（能力深度）**

| 层级 | 标准 | 检验问题 |
|------|------|---------|
| Y1 理解 | 看见客户没看见的 | 他说了什么客户没说出口的？ |
| Y2 判断 | 给出明确结论 | 他有没有给"你应该X"的判断？ |
| Y3 路径 | 提供可执行下一步 | 客户走出后能复述"接下来三件事"吗？ |

**第二步：X轴判断（立场强度）**

| 层级 | 标准 | 检验问题 |
|------|------|---------|
| X1 中转 | 传话筒，不站位 | 他说"业主说了算""您再考虑"了吗？ |
| X2 中性 | 列利弊，不偏 | 他说"ABC优点，XYZ缺点，您权衡"了吗？ |
| X3 立场 | 敢说违背自身利益的话 | 他有没有给过反向判断？ |

**第三步：综合定级**

> **综合定级 = 两个维度的最小值（短板决定）**

**L1 ○** —— 任意一个维度处于最低水平
- 视野到位但完全不敢站位（Y3 + X1） → 仍是 L1
- 立场鲜明但完全看不见（Y1 + X3） → 仍是 L1（瞎热情比冷漠更坑）
- 资料库578案例中394个落这里（68%）

**L2 ●** —— 两个维度都至少到中段
- 看得见、能给判断（Y2）+ 中性平衡（X2）
- 不会犯大错，但客户记不住你
- 资料库184个（32%）

**L3 ★** —— 两个维度都达到顶端
- 视野 + 判断 + 行动俱全（Y3）× 立场鲜明，敢说不（X3）
- 资料库4个（不到1%）——星级稀缺，不是评级吝啬，是真稀缺

**注意事项**：
- 水位判断基于**此次案例**，不跨案例推断
- 明确标注是Z1（单次接触/一次面访或带看）/Z2（单单成交/从需求到签约）/Z3（多年陪伴/5年/10年）哪个层面
- 不确定时标注"待验证"，不强行定级

---

### Step 5：争议处理

**判断不一致时怎么办？**

| 情况 | 处理方式 |
|------|---------|
| 能力映射不一致 | 回到原话：这个动作到底做了什么？ |
| 水位判断不一致 | 回到标尺：Y轴到哪？X轴到哪？ |
| 定义理解不一致 | 记录两种理解，不强行统一，留待共创讨论 |
| 案例信息不足 | 标注"信息缺失"，不猜测 |

**争议处理原则**：
- 争议本身是有价值的——它暴露了框架需要澄清的地方
- 不追求统一答案，追求"理解差异在哪"
- 争议点写入"争议清单"，作为四人会议和城市共创的讨论素材

## 三、聚焦1个阶段的4种能力萃取方法

**为什么从"1个格子"调整为"1个阶段4种能力"？**

在城市共创中，大概率无法一单全部萃取完成。更现实的做法：**聚焦一个消费者决策阶段，从理解→判断→路径+立场4种能力做完整拆解**。

这样做的优势：
1. **展示因果链**：理解→判断→路径是因果链，只看1个格子（如判断）看不到链路
2. **展示立场底色**：立场横切每一格，单独拆1格容易忽略立场的贯穿性
3. **更现实**：重庆共创的案例大概率只有1-2个阶段的信息比较完整，聚焦1个阶段4种能力比强求全流程更落地
4. **更有价值**：1个阶段4种能力拆透了，其他阶段参与者自己就会拆

**当前建议聚焦阶段**：**C2 需求发育**

| 理由 | 说明 |
|------|------|
| 付振博案例在此阶段有标杆表现 | "你要的不是复式，是带院子的别墅" |
| 所有经纪人都有此场景经验 | 需求发育是最常见的业务场景 |
| 因果链最清晰 | 理解（听出需求）→判断（给结论）→路径（锁定方向）完整展现 |
| 立场最易识别 | "你要的不是复式"本身就是立场表达 |

## 四、4人会议中的使用方式

### 建议议程

| 环节 | 内容 | 时间 |
|------|------|------|
| 1 | 每人5分钟：展示C2阶段的4能力拆解 | 20分钟 |
| 2 | 对比4个版本的差异：因果链是否完整？立场判断是否一致？ | 20分钟 |
| 3 | 讨论共识：统一的萃取标准和水位判断 | 30分钟 |
| 4 | 争议处理：不一致的地方怎么记 | 20分钟 |
| 5 | 下一步分工 | 10分钟 |

### 核心对齐问题

1. **C2阶段的4能力拆法是否一致？** 因果链（理解→判断→路径）是否完整？
2. **立场判断是否一致？** 同一个动作，X轴判断一样吗？
3. **水位判断是否一致？** 综合定级=短板决定，4个人用得一样吗？
4. **萃取模板是否可用？** 上面的单阶段4能力模板需要怎么调整？
