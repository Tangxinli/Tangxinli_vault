## 一、框架理解：大S专业服务的四层结构

### 1.1 为什么有四层？

大S框架的核心洞察：**一个问题一张表，摊平了谁都看不懂。**

| 层 | 回答的问题 | 工具 | 类比（医生） |
|---|-----------|------|-------------|
| **L1** | 要做哪些事？ | 4×7矩阵（28格） | 接诊→问诊→检查→诊断→处方→复诊的全流程清单 |
| **L2** | 做得怎么样？ | 2D水位标尺 | 实习医生 vs 主治医生，差距在哪 |
| **L3** | 为什么做得好？ | 8项底层能力 | 临床思维、沟通力、共情力等根能力 |
| **L4** | 长期能不能持续？ | 3D时间幅度 | 五年后有没有从主治长成主任 |

**一句话**：L1看做什么，L2量做多好，L3找根因，L4看成长。

---

### 1.2 L1：4×7矩阵的核心结构

**四个维度（纵向）**：

| 维度 | 含义 | 因果关系 |
|------|------|----------|
| **视野** | 看见客户没看见的 | 最底层，视野缺位→上层一定塌 |
| **判断** | 给出有立场的明确结论 | 在视野基础上敢拍板 |
| **行动** | 把判断落成具体下一步 | 判断的落地 |
| **同盟** | 站在谁那边 | 横切所有格的底色 |

**关键理解**：
- 视野→判断→行动是**因果链**（不是平行的三选一）
- 同盟是**底色**（每一格都在表达"我站谁"）

**七个阶段（横向）**：
```
1.需求摸底 → 2.看房带看 → 3.报价撮合 → 4.谈判 → 5.签约 → 6.签后服务 → 7.长期陪伴
```

---

### 1.3 L2：2D水位标尺的核心逻辑

**Y轴：能力深度**（从下往上）
- Y1 视野：看得见
- Y2 判断：敢拍板
- Y3 行动：能落地

**X轴：立场强度**（从左往右）
- X1 中转：业主说了算 / 您再考虑
- X2 中性：利弊摆给您，您权衡
- X3 立场：**敢说违背自身短期利益的话**

**等高线定级**：短板决定水位
- L1 ○：任意一个维度最低
- L2 ●：两个维度都到中段
- L3 ★：两个维度都到顶端

**最锋利的检验**：能不能给出**反向判断**（拒绝一笔本可以做的生意）

## 二、案例拆解：付振博服务的L1矩阵分析

### 2.1 阶段1：需求摸底（C1-C2）

**客户背景**：香港客户，微信后台找到付振博，需求表达非常简洁：
> "我在香港，想在大理商场酒店旁买带装修的别墅或顶层复式，预算1000万，5月份买"

| 维度 | 付振博做了什么 | 具体表现 |
|------|----------------|----------|
| **视野** | 判断客户真伪 | 识别"香港骗局"模式：很多假客户会用类似的简洁话术，最终引导到资金兑换骗局 |
| **判断** | 第一通语音判断是**真客户** | 依据：① 主动说"为什么找你"——"你视频不讲房子，像个领导"（真实理由）② 能说出具体细节（香港住哪、孩子多大、为什么要买） |
| **行动** | 直接要求语音通话 | "文字太冰冷，我要通过语音判断客户的真实购买欲" |
| **同盟** | 没有预设判断，而是**验证** | 没有因为是"香港客户"就直接拒绝或全盘接受 |

**关键洞察**：
- 付振博的"视野"体现在：**知道骗局的模式，但没有被模式困住**
- 他的"判断"体现在：**用语音通话获取真实信息，验证假设**
- 这是典型的 **Y2判断 + X2中性** 水位

---

### 2.2 阶段2：需求排序（深度面访）

**付振博的核心动作**：需求排序的"减法"

> "客户的需求有很多，我们做的是排除法——如果只保留三项核心需求，你会选什么？"

| 客户表达的表层需求 | 付振博识别的核心需求 |
|-------------------|----------------------|
| 别墅或复式 | **带院子的别墅**（因为有孩子撒欢的空间） |
| 5月份买 | **7月份必须入住**（公公婆婆从美国回来） |
| 预算1000万 | 实际可接受1500万（因为要精装，省掉装修时间） |
| 大型商场酒店旁 | 实际是**生活便利 + 孩子教育 + 老人养老**的综合需求 |

**关键判断**：

付振博说了一句**反向判断**：
> "你要的不是复式，是带院子的别墅。"

这是典型的 **X3立场** —— 帮客户纠正了错误的需求方向。

---

### 2.3 阶段3：带看匹配

**付振博的带看策略**：AABC四盘策略

| 盘位          | 作用            | 客户反应         |
| ----------- | ------------- | ------------ |
| A盘          | 客户自己挑的（高尔夫别墅） | 看完不满意，入住率低   |
| A盘          | 也是客户挑的（二手别墅区） | 看不上审美        |
| **B盘（目标盘）** | 付振博推荐的（精装别墅）  | **不想走，特别喜欢** |
| C盘          | 备选（供比较）       | 没看就定了        |

**关键洞察**：
- 付振博知道前两个盘客户不会喜欢，但**还是带看**——让客户自己排除
- B盘是他判断客户一定会喜欢的——**精装、大花园、家具全送、时间刚好**
- 这是 **Y3行动** 的体现：带看动线设计有明确目的

---

### 2.4 阶段4：信任建立的关键时刻

**第一个信任点**：客户想买大平层，付振博拦住了

> "王小姐，我和一般的经纪人不一样，我不等着开单吃饭。我不能因为想赚一点佣金，让你把1000多万放在这个不符合你需求的地方。"

**客户后来反馈**：
> "你有两个点让我特别相信你。第一个就是我在那个地方想买的时候你不让我买。"

**这是典型的 X3立场**：敢说违背自身短期利益的话。

---

### 2.5 阶段5：签约障碍处理

**障碍**：客户没有人民币账户，1000多万转不过来

**付振博的做法**：

| 典型L1经纪人的做法 | 付振博的做法 |
|-------------------|--------------|
| 急着催定金，怕客户跑了 | **不催**，反而安慰客户"别有压力" |
| 把问题抛给客户自己解决 | 陪客户去银行，协调开发商 |
| 让客户觉得自己没钱 | **识别客户心理变化**：她怕我们认为她不是决策者 |

**关键洞察**：
> "这个时候他心里面是最乱、最矛盾、最脆弱的时候。你唯一能做的就是**别吭声，坐着陪他**。"
> "促签约？他走了你还促签约？"

这是 **情绪共感 + 时间结构能力** 的组合体现。

---

### 2.6 阶段6-7：签后服务与长期陪伴

**服务细节**：
- 给两个孩子买六一儿童节礼物（乐高）
- 实时同步家具安装进度，拍长视频给客户看
- 准备收楼仪式（淡紫色包装、绿植、气球）
- 尊重客户信仰，不主动选"吉时"

**客户反馈**：
> "收楼之后会带好几个人来找你。"

这是 **Z3多年陪伴** 的伏笔。

## 三、水位分析：付振博是L几？

### 3.1 按2D标尺定位

**Y轴（能力深度）**：

| 维度    | 表现                    | 水位   |
| ----- | --------------------- | ---- |
| 视野 Y1 | 看得见骗局模式、客户隐性需求、产品匹配逻辑 | ✓ 到位 |
| 判断 Y2 | "你要的不是复式是别墅"、"这套别买"   | ✓ 到位 |
| 行动 Y3 | 带看动线设计、三步路径、签约障碍处理    | ✓ 到位 |

**X轴（立场强度）**：

| 维度    | 表现                  | 水位   |
| ----- | ------------------- | ---- |
| 中转 X1 | 无                   | -    |
| 中性 X2 | 有，但不限于此             | -    |
| 立场 X3 | "我不等着开单吃饭"、拦住客户买大平层 | ✓ 到位 |

**定位**：**Y3 × X3 = L3 ★**

---

### 3.2 按8项底层能力验证

| 根能力        | 案例中的体现              | 评分  |
| ---------- | ------------------- | --- |
| 1. 信息提取力   | 从简洁短信中提取出真客户信号、核心需求 | ★★★ |
| 2. 结构化思考   | 需求排序减法、AABC四盘策略     | ★★★ |
| 3. 数据敏感度   | 预算上浮30%的判断（考虑装修成本）  | ★★★ |
| 4. 承担判断的勇气 | "你要的不是复式是别墅"        | ★★★ |
| 5. 情绪共感    | 识别客户签约时的焦虑心理        | ★★★ |
| 6. 时间结构能力  | 带看动线、签约后的三步路径       | ★★★ |
| 7. 冲突中的中正  | 不偏业主不偏买家，站在客户长期利益   | ★★★ |
| 8. 诚实      | 不让买大平层、不催定金         | ★★★ |

**结论**：8项底层能力全部到位，这是真正的L3。

## 六、重庆工作坊设计优化建议

### 6.1 原流程分析

| 原流程             | 时间   | 问题       |
| --------------- | ---- | -------- |
| 1. "以消费者为中心"的解读 | 60分钟 | 可以压缩     |

### 6.2 优化建议

**第一部分：以消费者为中心的解读（40分钟）**

核心内容：
- S的战略判断：从信息播报机到顾问型服务者
- 一个关键案例（如S闭门会分享中的"三种为孩子买房的人"）
- 引出问题：我们怎么知道经纪人"叫行"？

**第二部分：消费者决策流程 + 能力框架（50分钟）**

**调整思路**：不要分开讲"流程"和"能力"，而是**用流程承载能力**

| 阶段      | 消费者在想什么    | 经纪人要做什么（视野/判断/行动/同盟） |
| ------- | ---------- | -------------------- |
| C1 寻找客户 | 我该不该买房？    | 视野：判断真伪 / 判断：识别动机    |
| C2 客户面访 | 我的真实需求是什么？ | 视野：听出未说出口的 / 判断：需求排序 |
| ...     | ...        | ...                  |

**输出**：一张"消费者视角 × 能力要求"的对照表

**第三部分：标杆案例拆解与共创（100分钟）**

**共创设计方案**：

**Step 1：案例呈现（15分钟）**
- 讲述付振博案例的完整链路
- 或者：邀请重庆本地的一位优秀经纪人讲自己的案例

**Step 2：个人拆解（15分钟）**
- 每人独立填写：你认为这个案例中，经纪人在每个阶段展现了什么能力？
- 使用简化版工作表

**Step 3：小组讨论（20分钟）**
- 4-6人一组
- 对比各自的拆解版本
- 找出共识点和争议点

**Step 4：版本呈现（20分钟）**
- 每组5分钟汇报
- 展示：你们认为最清晰的能力判断是什么？最不确定的是什么？

**Step 5：共识收敛（30分钟）**
- 引导全场讨论争议点
- 形成一张"重庆共识版"能力图谱雏形

### 6.3 共创的核心是"对比"而非"从零到一"

**关键洞察**：
- 让大家从零拆解4×7很难
- 但给一个样本版本，让大家**找问题、提建议、做对比**，就容易得多

**建议准备**：
- 提前准备一份"付振博案例的能力拆解版本"（就是本文档）
- 共创时先展示，让大家**挑刺、补充、修改**
- 这样降低了门槛，也提高了讨论质量

## 八、附录：大S框架的几个关键理解

### 8.1 为什么"视野→判断→行动"是因果链？

> 视野缺位，上层一定塌。

- 你看不见问题，就没法判断
- 你不敢判断，就没法行动
- 但反过来不成立：视野好的人可能不敢判断

### 8.2 为什么"同盟"是底色？

> 每一格都在表达"我站谁"。

- 视野可以为客户服务，也可以为业主服务，也可以为自己服务
- 同盟决定了前三者的落点
- 最锋利的检验：敢不敢说"别买""别卖"

### 8.3 L3为什么稀缺？

资料库578案例中：
- L1：394个（68%）
- L2：184个（32%）
- L3：4个（不到1%）

**原因**：L3需要两个维度都到顶端，且能持续。这不是技巧问题，是**选人问题**——8项底层能力的后两项（冲突中的中正、诚实）接近性格和价值观。

### 8.4 四层之间的关系

```
            L4 时间幅度（看长期）
                  ↑
                  │
            L3 底层能力（钻根因）
                  ↑
                  │
            L2 水位标尺（量水平）
                  ↑
                  │
            L1 内容矩阵（看清单）
```

**回答不同问题时，从不同的层进入**：
- "这单子接下来要做什么？" → L1矩阵
- "这个新人现在水平怎么样？" → L2水位
- "他为什么总是缺一口气？" → L3根能力
- "他能不能成为合伙人？" → L4时间
