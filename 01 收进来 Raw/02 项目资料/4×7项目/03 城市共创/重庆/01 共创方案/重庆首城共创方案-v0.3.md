## 一、项目背景

### 1.1 战略背景

S提出：**"AI时代，消费者需要的不是信息播报机，而是顾问型服务者。"**

核心判断：
- AI工具正在取代经纪人的信息搜集与播报功能
- 经纪人的核心不可替代价值，在于**顾问型服务能力**
- 花桥学堂的命题：构建经纪人服务能力体系——4×7

### 1.2 核心问题

> **我们知道经纪人哪里不行，但说不清"什么叫行"。**

4×7要做的，就是把"行"的标准，拆进每一个真实的业务场景里，让能力差距变得**可见、可训练、可评价**。

### 1.3 关键判断：框架通用，内容本土

大S专业服务框架来自578个跨市场案例实证，以下内容是**通用的**，不因城市而变：

| 层 | 通用（不变） | 本土（变） |
|---|---|---|
| L1 矩阵 | 4类能力×7阶段=28格结构 | 每格内的具体交付物、关键动作、案例 |
| L2 水位 | Y轴/X轴定义、L1/L2/L3标准 | 城市经纪人的典型分布比例 |
| L3 根能力 | 8项根能力的定义和数量 | 哪些根能力是城市最缺的优先项 |
| L4 成长 | A/B/C三种曲线类型 | 具体经纪人的成长路径和培训策略 |

**城市共创的本质**：每个城市用自己的内容，填通用的框架。

### 1.4 大S框架的定位

**大S专业服务框架是方向指引，不是唯一标准。** 理解核心逻辑，结合一线实际和用户思考落地，不偏离方向但要接地气。

## 三、4×7框架说明

### 3.1 核心结构

**消费者决策流程（横轴）**：

客户视角：动机形成 → 需求发育 → 聚焦收敛 → 精准匹配 → 签约成交 → 交付流程 → 售后服务

业主视角：卖房动机 → 理解市场 → 确认方案 → 定价 → 售房追踪 → 确认价格 → 置换

**四类能力（纵轴）**：

| 维度 | 含义 |
|------|------|
| **理解** | 读懂消费者的真实处境和需求 |
| **判断** | 给出有立场的明确结论 |
| **路径** | 提供清晰可执行的解决方案 |
| **立场** | 敢于承担责任，给出明确建议 |

**4×7 = 每个赛道28个能力单元，双赛道合计56个能力单元**

### 3.2 为什么从消费者决策流程出发

| 传统做法 | 问题 |
|----------|------|
| 以经纪人作业流程为主轴 | 经纪人陷入"动作思维"，非"消费者视角" |
| 假设流程是线性的 | 消费者决策是非线性、反复的 |

从消费者决策流程出发：始终问"消费者在想什么"；经纪人动作是"可参考的"而非"必须完成的"。

### 3.3 四层结构

| 层      | 工具            | 回答的问题    |
| ------ | ------------- | -------- |
| L1 矩阵  | 4×7（28格）      | 要做哪些事？   |
| L2 水位  | 2D标尺（Y深度×X立场） | 做得多好？    |
| L3 根能力 | 8项底层能力        | 为什么做得好？  |
| L4 时间  | 3D时间幅度        | 长期能不能持续？ |

## 四、重庆共创方案

### 4.1 核心定位：验证，不是产出

重庆共创的本质是**验证三件事**，不是产出完美的能力图谱：

| 验证项         | 问题                | 通过标准       |
| ----------- | ----------------- | ---------- |
| **框架能被听懂**  | 参与者能否理解4×7的基本逻辑？  | 能用自己的话复述框架 |
| **共创能产出讨论** | 小组拆解产出的差异度和深度如何？  | 有价值的争议点被识别 |
| **产出有落地意愿** | 城市团队会不会真的用这份能力图谱？ | 主动约定后续合作   |

三件全过 → 深圳直接复制。卡在哪件 → 深圳前先迭代。

### 4.2 设计原则

| 原则            | 说明                          |
| ------------- | --------------------------- |
| **先案例后框架**    | 不从时代背景讲起，用案例让参与者感受差距，再用框架标注 |
| **聚焦1个格子**    | 4小时跑通1个格子的拆解，比蜻蜓点水28格更有价值   |
| **先给样本再共创**   | 给样本版本让大家"挑刺、补充、修改"，降低入门门槛   |
| **同一案例对比**    | 同一案例不同人拆解的差异，是最好的学习素材       |
| **通用框架+本土内容** | 框架由花桥提供，内容由城市共创填入           |

### 4.3 阶段性目标

| 层面       | 目标                     |
| -------- | ---------------------- |
| **认知层面** | 理解框架逻辑（消费者决策流程 + 四类能力） |
| **产出层面** | 完成**1个格子**的重庆共识版拆解     |
| **关系层面** | 建立协作信任，约定后续合作方式        |

### 4.4 共创形式

**时间**：6月18日下午，4小时
**主题**：以消费者为中心的顾问型服务者能力探索
**参与者**：重庆城市核心骨干（建议20-30人）

### 4.5 流程设计

| 环节       | 内容               | 时长    | 形式       |
| -------- | ---------------- | ----- | -------- |
| **开场**   | 破冰+为什么今天坐在这里     | 10分钟  | 讲授       |
| **第一部分** | 一个案例看懂"什么叫行"     | 40分钟  | 案例讲述+互动  |
| **茶歇**   |                  | 10分钟  |          |
| **第二部分** | 7阶段流程+4类能力：用案例承载 | 50分钟  | 引导式讲解+练习 |
| **第三部分** | 案例共创（聚焦1个格子）     | 100分钟 | 小组共创     |
| **收束**   | 共识收敛+后续约定        | 30分钟  | 全员讨论     |

### 4.6 案例应用策略

**付振博案例**：Z1+Z2的L3示范样本，用来教方法、建立体感
**重庆案例**：城市共创的主体素材，用来验证框架、产出本土内容

### 4.7 聚焦哪个格子

建议聚焦 **C2（需求发育）× 判断能力**：

| 理由            | 说明                 |
| ------------- | ------------------ |
| 付振博案例在此格有标杆表现 | "你要的不是复式，是带院子的别墅"  |
| 所有经纪人都有此场景经验  | 需求发育是最常见的业务场景      |
| 判断能力是最核心的分水岭  | L1和L2的分界线在"敢不敢给判断" |
| 容易产出可对比的差异    | 不同人对"判断"的理解差异大     |

## 七、风险与应对

| 风险 | 应对措施 |
|------|----------|
| 参与者理解困难 | 先案例后框架，用故事建立感受再用术语标注 |
| 共创产出质量不高 | 先给样本版本降低门槛，聚焦1个格子而非28格 |
| 时间不够用 | 控制讲授时间，把时间留给共创 |
| 框架被质疑"不接地气" | 坦诚说"框架是通用的，内容需要你们来填" |
| 只讨论不产出 | 提前准备对比表格模板，讨论中实时填空 |
| 被付振博案例压住 | 强调：付振博是样本不是标准，用来教方法 |

## 八、成功标准

### 8.1 第一轮验证标准

**框架能被听懂**：
- [ ] 参与者能用自己的话复述4×7的基本逻辑
- [ ] 参与者能理解消费者决策流程的核心思路

**共创能产出讨论**：
- [ ] 小组拆解产出有差异度和深度
- [ ] 识别出至少2个有价值的争议点

**产出有落地意愿**：
- [ ] 城市团队主动约定后续合作方式
- [ ] 至少3人愿意在实战中验证

### 8.2 整体成功标准（三轮后）

- [ ] 城市共识版4×7能力图谱（通用框架+本土内容）
- [ ] 城市团队的认可和使用
- [ ] 可复制的城市合作SOP
- [ ] 4×7产出与BOX训练产品的承接贯通
