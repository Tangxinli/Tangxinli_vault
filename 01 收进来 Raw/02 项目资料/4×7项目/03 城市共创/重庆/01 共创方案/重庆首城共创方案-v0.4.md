## 一、项目背景

### 1.1 战略背景

S提出：**"AI时代，消费者需要的不是信息播报机，而是顾问型服务者。"**

核心判断：
- AI工具正在取代经纪人的信息搜集与播报功能
- 经纪人的核心不可替代价值，在于<font color="#c00000">**顾问型服务能力**</font>
- 核心命题：构建<font color="#c00000">经纪人服务能力体系——4×7</font>

### 1.2 核心问题

> **我们知道经纪人哪里不行，但说不清"什么叫行"。**

4×7要做的，就是把"行"的标准，拆进每一个真实的业务场景里，让能力差距变得**可见、可训练、可评价**。

### 1.3 经纪人顾问型服务能力体系（框架）是什么？

**能力体系分层——为什么要分层？**

一个能力问题摊成一张大表，把所有要素塞进去——结果谁都看不懂。
不同的人问不同的问题，需要不同的视角。
四层不是平行的，是**同一个对象的四种切法**，每一层回答一个不同的问题。

| 层      | 回答的问题        | 工具                | 工具图示及含义                                                     | 类比                         |
| ------ | ------------ | ----------------- | ----------------------------------------------------------- | -------------------------- |
| **L1** | 服务者知道要做什么？   | 4×7矩阵（28格）        | 4类能力（理解/判断/路径/立场）× 7个消费者决策阶段 = 28个能力单元，每格写清交付物/关键动作/所需能力    | 医生的接诊→问诊→检查→诊断→处方→复诊的全流程清单 |
| **L2** | 评估服务者做的有多好？  | 2D水位标尺（评价标准-能力差距） | Y轴（能力深度：理解→判断→路径）× X轴（立场强度：中转→中性→立场鲜明），L1/L2/L3是等高线         | 同样一个诊断，实习医生vs主治医生的差距在哪     |
| **L3** | 找到对应的根能力（根因） | 8项底层能力            | 8项根能力（信息提取力/结构化思考/数据敏感度/承担判断的勇气/情绪共感/时间结构能力/冲突中的中正/诚实）横切28格 | 临床思维、沟通能力、共情力等根能力          |
| **L4** | 看经纪人长期的成长曲线  | 3D时间幅度（赋能方向及方法）   | Z轴叠加到2D水位上：单次接触/单单成交/多年陪伴三个时间尺度                             | 五年后这个医生有没有从主治长成主任          |

**四层的顺序**：先看L1知道做什么，再用L2量做得多好，钻进L3找根因，最后用L4看长期——四层各司其职。

### 1.4 对于四层框架的关键判断

**关键判断**：<font color="#c00000">框</font><font color="#c00000">架各城通用、内容因城而异</font>

**框架各城通用**：经纪人能力体系的4层框架—来自578个跨市场案例实证，以下内容不因城市而变——

| 层   | 通用（不变）             | 原因                  |
| --- | ------------------ | ------------------- |
| L1  | 4类能力×7阶段=28格的结构    | 结构来自跨市场实证，是共识语言的基础  |
| L2  | Y轴/X轴定义、L1/L2/L3标准 | 标准跨市场通用，否则无法对比和复制   |
| L3  | 8项根能力的定义和数量        | 横切28格的根能力，是跨场景的底层逻辑 |
| L4  | A/B/C三种曲线类型        | 成长类型的归纳是跨市场的        |

**内容因城而异**：以下内容因城市而异——

| 层   | 本土（变）              | 原因               |
| --- | ------------------ | ---------------- |
| L1  | 28格内的具体交付物、关键动作、案例 | 不同城市的客户画像、市场节奏不同 |
| L2  | 城市经纪人的典型分布比例       | 市场成熟度、团队结构不同     |
| L3  | 哪些根能力是城市最缺的优先项     | 不同城市的薄弱环节不同      |
| L4  | 具体经纪人的成长路径和培训策略    | 本土案例才有共鸣         |

### 1.5 城市共创的本质

> **每个城市用自己的内容，填通用的框架。**

通用层由花桥提供：框架结构、评价标准、根能力定义、萃取方法
本土层由城市共创：具体案例、格内内容、优先提升项、培训课件

如果框架因城市而变 → 无法跨城市比较、无法复制、无法形成组织共识语言
如果只给框架不给内容 → 城市认为"空架子"，无法落地
**共创的价值**：用通用框架 + 本土内容，形成既可比又落地的能力图谱

## 二、重庆共创方案

### 2.1 核心定位：验证，不是产出

重庆共创的本质是**验证三件事**，不是产出完美的能力图谱：

| 验证项         | 问题                 | 通过标准       |
| ----------- | ------------------ | ---------- |
| **框架能被听懂**  | 参与者能否理解4×7的基本逻辑？   | 能用自己的话复述框架 |
| **共创能产出讨论** | 小组案例拆解产出的差异度和深度如何？ | 有价值的争议点被识别 |
| **产出有落地意愿** | 城市团队会不会真的用这份能力图谱？  | 主动约定后续合作   |

三件全过 → 深圳直接复制。卡在哪件 → 深圳前先迭代。

### 2.2 设计原则

| 原则             | 说明                                            |
| -------------- | --------------------------------------------- |
| **先案例后框架**     | 不从宏观时代背景讲起，用案例让参与者感受服务者能力的差距，再用框架标注           |
| **聚焦1个阶段4种能力** | 4小时聚焦1个消费者决策阶段，拆透理解→判断→路径+立场4种能力，比蜻蜓点水28格更有价值 |
| **先给样本再共创**    | 给付振博样本版本让大家"挑刺、补充、修改"，降低入门门槛                  |
| **同一案例对比**     | 同一案例不同人拆解的差异，是最好的学习素材                         |
| **通用框架+本土内容**  | 框架由花桥提供，内容由城市共创填入                             |

### 2.3 阶段性目标

| 层面       | 目标                                                 |
| -------- | -------------------------------------------------- |
| **认知层面** | 理解经纪人顾问型服务能力体系落地的框架逻辑<br>（L1做什么→L2做多好→L3找根因→L4看长期） |
| **产出层面** | 完成至少**1个消费者决策阶段的4种能力**重庆共识版拆解                      |
| **关系层面** | 建立与城市的协作信心                                         |

### 2.4 共创形式

**时间**：6月18日下午，4小时
**主题**：以消费者为中心的顾问型服务者能力探索
**参与者**：重庆城市核心骨干（建议20-30人）

### 2.5 流程设计

| 环节       | 内容                              | 时长   | 形式       |
| -------- | ------------------------------- | ---- | -------- |
| **开场**   | 破冰+为什么今天坐在这里                    | 10分钟 | 讲授       |
| **第一部分** | 大佬细致解读（赵忠祥+老关）                  | 20分钟 | 嘉宾轮流分享   |
| **第二部分** | 一个案例看经纪人服务"什么叫行"                | 30分钟 | 案例讲述+互动  |
| **茶歇**   |                                 | 10分钟 |          |
| **第三部分** | 引出经纪人服务体系的四层结构（工具说明）+用案例承载      | 70分钟 | 引导式讲解+练习 |
| **第四部分** | 重庆参与人用自己的案例拆解+理解四层结构，<br>聚焦1个阶段4种能力 | 70分钟 | 小组共创     |
| **收敛**   | 共识收敛+后续约定                       | 30分钟 | 全员讨论     |

**第一部分·大佬细致解读**：

邀请贝壳重庆区域负责人**赵忠祥** + 花桥学堂负责人**关书伟**，每人10分钟，轮流上台分享。

**分享方式**：从格子的视角出发——

| 嘉宾      | 分享视角           | 建议切入点                                  |
| ------- | -------------- | -------------------------------------- |
| **赵忠祥** | 重庆一线的"行"长什么样   | 举1-2个重庆经纪人做得好的具体场景，说清在那个格子里"行"和"不行"的差距 |
| **关书伟** | 花桥视角的"行"应该长什么样 | 从培训和赋能的角度，说清卡点在哪、为什么需要一套框架来定义"行"       |

**给嘉宾的分享提示**：
- 不需要讲完整框架，只需要讲**你看到的那个格子里，什么叫行**
- 最好举真实案例：某经纪人在某个消费者决策阶段，做了一件什么事，让你觉得"这就是行"
- 如果能说到"判断"或"立场"这类能力词更好，说不出来也没关系——后面我们会用框架帮你标注

**设计意图**：
- 让城市最高视角先开口，建立场域权威感和信任感
- 嘉宾从格子视角分享，让参与者提前进入"拆场景、看能力"的视角
- 大佬举的真实案例和痛点，直接为后续框架导入和共创做铺垫
- 嘉宾说不清楚的地方，恰好是框架的价值——"你感受到但说不出的，框架帮你标注"

### 2.6 案例应用策略

**付振博案例**：Z1+Z2的L3示范样本，用来教方法、建立体感
**重庆案例**：城市共创的主体素材，用来验证框架、产出本土内容

### 2.7 聚焦哪个阶段

建议聚焦 **C2（需求发育）**，从4种能力（理解→判断→路径+立场）做完整拆解：

| 理由 | 说明 |
|------|------|
| 付振博案例在此阶段有标杆表现 | 因果链完整：听出需求（理解）→"你要的不是复式"（判断）→锁定带院别墅（路径）+站在客户长期利益（立场） |
| 所有经纪人都有此场景经验 | 需求发育是最常见的业务场景 |
| 因果链在此阶段最清晰 | 理解→判断→路径构成完整链路，只看1格看不到链路 |
| 立场在此阶段最易识别 | "你要的不是复式"本身就是立场表达 |
| 1个阶段4种能力拆透了，其他阶段参与者自己就会拆 | 比只做1个格子更能展示框架的完整逻辑 |

**为什么从"1个格子"调整为"1个阶段4种能力"？**
- 城市共创中大概率无法一单全流程萃取完成，聚焦1个阶段更现实
- 只拆1个格子（如判断）看不到因果链，也容易忽略立场的贯穿性
- 4种能力拆透1个阶段，比1种能力蜻蜓点水7个阶段更有价值

| 轮次       | 时间    | 目标                 | 形式    |

```
第一轮：验证框架 + 1个阶段4种能力（线下工作坊）

第二轮：完成双赛道 + 本土化（线上/线下）
    ↓ 迭代优化
持续迭代：基于实战反馈（线上协作）
    ↓ 沉淀
城市复制手册 + BOX训练产品
```

| 环节     | 在4×7中的含义    | AI可加速    |
| ------ | ----------- | -------- |
| **学**  | 学习一个阶段的能力要求 | AI辅助内容生成 |
| **练**  | 用案例试填28格    | AI辅助案例拆解 |
| **评**  | 水位判断+短板识别   | AI基于标准初判 |

## 五、风险与应对

| 风险          | 应对措施                   |
| ----------- | ---------------------- |
| 参与者理解困难     | 先案例后框架，用故事建立感受再用术语标注   |
| 共创产出质量不高    | 先给样本版本降低门槛，聚焦1个阶段4种能力而非28格 |
| 时间不够用       | 控制讲授时间，把时间留给共创         |
| 框架被质疑"不接地气" | 坦诚说"框架是通用的，内容需要你们来填"   |
| 只讨论不产出      | 提前准备对比表格模板，讨论中实时填空     |
| 被付振博案例压住    | 强调：付振博是样本不是标准，用来教方法    |
| 大佬解读跑题或超时   | 提前沟通2-3个核心问题，现场控制节奏    |

## 六、成功标准

### 6.1 第一轮验证标准

**框架能被听懂**：
- [ ] 参与者能用自己的话复述4×7的基本逻辑
- [ ] 参与者能理解消费者决策流程的核心思路

**共创能产出讨论**：
- [ ] 小组拆解产出有差异度和深度
- [ ] 识别出至少2个有价值的争议点

**产出有落地意愿**：
- [ ] 城市团队主动约定后续合作方式
- [ ] 至少3人愿意在实战中验证

### 6.2 整体成功标准（三轮后）

- [ ] 城市共识版4×7能力图谱（通用框架+本土内容）
- [ ] 城市团队的认可和使用
- [ ] 可复制的城市合作SOP
- [ ] 4×7产出与BOX训练产品的承接贯通
