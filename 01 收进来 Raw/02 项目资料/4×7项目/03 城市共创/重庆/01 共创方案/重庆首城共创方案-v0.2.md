## 一、项目背景

### 1.1 战略背景

S提出：**"AI时代，消费者需要的不是信息播报机，而是顾问型服务者。"**

核心判断：
- AI工具正在取代经纪人的信息搜集与播报功能
- 经纪人的核心不可替代价值，在于**顾问型服务能力**
- 花桥学堂的命题：构建经纪人服务能力体系——4×7

### 1.2 核心问题

> **我们知道经纪人哪里不行，但说不清"什么叫行"。**

4×7要做的，就是把"行"的标准，拆进每一个真实的业务场景里，让能力差距变得**可见、可训练、可评价**。

### 1.3 项目定位

| 定位     | 说明                  |
| ------ | ------------------- |
| **本质** | 经纪人能力差距的扫描仪         |
| **目标** | 让"什么叫行"变得可见、可训练、可评价 |
| **产出** | 4×7能力图谱（城市共识版）      |

### 1.4 大S框架的定位

**大S专业服务框架是方向指引，不是唯一标准。**

我们的做法：
- 理解大S框架的核心逻辑
- 结合一线实际场景和用户思考
- 不偏离方向，但要落地

## 二、城市共创策略

### 2.1 为什么选择"城市共创"模式

| 模式              | 问题              |
| --------------- | --------------- |
| 总部制定标准 → 城市执行   | 不接地气，一线难以认同     |
| **城市共创 → 总部整合** | 标准来自一线，认同度高，可落地 |

**共创的核心价值**：
1. **认同感**：自己参与制定的，才会真正使用
2. **本土化**：每个城市有不同的客户特征、市场环境
3. **可复制**：跑通一个城市，形成SOP，复制到其他城市

### 2.2 城市选择逻辑

| 城市         | 选择原因          | 规划时间  |
| ---------- | ------------- | ----- |
| **重庆（首城）** | 已有合作基础，团队配合度高 | 6月18日 |
| 深圳（二城）     | 一线城市标杆，验证可复制性 | 8月-9月 |
| 待定（三城）     | 根据前两城经验调整     | Q4    |

### 2.3 三阶段规划

| 阶段               | 时间    | 目标        | 关键产出           |
| ---------------- | ----- | --------- | -------------- |
| **Phase 1：首城验证** | 6月-7月 | 在重庆跑通共创流程 | 4×7能力图谱V1（重庆版） |
| **Phase 2：二城迭代** | 8月-9月 | 在深圳验证可复制性 | 共创SOP、迭代V2版本   |
| **Phase 3：全国推广** | Q4起   | 形成标准化工具包  | 城市复制手册、训练产品原型  |

## 三、4×7框架说明

### 3.1 核心结构

**消费者决策流程（横轴）**：

**客户视角**：
1. 动机形成
2. 需求发育
3. 聚焦收敛
4. 精准匹配
5. 签约成交
6. 交付流程
7. 售后服务

**业主视角**：
1. 卖房动机
2. 理解市场
3. 确认方案
4. 定价
5. 售房追踪
6. 确认价格
7. 置换

**四类能力（纵轴）**：

| 维度 | 含义 |
|------|------|
| **理解** | 读懂消费者的真实处境和需求 |
| **判断** | 给出有立场的明确结论 |
| **路径** | 提供清晰可执行的解决方案 |
| **立场** | 敢于承担责任，给出明确建议 |

### 3.2 为什么从消费者决策流程出发

**传统做法的问题**：

| 传统做法        | 问题                      |
| ----------- | ----------------------- |
| 以经纪人作业流程为主轴 | 经纪人容易陷入"动作思维"，而非"消费者视角" |
| 假设流程是线性的    | 但消费者决策是非线性、反复的          |
| 用动作定义服务     | 而非用"消费者需要什么"定义服务        |

**从消费者决策流程出发的优势**：

1. **始终以消费者为中心**：每个阶段都问"消费者在想什么"
2. **适应非线性决策**：消费者可能反复多次，经纪人动作要灵活
3. **避免动作僵化**：经纪人动作是"可参考的"，不是"必须完成的"

### 3.3 能力矩阵

**4×7 = 每个赛道28个能力单元，双赛道合计56个能力单元**

每个单元包含：
- 消费者在这个阶段在想什么
- 经纪人需要什么能力
- 经纪人可参考的动作
- 能力好/不好的判断标准

## 四、重庆共创方案

### 4.1 阶段性目标（调整后）

**风险判断**：4小时共识完整4×7，时间不够，容易变成"匆忙填表"。

**调整后的阶段性目标**：

| 层面       | 目标                     | 可行性  |
| -------- | ---------------------- | ---- |
| **认知层面** | 理解框架逻辑（消费者决策流程 + 四类能力） | ✓ 可行 |
| **产出层面** | 完成**一个赛道**的能力拆解（客户或业主） | ✓ 可行 |
| **关系层面** | 建立协作信任，约定后续合作方式        | ✓ 可行 |

### 4.2 共创形式

**时间**：6月18日下午，4小时

**主题**：以消费者为中心的顾问型服务者能力探索

**参与者**：重庆城市核心骨干（建议20-30人）

### 4.3 流程设计

| 环节       | 内容           | 时长    | 形式    |
| -------- | ------------ | ----- | ----- |
| **开场**   | 背景介绍、破冰      | 15分钟  | 讲授    |
| **第一部分** | "以消费者为中心"解读  | 40分钟  | 讲授+互动 |
| **茶歇**   |              | 10分钟  |       |
| **第二部分** | 消费者决策流程+能力框架 | 50分钟  | 讲授+互动 |
| **第三部分** | 案例拆解与共创      | 100分钟 | 小组共创  |
| **收束**   | 共识收敛与后续约定    | 25分钟  | 全员讨论  |

### 4.4 案例应用策略（混合模式）

**方案**：付振博案例作为"示范样本"，重庆案例作为"共创主体"

| 阶段     | 内容                | 时间   |
| ------ | ----------------- | ---- |
| Step 1 | 用付振博案例演示"什么是能力拆解" | 10分钟 |
| Step 2 | 重庆团队拆解自己的案例       | 15分钟 |
| Step 3 | 对比自己的案例和示范案例，找异同  | 20分钟 |
| Step 4 | 各组汇报自己的案例拆解版本     | 20分钟 |
| Step 5 | 从多个案例中提取共识的能力要素   | 30分钟 |

**案例准备要求**：
- 提前和重庆沟通，请他们准备1-2个真实案例
- 案例可以是成交的，也可以是失败的
- 案例需要包含：客户/业主背景、关键互动节点、成交/失败结果
