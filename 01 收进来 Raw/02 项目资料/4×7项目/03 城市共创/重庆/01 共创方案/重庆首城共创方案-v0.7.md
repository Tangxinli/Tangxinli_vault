# 重庆首城共创方案

> **版本**：v0.7
> **日期**：2026-06-11
> **汇报对象**：金燕/燕儿姐
> **方案性质**：运营策略层
> **v0.6→v0.7核心变更**：
> 1. 重新定位：从"验证框架"升级为"验证框架+产出培训产品雏形"
> 2. 产出物分层：框架层→内容层→产品层→工具层，明确培训人产出
> 3. 流程重设计：先体验后展示（先共创拆解→再展示Skill助力）
> 4. 明确培训团队角色：不是语料收集工具，是"知其根知其因"的培训人
> 5. 补充各方价值主张：城市、店东、经纪人参与的理由
> 6. 调整时间分配：嘉宾分享和共创环节重新配时
> 7. 增加萃取质量标准：4×7框架即质量拉齐工具

## 一、项目背景

### 1.1 战略背景

S提出：**"AI时代，消费者需要的不是信息播报机，而是顾问型服务者。"**

核心判断：
- AI工具正在取代经纪人的信息搜集与播报功能
- 经纪人的核心不可替代价值，在于**顾问型服务能力**
- 核心命题：构建**经纪人服务能力体系——4×7**

### 1.2 核心问题

> **我们知道经纪人哪里不行，但说不清"什么叫行"。**

4×7要做的，就是把"行"的标准，拆进每一个真实的业务场景里，让能力差距变得**可见、可训练、可评价**。

**与城市共创的B点画面**：通过4×7项目，培训人沉淀出能力图谱+培训产品，试点经纪人能力提升，业务指标提升。

### 1.3 培训人立场：我们是谁、不是谁

> **"我不是收集语料的工具，我是人的发现者、培训契机的发现者。"** ——金燕

| 我们是            | 我们不是       |
| -------------- | ---------- |
| 知其根、知其因的培训人    | 语料收集的下游工具  |
| 能力图谱的沉淀者       | 框架的搬运工     |
| 人的链接者、培训契机发现者  | 产品方的附属执行者  |
| 课件、知识、培训产品的生产者 | 只做能力拆解的文案员 |

**与产品方的关系**：

| | 培训方（我们） | 产品方（王源团队） |
|---|---|---|
| 底层来源 | 人+AI发展出来的 | 大数据跑出来的 |
| 核心产出 | 能力图谱+培训产品 | AI训练工具+Practice Box |
| 价值主张 | 当产品没有时，4×7还能跑 | 当4×7没有时，产品是盲盒 |
| 关系 | 知其根知其因，做人的链接 | 做工具和效率，做及时反馈 |

**核心判断**：4×7能力图谱是培训人要沉淀出来能看得见的东西。当产品没有的情况下，这个还是可以跑的；但如果只有产品没有4×7，那大家对这件事情是盲盒。**两者互补，但培训方有独立于产品的底层价值。**

### 1.4 经纪人顾问型服务能力体系（框架）

**能力体系分层——为什么要分层？**

一个能力问题摊成一张大表，把所有要素塞进去——结果谁都看不懂。不同的人问不同的问题，需要不同的视角。四层不是平行的，是**同一个对象的四种切法**，每一层回答一个不同的问题。

| 层      | 回答的问题        | 工具                | 类比                         |
| ------ | ------------ | ----------------- | -------------------------- |
| **L1** | 服务者知道要做什么？   | 4×7矩阵（28格）        | 医生的全流程清单 |
| **L2** | 评估服务者做的有多好？  | 2D水位标尺（评价标准-能力差距） | 实习医生vs主治医生的差距在哪     |
| **L3** | 找到对应的根能力（根因） | 8项底层能力            | 临床思维、沟通能力等根能力          |
| **L4** | 看经纪人长期的成长曲线  | 3D时间幅度（赋能方向及方法）   | 五年后这个医生有没有从主治长成主任          |

**四层的顺序**：先看L1知道做什么，再用L2量做得多好，钻进L3找根因，最后用L4看长期——四层各司其职。

### 1.5 对于四层框架的关键判断

**关键判断**：**框架各城通用、内容因城而异**

**框架各城通用**：

| 层   | 通用（不变）             | 原因                  |
| --- | ------------------ | ------------------- |
| L1  | 4类能力×7阶段=28格的结构    | 结构来自跨市场实证，是共识语言的基础  |
| L2  | Y轴/X轴定义、L1/L2/L3标准 | 标准跨市场通用，否则无法对比和复制   |
| L3  | 8项根能力的定义和数量        | 横切28格的根能力，是跨场景的底层逻辑 |
| L4  | A/B/C三种曲线类型        | 成长类型的归纳是跨市场的        |

**内容因城而异**：

| 层   | 本土（变）              | 原因               |
| --- | ------------------ | ----------------  |
| L1  | 28格内的具体交付物、关键动作、案例 | 不同城市的客户画像、市场节奏不同 |
| L2  | 城市经纪人的典型分布比例       | 市场成熟度、团队结构不同     |
| L3  | 哪些根能力是城市最缺的优先项     | 不同城市的薄弱环节不同      |
| L4  | 具体经纪人的成长路径和培训策略    | 本土案例才有共鸣         |

### 1.6 城市共创的本质

> **每个城市用自己的内容，填通用的框架。**

通用层由花桥提供：框架结构、评价标准、根能力定义、萃取方法
本土层由城市共创：具体案例、格内内容、优先提升项、培训课件

如果框架因城市而变 → 无法跨城市比较、无法复制、无法形成组织共识语言
如果只给框架不给内容 → 城市认为"空架子"，无法落地
**共创的价值**：用通用框架 + 本土内容，形成既可比又落地的能力图谱

## 二、培训人产出物定义

> **"你培训人是不是要有课件？要有知识？要有培训产品？"** ——金燕

### 2.1 产出物四层模型

V0.6的产出物只有框架+工具，缺少培训产品层。V0.7重新定义：

| 层          | 产出                   | 对谁            | 性质  | 状态       |
| ---------- | -------------------- | ------------- | --- | -------- |
| **L1 框架层** | 4×7能力体系+能力解读         | 给管理层/项目组，共识语言 | 骨架  | ✅ 已有     |
| **L2 内容层** | 28格的标准化培训课件          | 给培训师，能直接讲     | 血肉  | 🔧 共创产出  |
| **L3 产品层** | 可交付的训练包（场景+标准+练习+评估） | 给一线，能直接练      | 产品  | 🔧 后续沉淀  |
| **L4 工具层** | Skill + Practice Box | 给经纪人，实时辅助+反复练 | 工具  | 🔧 产品方协作 |

**类比**：
- L1 = 学习机的操作系统（设计语言、底层逻辑）
- L2 = 学习机里的课程内容（能直接学的东西）
- L3 = 练习册+考试卷（能直接练、能评估的东西）
- L4 = 学习机硬件（载体）

**V0.6的差距**：只有L1框架和L4工具，缺L2内容和L3产品。培训人要做的是把L1变成L2和L3。

### 2.2 培训人vs产品方：分工与关系

| 维度    | 培训方（花桥）                | 产品方（王源团队）                 |
| ----- | ---------------------- | ------------------------- |
| 我们做什么 | 沉淀4×7能力图谱、生产培训课件和训练产品  | 做AI工具、Practice Box、及时反馈系统 |
| 我们的底层 | 人+AI发展出来的，我们懂人也懂业务     | 大数据跑出来的，更全面但没有人味          |
| 语料从哪来 | 和城市共创过程中**水到渠成**收集     | 需要大量干净语料蒸馏训练              |
| 我们不做  | 只做语料收集的下游              | 替代培训人的判断和链接               |
| 协作方式  | 培训方先沉淀能力和内容 → 产品方封装成工具 | 产品方提供工具框架 → 培训方填入内容和标准    |

**核心**：培训方不是产品方的下游工具。4×7能力图谱是独立于产品的培训底层——**当产品没有时，4×7还能跑；当4×7没有时，产品是盲盒。**

### 2.3 各方价值主张

> **"谁都不愿意当上下游的工具，赵总参与的动机是什么？"** ——金燕

| 参与方 | 他们在意什么 | 参与理由 |
|--------|------------|----------|
| **城市总（赵总）** | 团队能力提升、自己的管理抓手 | 借4×7看清团队差距，获得可操作的管理工具 |
| **客赋中心** | 培训能落地、有内容可交付 | 获得花桥的培训课件和萃取工具，赋能一线 |
| **运营管理者** | 业绩提升、解决场景痛点 | 在共创中发现业务场景的解法，找到培训契机 |
| **店东** | 经纪人成长、门店业绩 | 获得量身定制的经纪人评估和训练方案 |
| **经纪人** | 开单、解决客户问题 | 在案例拆解中发现自己的能力差距和成长方向 |
| **产品方（西元/王源）** | 干净语料、可蒸馏的优秀行为标准 | 培训方沉淀的案例和行为标准，是产品的优质语料 |

**设计原则**：每一方参与的理由必须是"对我有价值"，而不是"帮花桥完成任务"。

## 三、重庆共创方案

### 3.1 核心定位：验证+产出培训产品雏形

V0.6定位"验证，不是产出"，V0.7升级为**"验证+产出培训产品雏形"**：

| 验证项         | 问题                             | 通过标准       |
| ----------- | ------------------------------ | ---------- |
| **框架能被听懂**  | 参与者能否理解4×7的基本逻辑？               | 能用自己的话复述框架 |
| **共创能产出讨论** | 小组案例拆解产出的差异度和深度如何？             | 有价值的争议点被识别 |
| **产出有落地意愿** | 城市团队会不会真的用这份能力图谱？              | 主动约定后续合作   |

**新增——培训产品雏形产出**：

| 产出项 | 性质 | 对应产出物层 |
|---|---|---|
| 6个TOP案例的4×7拆解 | 素材 | L1框架层 |
| 28格行为标准共识（初版） | 内容 | L2内容层 |
| 1套可演示的案例萃取流程 | 方法 | L2内容层 |
| Skill使用意愿和反馈 | 验证 | L4工具层 |

三件全过 → 深圳直接复制。卡在哪件 → 深圳前先迭代。

### 3.2 设计原则

| 原则                    | 说明                                                           |
| --------------------- | ------------------------------------------------------------ |
| **先体验后展示**            | 不先秀肌肉，先让参与者自己做案例拆解，体验痛苦和卡点，再展示Skill作为助力。**培训的核心是让人体验痛苦，知道能和不能的地方，然后在不能的地方给助力。** |
| **先案例后框架**            | 不从宏观时代背景讲起，用城市案例让参与者感受服务者能力的差距，再用框架标注                        |
| **先给样本再共创**           | 给付振博/张良平样本版本让大家理解顾问型经纪人的能力体系，降低入门门槛                          |
| **不同案例对比**            | 不同优秀的案例不同人拆解的差异和最终共识，是最好的学习素材                                |
| **通用框架+本土内容**         | 框架由花桥提供，内容由城市共创填入                                            |
| **每方参与必有理由**          | 不让任何一方觉得自己是工具，设计每个人的获得                                       |

> **核心逻辑变更说明（v0.6→v0.7）**：V0.6中Skill演示和讲解放在第二部分（共创前），意图是"先秀肌肉再让大家用"。金燕指出这违反培训基本逻辑——"你都跑马拉松10年了，我连1km都不愿意跑，你给我Skill我根本不屑。但我自己跑5km真累，我就会问你：那我怎么跑马拉松？"**正确顺序：先让参与者自己做→体验卡点→再展示Skill助力→眼前一亮。**

### 3.3 阶段性目标（共创场）

| 层面       | 目标                                                                                                     |
| -------- | ------------------------------------------------------------------------------------------------------ |
| **认知层面** | 1. 初步**认识**经纪人顾问型服务能力体系落地的框架逻辑（L1做什么→L2做多好→L3找根因→L4看长期）<br>2. 从**业务或运营**的视角，让共创伙伴看到4×7对于一线提效赋能的作用 |
| **产出层面** | 1. 完成至少**1个真实的消费者服务案例的两层拆解**-4×7格/案例评估<br>2. 完成共创场6个TOP案例4×7=28格行为标准共识<br>3. **体验案例萃取的全流程，发现卡点，为后续培训课件设计提供依据** |
| **关系层面** | 1. 建立与城市的协作信心<br>2. 选出3个陪跑门店（愿者上钩）<br>3. **让城市管理者在共创中感受到"这件事对我有价值"** |

### 3.4 共创形式与流程设计

**时间**：6月18日下午，4小时
**主题**：以消费者为中心的顾问型服务者能力探索
**参与者**：重庆城市核心骨干（建议20-30人）

**流程设计（v0.7重设计）**：

| 环节       | 内容                                                                                                                        | 时长        | 形式         |
| -------- | ------------------------------------------------------------------------------------------------------------------------- | --------- | ---------- |
| **开场**   | 破冰+为什么今天坐在这里（AI时代——顾问型经纪人）                                                                                                | 10分钟      | 讲授         |
| **第一部分：认知建立** | 1.赵忠祥——一线业务视角：重庆顾问型经纪人的画像与成长方向<br>2.老关——培训赋能视角：AI时代之下培训赋能更敏捷/智能<br>3.引出4×7能力体系的四层结构 | 40分钟      | 嘉宾轮流分享+互动 |
| **第二部分：体验痛点** | 1.呈现付振博/张良平示范案例的关键信息（不给完整拆解）<br>2.**各小组用自己真实的消费者服务案例，尝试按4×7框架拆解**<br>3.聚焦**L1(4×7宫格)拆解**，5人1小组（1个案主，4个萃取人）<br>4.预计产出6个TOP案例的初版拆解 | **90分钟** | 小组共创+引导 |
| 休息       | ——                                                                                                                        | 15分钟      | — |
| **第三部分：看见助力** | 1.**收敛共创中的卡点和差异**：各组拆解的差异在哪？共识了什么？争议了什么？<br>2.**展示Skill**：你们刚才拆解的痛苦，Skill可以帮你——现场演示，用刚才的案例跑一遍Skill<br>3.基于6个TOP案例，产出4×7格行为标准共识 | **50分钟** | 引导者演示+全员讨论 |
| **收敛**   | 1.共识收敛（示范案例收敛：L1-L4）<br>2.后续约定（愿者上钩：选3个试跑门店；**陪跑核心价值：**量身定一系列门店评估的SKILL，帮助门店实时观察经纪人的成长）<br>3.**每方收获确认**：城市、店东、经纪人各获得什么 | 25分钟      | 全员讨论       |

**v0.6→v0.7流程变更对照**：

| 变更点 | v0.6 | v0.7 | 原因 |
|---|---|---|---|
| Skill展示位置 | 共创前（第二部分） | 共创后（第三部分） | 先体验痛苦，再给助力 |
| 嘉宾分享时长 | 20分钟（两人共） | 40分钟（各约20分钟） | 老关一个人就能讲20分钟 |
| 共创时长 | 120分钟 | 90分钟 | 先聚焦L1拆解，不贪全 |
| 新增卡点收敛 | 无 | 第三部分专门收敛卡点和差异 | 让参与者看见自己的痛点，Skill才有价值 |
| 新增收获确认 | 无 | 收敛环节确认各方收获 | 让每方明确"我获得了什么" |

### 3.5 案例应用策略

**付振博案例**：Z1+Z2的L3示范样本，用来教方法、建立体感
**重庆案例**：城市共创的主体素材，用来验证框架、产出本土内容

> **注意**：付振博案例在第二部分只呈现关键信息，不给完整拆解。完整拆解在第三部分展示Skill时作为演示素材——"你们刚才拆解遇到的困难，Skill可以帮你这样拆"。

## 四、后续合作方案

### 4.1 多轮共创模式

| 轮次      | 时间    | 目标                               | 形式    |
| ------- | ----- | -------------------------------- | ----- |
| **第一轮** | 6月18日 | 验证框架 + 4×7格共创+体验萃取流程 + 与城市建立关系 | 线下工作坊 |
| **第二轮** | 7月    | 输出试点门店的人才评估报告+沉淀可复用的Skill和流程+**产出培训课件初版** | 线上/线下 |
| **第三轮** | 8月    | 扩大城市案例库，不断修正Skill和流程，协同客赋规模推广+**产出训练产品包** | 线上协作  |

### 4.2 陪跑设计

**陪跑的核心价值**：不是帮产品方收集语料，而是**在水到渠成的过程中发现人的训练契机**。

| 角色 | 花桥TODO | 店东TODO |
|------|---------|---------|
| **萃取** | 输出萃取Skill，赋能店东 | 参与萃取Skill的共创和学习，试点期间按流程完成门店X个经纪人的萃取，交付评估报告 |
| **陪跑** | 下店陪跑3个好中差经纪人（优秀标准：能独立完成一张单子，业绩要求，对应环节表现优秀），并完成萃取 | 组织门店对应的经纪人3+X，按要求积累录音，配合萃取 |
| **案例库** | 建优秀案例库，将来共享，作为标杆展示；建差的案例库，作为避坑指南 | 能安排经纪人参与后续的针对性练习，以便观测结果 |
| **评估** | 生成试点门店的评估报告，汇总，给管理层参考 | — |
| **培训产品** | 基于陪跑中的发现，**提炼培训课件和训练产品** | 在使用评估和训练方案的过程中，**反馈产品优化方向** |

### 4.3 萃取质量标准

> **"语料质量怎么把控？花桥课程有7件套，那我们有什么？"** ——金燕

| 质量维度 | 标准 | 拉齐工具 |
|--------|------|----------|
| **框架对齐** | 萃取内容必须能对应到4×7的28格中 | 4×7框架本身就是质量拉齐工具 |
| **能力解读** | 每格的能力定义有共识版本 | 能力解读初稿+共创共识 |
| **行为可观察** | 描述的是可观察的行为，不是抽象的能力词 | 行为描述模板（场景→问题→行为→标准） |
| **案例有场景** | 每个行为都有对应的消费者服务场景 | 场景卡片模板 |
| **评价有刻度** | 行为标准有优秀/及格/不及格三档 | 2D水位标尺 |

**迭代逻辑**：
1. 第一轮萃取：每个人交出来的版本一定不同（90分/70分/60分）
2. 互看互学：三方看彼此的东西，自我学习+他人学习
3. 融合迭代：从0.1版→1.0版→1.1版→城市共创版
4. 标准收敛：多轮迭代后，共性部分自然沉淀为质量标准
