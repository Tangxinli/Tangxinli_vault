# 2D 水位标尺：能力深度 × 立场强度

> 28 格矩阵告诉你"做什么"，但同样在做一件事，谁做得好？
> 水位标尺给出一把尺子：把"做得好不好"摊到二维平面上。

---

## 为什么是两条轴

听过太多评级是单维的——"这个人 80 分"——但 80 分的两个人可能完全不是一回事。

王源评估资料库 600+ 案例归纳出来：差距不是一维的"高/低"，是两个**正交**的维度——

- **能力深度**——能不能看见、能不能拍板、能不能落地
- **立场强度**——你在替谁说话

一个能看得清但不敢拍板的人（深度高、立场弱），和一个敢拍板但看错方向的人（立场强、深度低），是两种完全不同的失败。所以要分开量。

---

## Y 轴：能力深度

> 从下往上是因果链——**视野 → 判断 → 行动**。下层缺位，上层一定塌。

### Y1 视野（最低层）
**看得见的能力。**
- 看得见房源缺陷、市场可比盘、政策窗口、客户隐性需求
- 反例：客户问"这房楼层会不会有遮挡"，回答"应该还行吧"——没看见
- 入门门槛：能列出当前案例的至少 3 个"客户没看见但你看见了"的点

### Y2 判断（中层）
**敢拍板的能力。**
- 在视野的基础上，给出有立场、有依据、可被追问的明确结论
- 反例：看见了所有问题，但是说"您再考虑下"——看见≠敢说
- 入门门槛：敢说"我建议出 X / 别出"，并能解释依据

### Y3 行动（最高层）
**能落地的能力。**
- 把判断变成有时间、有责任方、有反馈回路的具体下一步
- 反例：判断给了，路径却是"那您回去想想"——判断悬空
- 入门门槛：客户走出去能复述出"接下来三件事"

**关键：不是平行的三选一，是叠加的三层。** 行动不行的人通常判断也不稳，判断不行的人通常视野也窄——但反过来不一定（视野好的人可能不敢判断）。

---

## X 轴：立场强度

> 从左到右是**同盟的强度**——你在为谁服务。

### X1 信息中转（最弱）
- "业主说了算" / "您再考虑" / "市场不确定"
- 把判断责任推回客户和业主之间，自己不站位
- 客户感受：这人就是个传话筒

### X2 中性平衡（中等）
- 把利弊摆给客户，自己不偏
- "这套有 ABC 优点，也有 XYZ 缺点，您权衡"
- 客户感受：他比较专业，但好像也没在帮我

### X3 立场鲜明（最强）
- **敢说违背自身短期利益的话**——"这套别买" / "这价别出" / "现在别卖"
- 落点是"客户长期利益"而不是"这单成交"
- 客户感受：这人是站在我这边的，他的判断我可以信

**最锋利的检验**：能不能给出**反向判断**（拒绝一笔本可以做的生意）。
- 不能 → X1（哪怕话术再花哨）
- 偶尔能 → X2
- 习惯性能 → X3

## 二维平面与 L1 / L2 / L3 等高线

```
立场强度 X →
┌─────────────────────────────────────────────────┐
│       X1 中转           X2 中性          X3 立场│
│                                                 │
│Y3 行动                                       ★ │ ← L3 区
│        ──────────────────────────  L3 等高线  │
│Y2 判断                              ●          │ ← L2 区
│        ──────────────────────────  L2 等高线  │
│Y1 视野           ○                              │ ← L1 区
└─────────────────────────────────────────────────┘
                                  能力深度 Y ↑
```

**等高线的含义**：综合定级 = 两个维度的最小值（短板决定）

- **L1 ○**——任意一个维度处于最低水平
  - 视野到位但完全不敢站位（Y3 + X1） → 仍是 L1
  - 立场鲜明但完全看不见（Y1 + X3） → 仍是 L1（瞎热情比冷漠更坑）
  - 资料库 578 案例中 394 个落这里（68%）

- **L2 ●**——两个维度都至少到中段
  - 看得见、能给判断（Y2）+ 中性平衡（X2）
  - 不会犯大错，但客户记不住你
  - 资料库 184 个（32%）

- **L3 ★**——两个维度都达到顶端
  - 视野 + 判断 + 行动俱全（Y3） × 立场鲜明，敢说不（X3）
  - 资料库 4 个（不到 1%）——星级稀缺，不是评级吝啬，是真稀缺

## 为什么是双锚点

王源评估方法论里的"2A 核心判断 × 3B 推进跟进"双锚点，本质上就是这个二维标尺的实操版：

- **2A 核心判断** ≈ Y2 判断（能力深度的关键指标）
- **3B 推进跟进** ≈ Y3 行动（能力深度的落地指标）
- 任意一个 L1 → 整体定级锁死 L1

为什么不取平均？因为这两件事是**门槛**而不是**加分项**：
- 判断是 L1，再多的视野只是"信息搬运得很全"
- 行动是 L1，再准的判断只是"会议室里的诊断"

**门槛逻辑 = 短板逻辑 = 木桶。** 平均分会让"九维全 80 分"看起来很好，但实际上无人受益。

## 用法

### A. 给一次具体服务定级
读完一份评估，用两条轴各打一次：
1. 这次他的能力深度到哪一格？（看 2A、3B 两个评估维度）
2. 他的立场强度到哪一格？（看有没有给反向建议、有没有信息透明）
3. 取最小值定级

### B. 看一个人长期水位
不是看一次最好的样子，是看**最差的下限稳定在哪条等高线之上**。
- L3 选手 = 最差的一次也不会跌破 L2

### C. 设计提升路径
- 现在 X1 Y2（敢判断但不站位）→ 该练的是诚实、敢说不（X 轴右移）
- 现在 X3 Y1（站得稳但看不见）→ 该练的是数据敏感度、信息提取（Y 轴上移）

**两个轴对应不同的训练路径，混了就会瞎练。**

## 一句话压缩

> **能力深度决定你能不能服务，立场强度决定你在替谁服务。**
> **两轴俱佳，才是真 L3。**
