# 付振博案例萃取：四人沟通版

> **目的**：下周四人沟通会上展示我的案例萃取成果
> **案例来源**：付振博访谈逐字稿
> **萃取框架**：4×7能力框架

---

## 一、案例概述

| 项目 | 内容 |
|------|------|
| **客户画像** | 香港客户，两个儿子（12岁、7岁），北京大妞，老公做风投，7月份公公婆婆从美国回来 |
| **需求表达** | "我在香港，想在大理商场酒店旁买带装修的别墅或顶层复式，预算1000万，5月份买" |
| **成交结果** | 1200万精装别墅，从接触到签约约2周 |
| **关键特征** | 高净值客户、时间紧迫、需求表达简洁但真实需求复杂 |

---

## 二、核心发现：付振博展现的顾问型服务能力

### 发现1：判断客户真伪的能力（C1阶段）

**情境**：收到香港客户的简洁短信，多数经纪人会判断为"骗局"或"假客户"

**付振博的做法**：
- 知道"香港骗局"的模式（资金兑换骗局）
- 但没有被模式困住，而是用语音通话验证假设
- 判断依据：客户能说出"为什么找你"的真实理由

**能力映射**：
| 维度 | 表现 |
|------|------|
| 视野 | 看得见骗局模式，但不过度依赖模式 |
| 判断 | 主动验证假设，而非直接拒绝或接受 |
| 同盟 | 中性起点，不预设判断 |

---

### 发现2：需求排序的能力（C2阶段）

**情境**：客户说"别墅或复式"，但实际需求更复杂

**付振博的做法**：
- 通过对话提取核心需求：孩子撒欢的空间
- 一句话反向判断：**"你要的不是复式，是带院子的别墅"**
- 帮客户做需求减法，排除复式选项

**关键原话**：
> "你为什么一定要有室外空间？"
> "因为在香港孩子没有撒欢的空间，我希望孩子能有一个。"

**能力映射**：
| 维度 | 表现 |
|------|------|
| 视野 | 听出未说出口的需求（孩子成长空间） |
| 判断 | 给出反向判断，纠正客户需求方向 |
| 同盟 | 站在客户真实需求一边，而非迎合客户表达 |

---

### 发现3：带看动线设计的能力（C3阶段）

**付振博的策略**：AABC四盘策略

| 盘位 | 作用 | 他的判断 |
|------|------|----------|
| A盘 | 客户自己挑的 | "知道她不会喜欢，但还是要带看" |
| A盘 | 也是客户挑的 | "她看不上审美" |
| **B盘** | 他推荐的精装别墅 | "她一定会喜欢" |
| C盘 | 备选 | 没看就定了 |

**关键洞察**：
- 让客户自己排除A盘，而不是经纪人直接否定
- B盘是他判断客户一定会喜欢的（精装、大花园、家具全送、时间刚好）

**能力映射**：
| 维度 | 表现 |
|------|------|
| 视野 | 产品匹配逻辑：时间（7月入住）+ 需求（孩子空间）+ 条件（精装） |
| 判断 | "她一定会喜欢"——提前判断客户反应 |
| 行动 | 带看动线设计有明确目的 |

---

### 发现4：敢说"别买"的能力（信任建立）

**情境**：客户看完大平层很激动，想买

**付振博的做法**：
- 拦住客户："你不要买"
- 理由：不符合需求（不够住、没有院子）

**关键原话**：
> "王小姐，我和一般的经纪人不一样，我不等着开单吃饭。我不能因为想赚一点佣金，让你把1000多万放在这个不符合你需求的地方。"

**客户后来反馈**：
> "你有两个点让我特别相信你。第一个就是我在那个地方想买的时候你不让我买。"

**能力映射**：
| 维度 | 表现 |
|------|------|
| 同盟 | **X3立场**：敢说违背自身短期利益的话 |

**这是X3立场的关键检验**：能不能给出反向判断（拒绝一笔本可以做的生意）

---

### 发现5：签约障碍处理的能力（C6阶段）

**情境**：客户没有人民币账户，1000多万转不过来

**付振博的做法**：

| 典型L1经纪人的做法 | 付振博的做法 |
|-------------------|--------------|
| 急着催定金 | **不催**，反而安慰客户"别有压力" |
| 把问题抛给客户 | 陪客户去银行，协调开发商 |
| 让客户觉得自己没钱 | **识别客户心理变化**：她怕被认为"不是决策者" |

**关键原话**：
> "这个时候他心里面是最乱、最矛盾、最脆弱的时候。你唯一能做的就是**别吭声，坐着陪他**。"
> "促签约？他走了你还促签约？"

**能力映射**：
| 维度 | 表现 |
|------|------|
| 视野 | 看见客户的心理状态（焦虑、脆弱） |
| 情绪共感 | 读出客户犹豫背后的真实焦虑 |
| 行动 | 不催定金，而是陪伴和协调 |

## 三、水位判断

### 按2D标尺定位

**Y轴（能力深度）**：
- Y1 视野 ✓（看见骗局模式、隐性需求、产品匹配逻辑）
- Y2 判断 ✓（给出反向判断、需求排序）
- Y3 行动 ✓（带看动线设计、障碍处理）

**X轴（立场强度）**：
- X3 立场 ✓（敢说"别买"、不催定金、站在客户长期利益）

**定位：Y3 × X3 = L3 ★**

### 按8项底层能力验证

| 根能力 | 案例体现 | 评估 |
|--------|----------|------|
| 信息提取力 | 从简洁短信提取真客户信号 | ✓ |
| 结构化思考 | 需求排序减法、AABC策略 | ✓ |
| 数据敏感度 | 预算上浮30%（考虑装修成本） | ✓ |
| 承担判断的勇气 | "你要的不是复式是别墅" | ✓ |
| 情绪共感 | 识别签约时的焦虑心理 | ✓ |
| 时间结构能力 | 带看动线、三步路径 | ✓ |
| 冲突中的中正 | 不偏业主不偏买家 | ✓ |
| 诚实 | 不让买大平层、不催定金 | ✓ |

**结论**：8项底层能力全部到位，这是真正的L3。
