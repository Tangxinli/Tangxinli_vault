# 第四次研讨会·金燕指导纪要

**会议性质：** 项目脑暴会（唐文莉汇报共创方案，金燕点评与方向指引）
**参会人：** 唐文莉（糖心莉）、金燕（燕儿姐）
**角色分工：** 唐文莉汇报共创方案 → 金燕给出战略思考、流程建议和思维转变指引

## 一、金燕对4×7项目的战略思考

### 1.1 培训人的根本定位

> **"我不是收集语料的工具，我是人的发现者、培训契机的发现者。"** ——金燕

金燕明确提出培训团队在4×7项目中的定位不是产品方的下游执行者，而是独立的、有底层价值的专业角色：

| 培训人是 | 培训人不是 |
|----------|------------|
| 知其根、知其因的培训人 | 语料收集的下游工具 |
| 能力图谱的沉淀者 | 框架的搬运工 |
| 人的链接者、培训契机发现者 | 产品方的附属执行者 |
| 课件、知识、培训产品的生产者 | 只做能力拆解的文案员 |

**核心判断**：4×7能力图谱是培训人要沉淀出来能看得见的东西。当产品没有的情况下，这个还是可以跑的；但如果只有产品没有4×7，那大家对这件事情是盲盒。**两者互补，但培训方有独立于产品的底层价值。**

### 1.2 产出物的重新定义

> **"你培训人是不是要有课件？要有知识？要有培训产品？"** ——金燕

金燕指出v0.6方案的产出物只有框架+工具，缺少了培训产品层。培训人不能只交出框架和语料，必须产出能直接用于培训的课件和产品：

| 层 | 产出 | 对谁 | 性质 |
|----|------|------|------|
| L1 框架层 | 4×7能力体系+能力解读 | 给管理层/项目组，共识语言 | 骨架 |
| L2 内容层 | 28格的标准化培训课件 | 给培训师，能直接讲 | 血肉 |
| L3 产品层 | 可交付的训练包（场景+标准+练习+评估） | 给一线，能直接练 | 产品 |
| L4 工具层 | Skill + Practice Box | 给经纪人，实时辅助+反复练 | 工具 |

**v0.6的差距**：只有L1框架和L4工具，缺L2内容和L3产品。培训人要做的是把L1变成L2和L3。

### 1.3 各方价值主张

> **"谁都不愿意当上下游的工具，赵总参与的动机是什么？"** ——金燕

金燕要求方案中每一方参与的理由必须是"对我有价值"，而不是"帮花桥完成任务"。这一要求推动了v0.7中"各方价值主张"板块的新增：

| 参与方 | 参与理由 |
|--------|----------|
| 城市总（赵总） | 借4×7看清团队差距，获得可操作的管理工具 |
| 客赋中心 | 获得花桥的培训课件和萃取工具，赋能一线 |
| 运营管理者 | 在共创中发现业务场景的解法，找到培训契机 |
| 店东 | 获得量身定制的经纪人评估和训练方案 |
| 经纪人 | 在案例拆解中发现自己的能力差距和成长方向 |
| 产品方 | 培训方沉淀的案例和行为标准，是产品的优质语料 |

### 1.4 萃取质量标准

> **"语料质量怎么把控？花桥课程有7件套，那我们有什么？"** ——金燕

金燕要求建立萃取质量标准，不能让各方交上来的东西参差不齐、无法比较。4×7框架本身就是质量拉齐工具——萃取内容必须能对应到28格中，行为必须可观察，评价必须有刻度。

## 二、金燕对重庆共创流程的核心建议

### 2.1 核心原则：体验先行、标准后置

> **"培训的核心是让人体验痛苦，知道能和不能的地方，然后在不能的地方给助力。"** ——金燕

金燕指出v0.6方案中Skill演示放在共创之前，违反培训基本逻辑：

> **"你都跑马拉松10年了，我连1km都不愿意跑，你给我Skill我根本不屑。但我自己跑5km真累，我就会问你：那我怎么跑马拉松？"** ——金燕

**正确顺序**：先让参与者自己做 → 体验卡点 → 再展示Skill助力 → 眼前一亮

| 调整项 | v0.6（原方案） | v0.7（金燕建议后） | 背后逻辑 |
|--------|----------------|---------------------|----------|
| Skill展示位置 | 共创前（第二部分） | 共创后（第三部分） | 先体验痛苦，再给助力 |
| 共创重点 | 贪全（L1-L4全拆） | 先聚焦L1拆解，不贪全 | 降低入门门槛，先跑通一个闭环 |
| 新增卡点收敛 | 无 | 第三部分专门收敛卡点和差异 | 让参与者看见自己的痛点，Skill才有价值 |
| 新增收获确认 | 无 | 收敛环节确认各方收获 | 让每方明确"我获得了什么" |

### 2.2 流程节奏调整

- **嘉宾分享时长**：从20分钟（两人共）调至40分钟（各约20分钟）——金燕指出老关一个人就能讲20分钟
- **共创时长**：从120分钟调至90分钟——先聚焦L1拆解，不贪全
- **案例呈现方式**：付振博案例在共创环节只呈现关键信息，不给完整拆解；完整拆解在Skill演示环节作为"你们的痛苦我能解"的素材

### 2.3 共创形式建议

金燕对共创的实操形式给出了几个具体建议：

- **问题清单收集**：共创中要求学员记录拆解案例时遇到的困难，作为后续教学内容调整的依据
- **同伴互评机制**：小组间互相展示拆解成果，让学员在对比中自我对齐标准
- **混合编组策略**：总监层级与优秀经纪人混合分组，收集不同角色视角下的拆解逻辑

## 三、金燕对唐文莉思维模式转变的建议

金燕的指导不仅是方案调整，更深层是对唐文莉思维模式的三个转变要求：

### 3.1 从"语料工具"到"培训人"

唐文莉原方案中培训团队的定位偏向"为产品方收集语料"的执行角色。金燕明确要求：**你不是收集语料的工具，你是人的发现者、培训契机的发现者。**

这意味着：
- 不再以"给产品方交语料"为终点，而以"沉淀培训产品"为终点
- 语料是共创过程中**水到渠成**的副产品，不是培训人的核心交付物
- 培训人的独立价值在于：**当产品没有时，4×7还能跑；当4×7没有时，产品是盲盒**

### 3.2 从"验证"到"验证+产出"

唐文莉v0.6的定位是"验证，不是产出"。金燕推动升级为"验证+产出培训产品雏形"：

| 维度 | v0.6思维 | v0.7思维 |
|------|----------|----------|
| 共创定位 | 只是验证框架能不能跑通 | 验证的同时必须产出东西 |
| 产出预期 | 框架验证结果 | 6个TOP案例拆解 + 28格行为标准共识初版 + 1套萃取流程 |
| 后续节奏 | 验证完再说 | 7月出培训课件初版，8月出训练产品包 |

> **"1.0版做出来了，后面呢？"** ——金燕

### 3.3 从"标准先行"到"体验先行"

这是金燕对唐文莉最核心的思维转变要求。唐文莉习惯先展示标杆、再让大家对照学习（专家思维）。金燕指出：**你先跑了10年马拉松，你给我看奖牌我没感觉。但我自己跑5公里累死了，我就会问你：怎么才能跑完？**

| 维度 | 原思维（标准先行） | 新思维（体验先行） |
|------|---------------------|---------------------|
| 起手 | 先展示标准答案 | 先让学员自由拆解 |
| 学员状态 | 被动接受 | 主动暴露盲点 |
| 标准出场时机 | 一开始就给 | 经历痛苦后再给 |
| 学习驱动力 | "你应该学这个" | "我想要这个" |

**这一思维转变不只是共创流程的调整，而是培训哲学的根本切换**——从"教"到"学"，从"给"到"要"。

## 四、金燕指导对唐文莉后续工作的直接影响

金燕的指导直接推动了v0.7方案的六大变更，也明确了唐文莉接下来要做的事：

| 金燕指导 | 对唐文莉的要求 | 具体产出 |
|----------|----------------|----------|
| 培训人不是语料工具 | 重新定义培训团队角色和产出 | 共创方案v0.7 §1.3、§2.1 |
| 要有课件、知识、培训产品 | 产出物从2层扩展到4层 | 共创方案v0.7 §2.1 |
| 先体验后展示 | 共创流程重设计 | **共创流程表格**（待产出） |
| 谁都不愿意当工具 | 每方参与必有理由 | 共创方案v0.7 §2.3 |
| 语料质量怎么把控 | 建立萃取质量标准 | 共创方案v0.7 §4.3 |
| 1.0版做出来了后面呢 | 明确7月/8月产出节奏 | 共创方案v0.7 §4.1 |

**唐文莉当前最紧迫的两项产出**：

2. **共创课件**：基于"体验先行、标准后置"的流程设计，制作能直接用于6月18日共创场的课件
