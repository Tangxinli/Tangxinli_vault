# 共创流程表格与课件梳理

**目标**：基于金燕的方向建议，明确唐文莉需要产出的两样东西怎么做——共创流程表格 + 共创课件
**依据**：金燕指导纪要 + 共创方案v0.7

---

## 一、共创流程表格：应该怎么做

### 1.1 流程表格的定位

共创流程表格不是课程大纲，是**执行脚本**——谁在什么时间、说什么话、做什么动作、期待什么产出、可能出现什么卡点，全部写清楚。一个没参与过方案设计的人，拿着这张表也能引导共创。

金燕的核心要求：**体验先行、标准后置**。流程表格的每一分钟都要贯彻这个逻辑。

### 1.2 表格结构建议

每一行是一个环节，包含以下字段：

| 字段 | 说明 | 为什么需要 |
|------|------|------------|
| **环节名称** | 如"开场""认知建立""体验痛点" | 定位清晰 |
| **时长** | 精确到分钟 | 4小时有限，必须卡时 |
| **环节目标** | 这个环节结束，参与者要达成什么 | 金燕要求每步都有产出 |
| **流程步骤** | 第1步→第2步→第3步 | 引导者的执行手册 |
| **引导话术要点** | 关键转折点说什么 | 避免即兴发挥跑偏 |
| **互动形式** | 讲授/小组共创/同伴互评/全员讨论 | 金燕要求多种互动 |
| **产出物** | 这个环节结束时产出了什么 | 金燕要求产出培训产品雏形 |
| **卡点预判** | 可能出什么问题、怎么应对 | 体验先行，卡点是教学素材 |
| **课件对应** | 这个环节用到课件哪几页 | 流程表和课件一一对应 |
| **物料准备** | 需要什么材料/工具 | 提前准备，现场不慌 |

### 1.3 流程框架（基于v0.7方案细化）

以下是基于v0.7方案的流程框架，每一环节需填入上述字段：

| 时间 | 环节 | 核心逻辑 |
|------|------|----------|
| 0:00-0:10 | **开场** | 破冰 + 为什么坐在这里（AI时代→顾问型经纪人） |
| 0:10-0:50 | **第一部分：认知建立** | 嘉宾分享（赵忠祥一线视角 + 老关培训视角）→ 引出4×7四层结构 |
| 0:50-2:20 | **第二部分：体验痛点** | 呈现示范案例关键信息 → 小组自由拆解 → 暴露盲点和卡点 |
| 2:20-2:35 | 休息 | — |
| 2:35-3:25 | **第三部分：看见助力** | 收敛卡点和差异 → 展示Skill → 产出28格行为标准共识 |
| 3:25-3:50 | **收敛** | 示范案例收敛L1-L4 → 后续约定 → 每方收获确认 |

### 1.4 每个环节需要特别细化的问题

**开场（10分钟）**
- 第一句话说什么？如何把"AI时代"这个大话题在3分钟内落到"你今天的客户需要什么"？
- 破冰用什么方式？和4×7有什么关联？

**第一部分：认知建立（40分钟）**
- 赵忠祥分享的具体议题和时长分配？
- 老关分享的具体议题和时长分配？
- 两位嘉宾分享后，如何过渡到4×7四层结构？过渡话术？
- 嘉宾分享环节，参与者有没有互动？还是纯听？

**第二部分：体验痛点（90分钟）**——**最核心环节，需最细的脚本**
- 示范案例（付振博/张良平）呈现到什么程度？只给信息，给哪些信息？
- 小组如何编组？5人1组（1个案主+4个萃取人）的分工怎么分配？
- 拆解指引给到什么程度？给4×7空表格就算指引，还是需要更多？
- 拆解过程中引导者做什么？巡场？记录？干预？
- **关键：如何确保参与者"真的拆不动"，而不是"随便填填就过了"？**
- 90分钟内的时间切割：读案例→讨论→填写→组内对齐→准备展示，各多长时间？
- 问题清单怎么收集？纸笔记录？白板？线上？

**第三部分：看见助力（50分钟）**
- 如何从"各组拆解差异"自然过渡到"Skill能帮你们"？
- Skill演示用哪个案例？用参与者的还是付振博的？
- 28格行为标准共识的产出方式：全员讨论？引导者整理？投票？
- 如果时间不够，哪些可以砍？哪些不能动？

**收敛（25分钟）**
- 示范案例L1-L4收敛，用什么方式呈现？PPT？白板？
- "愿者上钩"选3个试跑门店——怎么选？现场举手？城市总指定？
- 每方收获确认的具体形式？

### 1.5 流程表格的输出格式建议

建议用以下格式，一个环节一张表：

```
### [环节名称] | [时间]

**目标**：xxx
**产出物**：xxx

| 步骤 | 时长 | 引导者动作 | 参与者动作 | 话术要点 | 课件页码 |
|------|------|------------|------------|----------|----------|
| 1 | 3min | xxx | xxx | xxx | P3 |
| 2 | 5min | xxx | xxx | xxx | P4-P5 |
| ... | ... | ... | ... | ... | ... |

**卡点预判**：
- 可能出现xxx → 应对：xxx

**物料准备**：
- xxx
```

## 二、共创课件：应该怎么做

### 2.1 共创课件的定位

共创课件不是传统培训PPT——不是"我讲你听"，而是**共创场的引导脚本可视化**。课件的核心功能是：

1. **信息呈现**：在需要传递信息时（开场、认知建立、Skill演示），课件承载内容
2. **指令发布**：在需要参与者行动时（拆解案例、互评、讨论），课件给出明确的任务指令和时间
3. **框架标注**：在共创产出时（拆解表、共识卡），课件提供结构化的填写框架
4. **视觉锚点**：让参与者随时知道"现在在哪个阶段""要做什么"

金燕的要求：课件要让**培训师能直接讲**——这是L2内容层的核心产出物。

### 2.2 课件整体结构（基于流程设计）

| 课件模块 | 对应流程环节 | 页数估计 | 核心功能 |
|----------|--------------|----------|----------|
| **模块0：开场** | 开场（10min） | 3-5页 | 定调 + 破冰 |
| **模块1：认知建立** | 第一部分（40min） | 10-15页 | 嘉宾分享引导 + 4×7框架引入 |
| **模块2：体验痛点** | 第二部分（90min） | 5-8页 | 任务指令 + 拆解框架 + 时间提示 |
| **模块3：看见助力** | 第三部分（50min） | 8-12页 | 卡点收敛 + Skill演示 + 共识产出 |
| **模块4：收敛** | 收敛（25min） | 5-8页 | L1-L4示范 + 约定 + 收获确认 |
| **附录** | 参考材料 | 不限 | 能力解读、案例原文、评估工具 |

**注意**：模块2（体验痛点）页数最少但最重要——这个环节的主角是参与者，不是课件。课件只负责"发指令"和"给框架"，剩下的交给人。

### 2.3 每个模块的内容要点

**模块0：开场（3-5页）**

| 页 | 内容 | 设计要点 |
|----|------|----------|
| P1 | 封面：主题 + 日期 + 主办方 | 主题：以消费者为中心的顾问型服务者能力探索 |
| P2 | 破冰问题 | 直接问参与者：你最近一次觉得"这个客户我真的搞不定"是什么时候？→ 暖场+引出痛点 |
| P3 | 为什么今天坐在这里 | AI时代→信息播报机被替代→顾问型服务者是未来→今天来探索"什么叫行" |
| P4 | 今天的旅程地图 | 4小时流程预览（4个站点的视觉化），让参与者有全局感 |

**模块1：认知建立（10-15页）**

| 页 | 内容 | 设计要点 |
|----|------|----------|
| P5-P6 | 赵忠祥分享引导页 | 重庆顾问型经纪人的画像与成长方向 |
| P7-P8 | 老关分享引导页 | AI时代之下培训赋能更敏捷/智能 |
| P9-P12 | 4×7四层结构 | L1做什么→L2做多好→L3找根因→L4看长期，每层一页，用类比（医生全流程清单→实习vs主治→临床思维→5年后长成主任） |
| P13 | 28格矩阵总览 | 4能力×7阶段，让参与者第一次看见全貌 |
| P14 | 能力解读（简化版） | 理解力/判断力/路径力/立场力各一句话，不展开 |
| P15 | 过渡到体验环节 | "现在框架你们看到了，接下来——你们自己拆一个试试" |

**模块2：体验痛点（5-8页）**——**课件最精简的模块**

| 页 | 内容 | 设计要点 |
|----|------|----------|
| P16 | 示范案例呈现 | 付振博/张良平案例的关键信息（不给完整拆解），只呈现消费者服务过程 |
| P17 | 任务指令 | 明确任务：用4×7框架拆解你小组的案例 → 填写28格拆解表 → 记录你拆不动的地方 |
| P18 | 拆解框架表 | 4×7空表格，打印版+投屏版，让参与者填写 |
| P19-P20 | 时间提示 | "还剩30分钟""还剩10分钟，准备组内对齐"——课件只做计时器用 |
| P21 | 问题清单收集 | 提醒参与者记录：拆解中遇到什么困难？不理解什么？ |
| P22 | 组内准备展示 | "每组准备2分钟分享：你们拆了什么、卡在哪里" |

**模块3：看见助力（8-12页）**

| 页 | 内容 | 设计要点 |
|----|------|----------|
| P23 | 各组拆解差异对比 | 引导者现场整理的对比（白板/投屏），让参与者看见"不同人拆出了不同的东西" |
| P24 | 卡点收敛 | "刚才大家拆不动的，集中在这些地方"——从问题清单中提炼 |
| P25-P27 | Skill演示 | 用刚才的案例跑一遍Skill："你们拆了30分钟没拆出来的，Skill这样拆"——**碾压级对比** |
| P28 | 示范案例完整拆解 | 付振博案例L1-L4完整拆解展示——"这就是标准长什么样" |
| P29-P30 | 28格行为标准共识 | 引导全员讨论，逐步填写每格的行为标准共识 |
| P31 | 共识结果 | 本场产出的28格行为标准共识（初版） |

**模块4：收敛（5-8页）**

| 页 | 内容 | 设计要点 |
|----|------|----------|
| P32 | 示范案例L1-L4收敛 | 一个完整案例从"拆解→评估→根因→成长"的闭环展示 |
| P33 | 陪跑核心价值 | 量身定一系列门店评估的Skill，帮助门店实时观察经纪人的成长 |
| P34 | 后续约定 | 选3个试跑门店的方式和标准 |
| P35 | 每方收获确认 | 城市→店东→经纪人，各获得了什么 |
| P36 | 结束页 | 感谢 + "4×7的旅程，今天只是第一步" |

### 2.4 课件设计的三个关键原则

**原则一：体验环节课件最精简，主讲环节课件最详实**

| 环节 | 课件角色 | 页数 | 参与者注意力 |
|------|----------|------|--------------|
| 开场+认知建立 | 信息载体 | 15页 | 看课件 |
| 体验痛点 | 指令发布 | 7页 | 看案例+看人 |
| 看见助力 | 信息+对比载体 | 12页 | 看Skill+看差异 |
| 收敛 | 共识载体 | 8页 | 看产出 |

**原则二：每页只做一件事**

- 一页一个观点/一个指令/一个框架
- 绝不在一页上既讲框架又发任务
- 参与者抬头看一眼就知道"现在该做什么"

**原则三：可打印 > 只能投屏**

- 拆解框架表、28格空表格、问题清单——全部做成可打印版本
- 参与者手写 > 在屏幕上看——体感更真实，也便于收集
- 课件中的框架类页面，同步设计A3打印版，每组一份

### 2.5 课件之外需要同步准备的东西

课件只是冰山一角，以下物料必须和课件同步准备：

| 物料                | 用途                 | 准备方  |
| ----------------- | ------------------ | ---- |
| **示范案例打印版**       | 付振博/张良平案例关键信息，每组1份 | 唐文莉  |
| **4×7拆解表（A3打印版）** | 小组拆解时填写            | 唐文莉  |
| **问题清单卡片**        | 每人记录拆解困难的卡片        | 唐文莉  |
| **28格共识便签墙**      | 第三环节全员讨论时，便签贴墙     | 唐文莉  |
| **计时器**           | 90分钟拆解环节的时间提示      | 现场设备 |
| **Skill演示环境**     | 确保现场网络和设备能跑Skill   | 产品方  |
| **白板/翻页纸**        | 引导者现场整理对比和卡点       | 场地提供 |
