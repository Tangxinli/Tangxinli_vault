## 一、付振博案例 × 大S框架：帮你"看懂"四层结构

### 1.1 为什么看案例比看框架更容易懂？

大S的四层结构本身逻辑严密，但你带着"怎么用"的问题去读，会发现一个困境：

> L1矩阵列出了28格"应该做什么"，但**真正的高手不是在填表，而是在做一系列判断链**。

付振博案例的价值在于：**它让你看到，一个L3经纪人的28格，不是28个独立动作，而是7条连续的判断链。**

### 1.2 用付振博案例跑通四层结构

| 层 | 框架定义 | 在付振博案例中长什么样 |
|---|---------|---------------------|
| **L1** | 28格矩阵（做什么） | 7个阶段全走通：需求摸底→带看匹配→报价→信任建立→签约障碍→签后服务→长期陪伴 |
| **L2** | 2D水位（做多好） | **Y3×X3 = L3★**：敢说"别买大平层"（X3立场）+ 三步路径拉满（Y3行动） |
| **L3** | 8项根能力（为什么好） | 8项全到位，尤其"承担判断的勇气"和"诚实"是分水岭 |
| **L4** | 3D时间幅度（能不能持续） | 客户说"收楼后带好几个人来找你"——Z3多年陪伴的伏笔已埋下 |

### 1.3 三层理解递进（方便你跟人讲）

**给金燕讲的版本**（1分钟）：
> 付振博是L3★——7个阶段全覆盖、每个阶段都有X3立场的反向判断、8项根能力全部到位。578个案例里只有4个L3，这是其中一个。

**给重庆城市团队讲的版本**（3分钟）：
> 这个经纪人收到一条香港客户短信"想在大理买别墅，预算1000万"，他没有直接推房源，而是先打了个语音电话判断客户真伪——这是"视野"。他发现客户说要复式，其实需要的是带院子的别墅——这是"判断"。他带客户看了4套房，前两套他知道客户不会喜欢但还是带了——这是"行动策略"。他拦住客户不让买大平层，说"我不等着开单吃饭"——这是"立场"。从接触到成交到售后，7个阶段没有掉链子。

**给自己用的版本**（拆解维度）：
7个阶段各有至少一个"X3立场时刻"——付振博不是偶尔敢说不，是**习惯性地站在客户长期利益那边**。这才是L3和L2的真正分界线，不是技巧差异，是价值观差异。

## 二、4×7城市共创路径：从重庆到深圳到全国

### 2.1 你的定位再确认

你在项目中的角色不是"执行者"，是**共创流程的设计者和推动者**。这意味着：

| 不是 | 而是 |
|------|------|
| 自己填28个格子 | 设计让城市团队能填格子的流程 |
| 总部产出一个完美的能力图谱 | 产出一个"城市团队愿意用、能迭代"的共识版 |
| 单城一次性活动 | 验证可复制模式的首城试点 |

### 2.2 三阶段路径（调整版）

基于金燕"先跑一个格子"的方法论，调整之前的三阶段：

| 阶段 | 时间 | 目标 | 关键动作 | 交付物 |
|------|------|------|----------|--------|
| **Phase 1a：First Sample** | 6月6日-12日 | 跑通1个格子的完整拆解 | 付振博案例×C2需求排序×判断已完成；下周四人各出一个案例的1格拆解 | 1个完整格子（能力解读+动作+标准+案例片段） |
| **Phase 1b：重庆验证** | 6月18日 | 在重庆验证共创流程 | 4小时工作坊执行 → 观察什么环节卡、什么环节顺 | 重庆共识版+共创流程反馈 |
| **Phase 2：深圳迭代** | 7月-8月 | 验证可复制性 | 用重庆经验优化SOP，深圳跑第二遍 | 共创SOP v1.0 + 能力图谱v2 |
| **Phase 3：全国推广** | Q4起 | 形成标准化工具包 | 城市复制手册 + 训练产品原型 | 可交付的城市落地工具包 |

### 2.3 关键判断：重庆共创的验证要点

重庆不是"产出完美能力图谱"的场合，是**验证三件事**：

1. **框架能不能被听懂？** —— 参与者能否在4小时内理解4×7的基本逻辑
2. **共创能不能产出有价值的讨论？** —— 小组拆解产出的差异度和深度
3. **产出有没有落地价值？** —— 城市团队会不会真的用这份能力图谱

**如果三件全过 → 深圳直接复制流程。如果卡在哪一件 → 深圳前先迭代。**

## 三、重庆工作坊v0.2优化方案

### 3.1 核心问题诊断

v0.1的三个问题：

| 问题 | 表现 | 根因 |
|------|------|------|
| 第一部分太长 | 60分钟"以消费者为中心"的解读 → 对一线团队来说偏学术 | 宏大的"时代背景"和"消费者变了"对共创的实际支撑不够直接 |
| 第二部分太散 | C1-C7 + S1-S7 + 四类能力承接 → 60分钟内信息密度过高 | 试图在讲"流程"的同时讲"能力"，但两者没有在同一个载体上整合 |
| 第三部分共创模糊 | "案例呈现→小组拆解→版本呈现→对比讨论→共识" | 步骤是对的，但没有给参与者一个"锚点"——从零拆解门槛太高 |

### 3.2 v0.2时间重组

| 模块 | 内容 | 时长 | 形式 | 变化 |
|------|------|------|------|------|
| 开场 | 破冰+为什么今天坐在这里 | 10分钟 | 讲授 | 压缩5分钟 |
| **第一部分** | **一个案例看懂"什么叫行"** | 40分钟 | 案例讲述+互动 | **重构** |
| 茶歇 | | 10分钟 | | 不变 |
| **第二部分** | **7阶段流程 + 4类能力：用案例承载** | 50分钟 | 引导式讲解+练习 | **重构** |
| **第三部分** | **标杆案例共创（五步法）** | 100分钟 | 小组共创 | **深化** |
| 收束 | 对比+共识+下一步 | 30分钟 | 全员讨论 | 增加5分钟 |

### 3.3 第一部分重构：一个案例看懂"什么叫行"

**设计思路**：不要从"时代背景""消费者变了"讲起——直接用一个案例，让参与者自己感受到差距。

**内容结构**：

```
Step 1：案例呈现（付振博×香港客户）（15分钟）
  - 用3分钟的叙事节奏讲完整个案例
  - 关键片段标注：①第一通语音 ②"你要的不是复式是别墅" ③"我不等着开单吃饭" ④签约时坐着陪客户 ⑤收楼仪式
  - 不讲框架，不讲理论，只讲故事

Step 2：参与者第一反应（10分钟）
  - 引导问题："你听完这个案例，觉得这个经纪人最厉害的点是什么？"
  - 记录关键词（贴在白板上）

Step 3：引导对照（15分钟）
  - 提问："如果是你，在香港客户的短信阶段，你会怎么做？"
  - 提问："你敢跟客户说'这套别买'吗？为什么敢/不敢？"
  - 自然引出：**这就是差距——不是信息差，是判断和立场的差距**

Step 4：收束 → 引出框架（5分钟）
  - "这个经纪人做了7个阶段的事，每个阶段都有一系列判断和选择。我们接下来把这个拆开看。"
```

**为什么这样改？**
- 金燕说"先给案例，再给框架"——直接验证
- 邓鹏说"经纪人听不懂术语"——先用故事建立感受，再用术语标注
- 付振博案例已经在手上——不需要额外准备

### 3.4 第二部分重构：用案例承载流程+能力

**设计思路**：不要分开讲"7个阶段"和"4类能力"，而是用付振博案例作为载体，**在同一个故事里同时展开流程和能力**。

**核心工具：一张"流程×能力"对照表**（用于全程引导）

| 阶段 | 消费者在想什么 | 经纪人做了什么 | 体现了什么能力 |
|------|---------------|---------------|---------------|
| C1 需求摸底 | "这个经纪人靠谱吗？" | 打语音电话判断真伪 | 理解：识别客户动机；判断：是真客户 |
| C2 需求排序 | "我到底要什么？" | "你要的不是复式是别墅" | 理解+判断+立场（三类同时发生） |
| C3 带看匹配 | "这几套哪个好？" | AABC四盘策略 | 视野+判断+路径（动线设计） |
| C4 信任建立 | "他是不是只想赚我钱？" | "我不等着开单吃饭" | 立场（X3：反向判断） |
| C5 签约障碍 | "钱过不来怎么办？" | 不催、陪客户去银行 | 情绪共感+路径设计 |
| C6 签约完成 | "我决定了吗？" | 安抚客户"别有压力" | 情绪共感+中正 |
| C7 签后服务 | "买对了没有？" | 礼物+收楼仪式+反馈 | 立场+时间结构+诚实 |

**引导节奏**（50分钟）：

| 环节 | 内容 | 时间 |
|------|------|------|
| 整体概览 | 展示7个阶段的全貌，点出"每个阶段经纪人都在做什么判断" | 10分钟 |
| 重点拆解 | 选C1、C2、C4三个节点深讲——这三个节点最能展示"视野→判断→行动"的因果链 | 15分钟 |
| 引入四类能力 | 用案例中的动作，反推到"理解/判断/路径/立场"四个维度——**不是先定义再举例，是先看动作再归类** | 10分钟 |
| 互动练习 | 每人选一个节点，写出"如果是你在这个节点，你会做什么跟付振博一样的事？做什么不一样的事？" | 15分钟 |

**关键调整**：
- 把v0.1中"先讲四类能力定义，再让大家拆解"的顺序**反过来**：先用案例中的动作建立直觉，再用能力标签归纳
- 删掉业主赛道S1-S7的详细展开（客户赛道足够4小时内消化）
- 压缩"与业务流程的关系"那张图——讲1分钟即可，不用展开讨论

### 3.5 第三部分重构：标杆案例共创五步法

**设计思路**：v0.1的问题在于"案例呈现→小组拆解"之间缺少一个**锚点**——参与者从零拆解门槛太高。五步法的核心改进是：**先给一个"样本版本"，让大家基于样本做"挑刺、补充、修改"**。

#### 五步流程总览（100分钟）

| 步骤 | 核心动作 | 时间 | 产出 |
|------|----------|------|------|
| **Step 1：样本展示** | 展示付振博案例的拆解版本（精简后） | 10分钟 | 参与者见到"一个格子长什么样" |
| **Step 2：个人拆解** | 每人用本地案例独立填写工作表 | 20分钟 | 个人版本的能力拆解 |
| **Step 3：小组讨论** | 4-6人组内对比差异、找争议点 | 25分钟 | 小组共识版+争议清单 |
| **Step 4：版本路演** | 每组5分钟汇报，其他组"挑刺" | 25分钟 | 跨组差异可视化 |
| **Step 5：共识收敛** | 引导全场讨论争议点，形成初步共识 | 20分钟 | 重庆第一版能力图谱雏形 |

#### 各步详细设计

**Step 1：样本展示（10分钟）**

展示内容：付振博案例C2阶段×4能力的拆解示例，**精简到一页纸**——

```
┌─────────────────────────────────────────────┐
│  样本：付振博 × C2需求排序 × 判断能力         │
│                                              │
│  场景问题：客户说"要别墅或复式"，经纪人怎么   │
│  判断他真正需要什么？                         │
│                                              │
│  能力解读：能从客户表达的模糊需求中，识别出    │
│  未被说出口的真实需求，并给出明确的判断结论    │
│                                              │
│  经纪人动作：                                  │
│  ① 先让客户列出所有需求，然后做减法——         │
│    "如果只能保留三项核心需求，你选什么？"      │
│  ② 听到"5月买"后追问"为什么是5月"——发现       │
│    真实约束是"7月公公婆婆从美国回来必须入住"   │
│  ③ 锁定"带院子的别墅"而非"复式"——             │
│    因为有孩子需要撒欢的空间                    │
│                                              │
│  评价标准：                                    │
│  - 能说出客户至少1个"没说出口的真实约束"       │
│  - 能给客户一个明确的"你应该选X而不是Y"的判断  │
│  - 判断能给出至少2个具体依据                   │
└─────────────────────────────────────────────┘
```

**引导话术**：
> "这是我们提前拆好的一个样本。核心说三件事：在这个场景下，'判断'到底指什么、经纪人做了什么动作证明他有判断力、怎么判断他做到了还是没做到。
> 
> 接下来你们要做的事不是照抄——是用你们自己的案例，填同样的结构。**你们觉得样本哪里拆得不好，直接改。样本只是个起跳板。**"

**Step 2：个人拆解（20分钟）**

注意：需要提前准备**重庆本地的一个真实案例**（建议选重庆本地一位优秀经纪人的完整成交案例），作为共创的共同素材。如果同时用付振博案例，参与者容易混淆。

**工作表简化版**（一人一张A4）：

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
你的名字：_____________
你选择的节点（C1-C7中的一个）：_____
你选择拆解的能力（理解/判断/路径/立场中的一个）：_____

① 在这个节点，经纪人做了什么具体动作？
_______________________________________
_______________________________________

② 这个动作体现了什么能力？为什么？
_______________________________________

③ 如果这个能力"做到了"，会长什么样？（写1-2条标准）
_______________________________________

④ 你觉得最难判断的是哪个能力？为什么？
_______________________________________
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**为什么从"全28格"缩减到"1个节点×1个能力"？**
- 金燕的"先跑一个格子"——不是让你跑满28格，是所有人聚焦同一个格子
- 降低认知负荷——参与者不需要理解28格的框架，只需要理解"一个格子里应该写什么"
- 提高讨论质量——所有人的产出可以直接对比，差异一目了然

**Step 3：小组讨论（25分钟）**

讨论三件事：
1. **对比拆解版本**：你们组的4个人，对同一个节点的同一个能力，拆出来的一样吗？
2. **找共识和争议**：哪些大家理解一致？哪些分歧很大？
3. **选出"最清晰的一份"**：你们组觉得谁拆得最好？好在哪？

**引导话术**：
> "现在把你们的纸摊开，互相看一下。你会发现——同一个案例、同一个节点，大家拆出来的东西可能完全不一样。这不是谁对谁错的问题，是'能力'这个东西本来就藏在细节里。你们现在的任务就是：找出差异、讨论差异、选一个你们组觉得最清晰的说法。"

**Step 4：版本路演（25分钟）**

每组5分钟：展示"我们组选出来的最清晰的一份" + "我们组争议最大的一个问题"

**Step 5：共识收敛（20分钟）**

引导全场讨论两个问题：
1. **不同组的"最清晰版本"有什么共性？** → 提炼"这个格子的核心要素"
2. **争议点有什么规律？** → 是能力定义的问题，还是案例本身的问题？

**预估产出**：
- 1个格子的重庆共识版（如"C2×判断"的共识解读+动作+标准）
- 关于"拆解能力为什么难"的讨论记录（后续迭代输入）
- 参与者对框架的直观感受（下次沟通的锚点）

### 3.6 关键设计原则（必须记住的）

| 原则 | 说明 | 反例 |
|------|------|------|
| **先给样本，再让拆解** | 降低入门门槛，提高讨论起点 | 让大家从零拆解 → 产出参差、讨论发散 |
| **聚焦1个格子，不展开28格** | 4小时内能建立"一个格子的体感"就是成功 | 试图覆盖全28格 → 蜻蜓点水、无一深入 |
| **用案例讲框架，不用框架套案例** | 先有动作再有标签，不是先有标签再找动作 | "这个属于判断" → "他做了什么，所以这叫判断" |
| **对比是核心驱动力** | 同一案例不同人拆解出的差异，是最好的学习素材 | 选不同案例 → 差异无法直接对比 |
| **共识不是"统一答案"** | 共识是对框架的理解一致 + 对争议的讨论充分 | 强行统一所有拆解 → 抹杀有价值的差异 |

## 四、下周四人沟通：支撑资料与准备建议

### 4.1 两个任务的关系

金燕布置的两个任务不是并列的，是**因果链**：

```
任务b（重庆研讨框架：学-练-评）
    ↑ 输入
任务a（四人案例交付整合与共识）
```

**任务a是"我们自己对框架有体感"，任务b是"把这个体感设计成别人也能参与的活动"。**

### 4.2 任务a：四人案例交付整合与共识

#### 建议流程（60-90分钟线上碰头）

| 环节 | 内容 | 时间 | 目的 |
|------|------|------|------|
| **展示** | 每人5分钟：展示自己的案例+拆解的1个格子 | 20分钟 | 看到彼此的理解差异 |

### 4.3 任务b：重庆研讨框架（学-练-评）

#### 学-练-评的结构映射到v0.2

| v0.2模块 | 对应环节 | 时间 | 核心动作 |
|----------|----------|------|----------|
| 第一部分：一个案例看懂"什么叫行" | **学** | 40分钟 | 听故事→建立感受→引出框架意识 |
| 第二部分：7阶段+4能力（案例承载） | **学+练** | 50分钟 | 看拆解样本→理解流程和能力→自己试拆一个节点 |
| 第三部分：五步共创 | **练+评** | 100分钟 | 小组拆解→对比差异→相互"挑刺"→共识收敛 |
| 收束 | **评** | 30分钟 | 回顾产出→明确下一步→"这不是终点是起点" |

#### 你需要向四人展示的关键设计逻辑

1. **为什么第一部分只讲案例不讲框架？** 
   → 金燕说"先给案例再给框架"。参与者先建立"什么叫行"的感受，再用框架标注。

2. **为什么第三部分聚焦1个格子而不是28格？**
   → 金燕说"先跑一个格子找体感"。4小时内跑通1个格子比蜻蜓点水28格更有价值。

3. **为什么给样本版本而不是让大家从零拆？**
   → 从零拆解门槛太高，给样本让大家"挑刺、补充、修改"是更低的起跳点。

4. **为什么用同一个案例而不是各选各的？**
   → 同一个案例才能直接对比差异。不同案例的差异混杂了案例本身差异，无法判断是能力理解差异还是素材差异。

### 4.4 四人沟通的"避坑"提醒

| 陷阱 | 表现 | 怎么避 |
|------|------|--------|
| **争论能力定义** | "到底'判断'应该怎么定义？" → 陷入无限讨论 | 对齐金燕："不走证明对错的路，走跑通大多数人认可的路" |
| **追求完美填满** | "C6正签×立场这个格子拆不出来怎么办？" → 焦虑 | 如实记录哪些格子是空的——空本身是有价值的信息（邓鹏说"不一定每个格子都有内容"） |
| **只讨论不产出** | 聊了2小时但没有落到一张纸上 | 提前准备对比表格模板，讨论过程中实时填空 |
| **被付振博案例压住** | 觉得自己的案例"不够好"、"没有L3" | 强调：四人整合不是选L3案例，是建立"拆解能力的方法" |
