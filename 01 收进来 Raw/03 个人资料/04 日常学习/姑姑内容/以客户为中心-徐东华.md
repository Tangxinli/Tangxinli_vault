# 以客户为中心

**副标题**：围绕客户决策流程，重塑房产经纪人服务流程

**讲师**：徐东华（徐姑姑）

**关键词**：#专业主义 #新学习曲线 #供需错配 #决策支持 #顾问式经纪人 #六步服务流程 #技能提效

---

## 一、核心命题

> **旧的训练方法，在今天越来越失灵；新的专业主义，要围绕客户的决策流程来设计。**

---

## 二、旧学习曲线 vs 新学习曲线

| 维度 | Before 旧学习曲线 | After 新学习曲线 |
|------|-------------------|-------------------|
| **核心方向** | SE 销售有效性（获客、转化、议价、成交） | DE 决策有效性（Decision Effectiveness） |
| **学习内容** | 促成、逼定、异议处理等销售话术 | 需求挖掘、咨询诊断、项目管理、营销能力、AI 应用 |
| **作业逻辑** | 围绕销售漏斗展开 | 围绕决策支持与交付展开 |

> **旧时代研究的是"怎么把房卖出去"，新时代还要着重研究的是"怎么帮客户把决策做对"。**
>
> 这是一条**全新的学习曲线**。

---

## 三、供需错配：行业主要矛盾

### 现状诊断

- **宏大叙事**飘在天上 → **数据指标**悬在头上 → **三方场景**碎在地上
- 如果无法满足客户需求，也就无法帮助经纪人技能提效

### 七个典型错位：透过现象看本质

经纪人看到的是"客户不配合"，消费者感受到的是"没有足够依据完成决策"。

| 经纪人视角 | 消费者视角 | 背后本质 |
|-----------|-----------|----------|
| IM 已读不回 | 增量信息太少，像推销 | 客户在筛选"谁值得继续沟通"，并可进入"面试"环节 |
| 总在观望价格 | 怕买错房、买错时机 | 重大决策靠"长出来"的，不要观点话术，而是"观点是如何形成"的 |
| 带看邀约越来越难约 | 抗拒盲目看房 | 任何投入时间的动作都要证明"为什么值得" |
| 看了很多房不定 | 越看越乱 | 先有标准，后有匹配 |
| 客户突然断联 | 太复杂、太累 | 决策负荷过载导致暂停 |
| 业主不降价 | 你什么都没做就让我降 | 让客户承担损失前，必须先完成价值交付 |

> **经纪人遇到的不是更多话术的问题，而是如何提供更好的决策支持。**

### 供需矛盾

| 需求侧已经变化 | 供给侧升级迟缓 |
|--------------|--------------|
| 消费者线上获取信息能力更强 | 价值停留在成交而非帮客户做对决策 |
| 靠"推房、带路、开门"无法满足 | 技能停留在销售而非决策服务 |
| 新的需求是：陪我做选择与决策 | 服务产品尚未成型、行业心智还停留在渠道推销 |

> **结论**：今天经纪人面对的不是销售技巧不够，而是**决策服务不够**。
>
> 问题不在需求侧，而在供给侧——消费者对专业"决策支持"的需求，与经纪人以"撮合成交"为主的浅层推销服务之间的供需矛盾。

## 四、几个值得深思的"反共识"

不是为了显得新，而是为了跳出旧路径依赖，用新的提问方式理解今天的客户。

| 问题              | 答案                                                   |
| --------------- | ---------------------------------------------------- |
| **客户怎么分类？**     | 不是以"刚需/改善"划分的产品分类，是围绕家庭生命周期与购房任务来分类                  |
| **客户流程是什么？**    | 不是经纪人的销售流程，而是客户从动机形成到完成交付的决策流程                       |
| **服务是成本还是投资？**  | 普通中介费是期间费用；优质顾问服务更像投资                                |
| **买方可以不要经纪人吗？** | 带路谁都可以，但需要 Coach（教练）、Buyer（买手）、Consultant（顾问）        |
| **不推房、不带看行不行？** | 先排除、再验证；先降低决策负荷，再进入实地确认                              |
| **需求和匹配到底是什么？** | 需求不是找房诉求，是可被满足的需要（Needs）和期待（Wants）；匹配是围绕"人、房、钱"三者的匹配 |

> **今天最大的危险，不是不知道答案，而是继续用过去的方式思考今天的问题。**

## 五、客户六步决策流程

> **以客户为中心，不是态度更好一点，而是用客户的决策流程来重构服务流程。**

客户不是在"购买一套房子"，而是在完成一个**高总价、低频次、多人参与、长周期的人生决策**。

经纪人的销售流程 **≠** 客户的决策流程。

```
① 动机形成 → ② 需求发育 → ③ 聚焦收敛 → ④ 精准匹配 → ⑤ 签约成交 → ⑥ 交付流程
```

---

### 阶段一：动机形成

> **真动机决定后续一切是否成立；动机不清，需求必乱。**

房源不重要，重要的是"为什么要行动、为什么是现在、这件事值不值得优先"。

| 技能 | 说明 |
|------|------|
| **动机唤醒技能** | 帮助客户看见现状中的不满意、不满足与变化；从"没有明确行动意愿"进入"认真思考要不要动" |
| **动机辨别技能** | 区分表层动机、深层动机、伪动机；确认这件事是否真的需要通过交易来解决 |
| **动机强化技能** | 把"感觉上需要"变成"决策上优先"；方法：问题具体化、后果具体化、目标显性化 |

---

### 阶段二：需求发育

> **需求不是简单问出来的，而是在讨论、比较与现实校准中长出来的。**

客户不是要一个现成答案，而是要可比较、可排序、可共创的分析过程。

| 技能 | 说明 |
|------|------|
| **需求解码技能（5W2H）** | Why/Who：动机是什么；When/How/How-much：约束条件是什么；Where/What：房源特征与偏好；区分 Needs（必须有/必须无）与 Wants（期望有/期望无） |
| **共识构建技能** | 路径：发现问题→定义问题→分析问题→讨论→验证；从"消除异议"升级为"消除分歧、增进共识"；不是说服客户，而是帮客户自己说服自己 |
| **目标建模技能** | 建立客户找房 OKR（目标和攻略）；基于客户 OKR 建立顾问的 KPI；形成双方 To Do List 与行动路线图 |

---

### 阶段三：聚焦收敛

> **没有收敛就没有决策，没有取舍就没有匹配。**

当信息过载发生时，工作的中心是"降负荷"，而不是"给更多"。

| 技能 | 说明 |
|------|------|
| **排除收敛·分层带看技能** | 二维（表格/屏幕初筛，先排除不值得看的）→ 2.5维（VR 复核，初步验证）→ 三维（实地看，找体感、做确认）→ 四维（看未来十年，是否仍然适配） |
| **比较建模技能** | 建立统一对比框架：板块、通勤、学区、户型、总价、税费、流动性等；让客户用同一把尺子做比较，而不是凭感觉反复摇摆 |

---

### 阶段四：精准匹配

> **顾问不是房源搬运工，而是帮客户从海量房源中策展答案的人。**

不是无限找下去，而是帮助客户找到"足够好且值得停下来"的答案。

| 技能 | 说明 |
|------|------|
| **找到最佳停止点** | 帮助客户找到最佳停止点，而非执着理论最优解；越往后看，边际收益递减，焦虑却可能上升；欧拉 37 法则启发：先建立基准，再识别"明显更优" |
| **房源策展技能** | 像策展人一样完成：选品、组织、排序、呈现；把少数真正值得看的房源以"答案集"方式展示；说清楚：为什么是这些、为什么 A 比 B 更适合、各自取舍 |

---

### 阶段五：签约成交

> **成交不是把客户推过去，而是把风险挡在前面，把条件设计清楚。**

成交不是流程的唯一目标，而是客户在交易层面对决策的确认。

| 技能 | 说明 |
|------|------|
| **交易尽调技能** | 识别、核查并预防产权、税费、户口、租约、贷款、腾房等关键风险；专业不是只会成交，而是先把坑找出来 |
| **Offer 设计技能** | 围绕客户目标、市场环境、房源竞争态势与业主心理设计报价节奏；价格、付款方式、税费、腾房时间等都可成为条件组合 |
| **利益协商技能** | 谈判不是谁压过谁，而是把双方最在意的东西摆对位置；必要时要推动达成，也要敢于在不合适时 STOP |

---

### 阶段六：交付流程

> **流程结束不等于服务结束，客户安顿下来才是真正的完成。**

交付不是尾声，而是价值兑现与长期关系开始的地方。

| 技能 | 说明 |
|------|------|
| **项目交付管理技能** | 两张表：时间表、项目清单；签约解决的是交易成立；交付解决的是交易兑现；最后一公里，决定客户看到的是单次交易，还是长期价值 |
| **客户复利力（LTV）** | 从用户思维与全生命周期价值出发经营客户关系；完成入住只是阶段终点；再次升级/焕新/换新，是下一轮服务起点；**一次成交赚佣金，长期经营赚信任复利** |

## 六、思维升级：从流量思维到用户思维

```
流量思维 → 客户思维 → 用户思维
追求曝光与转化 → 专注单次服务价值 → 经营全生命周期
```

## 七、一张表：顾问式经纪人的技能地图

六个阶段、十五个关键技能点，对应同一条主线：**帮助客户把复杂决策做对**。

| 阶段 | 目标 | 关键技能点 |
|------|------|-----------|
| 动机形成 | 启动 | 动机唤醒力 / 动机辨真力 / 动机定锚力 |
| 需求发育 | 定义问题 | 需求解码力 / 共识构建力 / 目标建模力 |
| 聚焦收敛 | 做减法 | 排除收敛力 / 比较建模力 |
| 精准匹配 | 形成答案 | 满意解判断力 / 房源策展力 |
| 签约成交 | 控制风险 | 交易尽调力 / Offer 设计力 / 利益协商力 |
| 交付流程 | 兑现与复利 | 交付项目力 / 客户复利力 |

> **顾问式经纪人的专业，不是更会推房，而是更懂得在每一步提供恰当、清晰、可交付的支持。**

## 八、从"推房带看"到"决策服务"

| 维度 | 旧逻辑：围绕房源与成交 | 新逻辑：围绕客户决策流程 |
|------|----------------------|------------------------|
| **擅长** | 推房、带看、议价、促成 | 唤醒、解码、共识、排除、策展、尽调、交付 |
| **评价标准** | 是否更快成交 | 是否帮助客户把决策做对 |
| **结果** | 客户觉得被推进 | 客户感到被理解、被辅助、被承接 |

> **真正的服务创新，是对客户价值的极致尊重。**

## 九、业主服务"四定"

业主服务是一个典型的**营销服务**。有三件事需要和业主共识：

1. 成交价格和成交周期哪个更重要
2. 二手房是一套一套卖掉的
3. 房源成交效率 = 更多曝光 × 更多经纪人参与销售

| 环节 | 核心 |
|------|------|
| **定位** | 营销始于"定位"：市场定位 / 客群定位 / 竞品定位 |
| **定策** | 协助业主制定有效的竞争策略 |
| **定价** | 确定价格竞争力：试价 / 市价 / 市值 |
| **定责** | 业主就是 CEO / 销售管理者是 CMO / 经纪人是 Sales |

---

## 十、结语：三句带走

> 以客户为中心不是一句口号，也不仅仅是我们的职业操守，而是——**生存策略**！

1. **客户不是来配合我们成交的，而是来完成自己的复杂决策。**
2. **专业主义，不是更会卖房，而是更会帮助客户把决策做对。**
3. **真正的服务创新是顺着客户决策流程，把专业能力重新长出来。**
