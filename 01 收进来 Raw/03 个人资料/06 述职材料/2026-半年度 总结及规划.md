## 一、上半年工作复盘与核心反思

### 1.1 年初定位与实际走向

年初我的OKR定位是：跑通TGC讲师内容价值飞轮。实际走到6月底，工作内容远超OKR规划——组织变革加速、4×7项目从0到1、角色从课研转向讲师运营——上半年不是一个"按计划执行"的半年，而是一个"边转型边建设"的半年。

### 1.2 三条线的事实回顾

**线一：TGC运营——从0到1的冷启动**

| 阶段   | 关键动作               | 产出                          |
| ---- | ------------------ | --------------------------- |
| 5-6月 | 老左奖学金糖果厂投稿活动       | 收稿38篇，完成首批内容闭环              |
| 5月   | 先行者访谈录（陈荣+邓鹏）      | 首批视频号内容，1+4矩阵浏览量达首期4.5倍     |
| 6月   | TGC×BL1新媒体合作（三次沟通） | 确定产品三阶段框架+Skill模式+30人讲师推荐清单 |
| 6月   | TGC收尾与讲师1v1沟通      | 完成投稿讲师收尾沟通+奖品发放+持续投稿邀约      |

**核心挑战**：TGC最大的困难不是"没人投"，而是"怎么让内容产生真实价值"。糖果厂收了38篇稿，但内容出花桥后的落地效果还没验证；贝壳币激励弱，讲师参与动力不足。这让我意识到：TGC不能只做"投稿平台"，必须嵌入具体产品/应用场景才有生命力——**案例ai短视频（视频号）or BL1(案例展示)的合作就是破局点。

**线二：4×7项目——在验证框架与被框架束缚之间**

| 阶段      | 关键动作              | 产出                           |
| ------- | ----------------- | ---------------------------- |
| 6月初     | 项目组成立+付振博案例萃取     | 萃取SKILL v0.3，标杆样本            |
| 6月5-18日 | 重庆共创方案+共创执行       | 首城共创4组案例拆解+3位标杆访谈            |
| 6月下旬    | 案例梳理：案例结构化梳理+横比分析 | 17条框架外发现+9条框架优化建议初稿+项目路径V1.0 |

**核心挑战**：4×7最大的困惑是"被大S的框架牵着鼻子走"。我在验证大S提出的4×7，当一线体感与框架不一致时，不知道是框架的问题还是自己的理解问题。做横比分析时发现：C6交付阶段四个案例全部降级——这不是四人共同的能力短板，更可能是框架对C6的定义与一线实际脱节。这个发现让我从"用框架判断案例"转向"用案例校验框架"——后者才是4×7项目的真正价值。

**线三：角色转型——从课研到讲师运营**

2026年4月，从课程研发部门转到讲师发展部门。这是上半年最重要的身份变化。

- **课研时期**的核心能力：解决内容问题、打磨课程逻辑、辅导讲师授课
- **讲师运营时期**需要的新能力：设计赋能机制、跨部门协同、系统性运营、用AI提效

这两个角色需要的底层能力不同。课研是"自己做出来"，讲师运营是"让别人能做出来"。上半年我最大的转型挑战就在这里——从"内容生产者"到"能力基础设施的建设者"。

### 1.3 变革期的核心反思

**反思一：从"填满框架"到"让框架服务一线"**

我的惯性是先搭完整框架再逐步填充——这是课研的肌肉记忆。但4×7项目让我发现，这个惯性在变革期是有问题的：框架越完整，越容易让人"被框架牵着走"，<font color="#c00000">而不是从一线体感出发</font>。金燕的方式是"先深挖1个格子找体感再展开"——这比我的方式更贴合"体验先行、标准后置"的变革逻辑。我学到的：先收起"填满28格"的冲动，用1个真实案例找到第一个格子的体感，框架自然会长出来。

**反思二：从"自己做到"到"让别人能做到"**

课研时期我习惯自己做出高质量产出。但讲师运营的命题不是"我做得好不好"，而是"我能不能让更多讲师做出来"。TGC糖果厂收了38篇稿，但如果讲师离了我就投不出来，那就不是机制，是我的个人输出。Skill模式的提出就是为了解决这个问题——把课研能力封装成可复用的Skill工具，讲师用Skill自产课件，不依赖课研全程跟进。这是从"个人能力"到"组织能力"的转变——推进中。

**反思三：5·26研讨会逼出的根本追问**

S在5·26研讨会上逼出了一个问题：**如果知识可以被AI生成，练习可以被AI陪跑，反馈可以被AI即时完成，那培训人还创造什么价值？**

这个问题刺到了我。上半年我做的每一件事——TGC内容运营、4×7案例萃取、Skill体系设计——本质上都在回答这个问题。我的答案逐渐清晰：<font color="#c00000">培训人的新价值不是讲得更好、课件更完整，而是**让人变强**——让服务者理解消费者、做出判断、设计路径、承担立场；让讲师能用AI解题、能产出内容、能赋能一线</font>。

## 四、收获与认知升级

### 顿悟一：培训人的价值不是"做得更好"，而是"让人变强"

5·26研讨会之前，我的潜意识是"我要做出更好的内容、更好的课程、更好的框架"。研讨会上S逼问"培训人还创造什么价值"，让我意识到：如果培训人只是在"做得更好"这个维度上精进，AI迟早会追上来。真正的价值不在"我做得好"，而在"我让服务者变强了"。4×7不是一门课，是让服务者能力差距可见、可训练、可评价的系统；Skill不是工具，是把课研能力赋能给讲师、让讲师自己能产出内容的机制。

### 顿悟二：框架是工具不是答案，一线体感才是校准器

我过去的能力优势是"系统化思考"——能快速搭建框架、梳理逻辑。但4×7项目让我发现：框架先行的风险是"被框架束缚"——当你拿着28格去套案例，会不自觉地忽略框架解释不了的东西。横比分析中17条"框架外发现"才是最有价值的产出——它们不是"填不进去的异常"，而是"框架需要进化的信号"。从此我多了一个判断标准：**一个框架好不好，不在于它能不能解释所有案例，而在于它能不能暴露自己解释不了什么。**

### 顿悟三：从"个人产出"到"组织能力"——我的角色本质变了

课研时期，我的价值 = 我做出的内容质量。讲师运营时期，我的价值 = 我设计的机制能让多少人产出内容。这个转变的深层含义是：我不再是"内容生产者"，而是"能力基础设施的建设者"。Skill体系、TGC运营闭环、4×7萃取方法论——这些不是我的个人作品，而是组织的赋能工具。衡量它们好不好，不是看我做得精不精致，而是看没有我的时候，它们能不能自己运转。

### 顿悟四：变革期最稀缺的不是能力，是"先做起来"的勇气

上半年很多工作没有先例可循——4×7怎么做、TGC怎么运营、Skill怎么设计、与BL1怎么合作。想多了会不敢动。金燕说"你太完善了，完善和完美的东西让人没有体感"——这句话点醒了我。不需要先想清楚4×7的终极形态再动手，整理案例的过程就是理解4×7的过程；不需要先想清楚TGC的完整运营手册再启动，跑一次投稿活动就会暴露真实问题。**先做起来，在做的过程中理解，在理解中校准方向。**
