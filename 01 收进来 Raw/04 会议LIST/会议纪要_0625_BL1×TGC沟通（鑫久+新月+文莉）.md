## 五、内容产出模式：「流程 + Skill」

### 5.1 核心思路

```
传统模式：课研萃取老师 → 老师输出 → 课研做课件
新模式：  课研产出工作坊课件含（流程 + Skill体系） → 评价讲师OK → 讲师用工作坊课件自产课件
```

工作坊课件 = **流程框架**（课研做）+ **Skill体系**（每页配一个Skill，讲师输入素材→生成内容）

### 5.2 课件拆解示例

| 页面      | 内容          | Skill     | 讲师输入      |
| ------- | ----------- | --------- | --------- |
| 课程名称    | —           | 无         | —         |
| 讲师介绍    | 生成讲师介绍页     | 讲师介绍Skill | 老师自我描述    |
| 人设/IP定位 | 生成人设定位页     | 人设定位Skill | 老师定位思考    |
| 如何选题    | 分析选题方向与内容构成 | 选题Skill   | 爆款视频、选题素材 |
| 如何表达    | …           | 表达Skill   | …         |
| 如何制作    | …           | 制作Skill   | …         |

### 5.3 Skill体系的价值

- **标准化产出**：不同讲师按同一流程产出，保证质量底线
- **降低课研依赖**：讲师可自行迭代，与Skill对话即可产课件
- **可复用扩展**：内容实践Skill做好后，增长/经营实践可沿用框架调整
- **长期是TGC方向**：评价老师OK → 给Skill → 自产课件，做课效率持续提升

## 六、讲师配合原则

| 原则 | 说明 |
|------|------|
| **方向明确后再沟通** | 不急于让老师出内容；方向和命题未定就让老师产出是双向消耗 |

| **可同步推进** | 客研细化框架的同时，老师可沿大方向先准备素材，两条线并行 |
