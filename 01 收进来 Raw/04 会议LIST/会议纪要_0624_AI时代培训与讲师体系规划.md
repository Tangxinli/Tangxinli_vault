## 二、专题分享一：AI时代，培训人的价值重构
**主讲人：** 花桥基地负责人 宗飞飞（菲姐）

### 核心主题
> 从「知识传递」到「推动改变」——AI时代培训人的价值再定义

### 1. AI带来的「三次解放」

| 解放维度 | 内容 | 对培训的影响 |
|------|------|------|
| **知识解放** | AI可快速调取、生成适配学习者的知识体系 | 知识传递不再是培训人的核心价值 |
| **个体解放** | AI可针对每个人个性化定制学习路径和反馈 | 班级化培训的"兼容性难题"被解决 |
| **场景解放** | AI可在岗位上完成学、练、应用、反馈的闭环 | 传统课堂"拉人培训"的局限被突破 |

**个人实践案例：** 菲姐将每场会议录音喂给GPT，从"上级视角+管理教练+商业顾问"三个角度获得复盘洞察，形成行动方案并持续追踪——AI成为个性化"高价值带教顾问"。

### 2. AI解放后，培训人的新价值

| 价值方向 | 说明 |
|------|------|
| **隐性知识萃取** | Top Sales自己都说不清的成功逻辑，需要深度观察、分析、提炼的人 |
| **人与人的连接** | AI可自学，但场域中的气场、情绪触动、同侪激发无法替代 |
| **创造价值** | 知识被大量应用后，培训人被"逼"到价值创造的核心位 |
| **动机唤醒与行为锚定** | 对认知受限、驱动力弱的学员，意愿撬动和行为锚定是"人的战场" |
| **必要的摩擦设计** | 在AI流畅学习中保留认知冲突、同侪压力、紧迫感——体验设计能力 |

### 3. 花桥产品演进路径

### 4. 时代背景与经营挑战

- 信息优势→**信任优势**：重新构建服务流程与商业模型
- 高提佣挖人→**从组织内部长人**：系统性经营能力建设
- 规模型经营→**精准效率型经营**：找到真正产生价值的路径
- 合规风险倒逼利润压缩，门店经营需重构盈利模式

### 5. 改变如何发生？（核心模型）

```

    ↓

    ↓
初步正反馈
    ↓
行为强化 → 习惯形成 → 身份重塑
```

### 6. 培训人的终极定位

> **AI时代最稀缺的不是知识，而是改变。**  
> 培训人的价值 = **发现改变 + 理解改变 + 推动改变 + 放大改变 + 运营改变**

**新的内容飞轮：**

## 三、专题分享二：讲师体系2.0——从星级讲师到能力讲师
**主讲人：** 讲师发展负责人 金燕燕（燕姐）

### 1. 讲师体系1.0现状（星级体系）

| 数据项 | 数值 |
|------|------|
| 讲师序列总人数 | 11,863人 |
| 覆盖城市 | 92个核心城市 |
| 覆盖组织 | 10个专业组织 |
| 一星占比 | 45%（5,377人）|
| 四星+五星占比 | 约10%（约1,000人）|
| 有标签但从未上课 | 32.4% |
| 人均授课（中位值） | 约1次 |

**1.0体系三大痛点：**
1. **活跃度不足**——1/3讲师从未上课，贡献高度集中
2. **成长梯队断层**——70%在一二星，四五星仅10%，晋升路径不清
3. **贡献评估单一**——只考量授课量/次数，忽略内容质量和隐性贡献

### 2. 时代背景下的能力转型

| 维度 | 1.0时代 | 2.0时代 |
|------|------|------|
| 知识来源 | 经验萃取→标准化传播 | 实践突破→个体创新 |
| 讲师角色 | 课程使用者/传播者（工具） | 业务实践者/内容生产者（创新者）|
| 组织需求 | 规模化经验复制 | 个体崛起+创新能力 |
| 解决问题 | 有讲师 | 有**创造内容**的讲师 |
| 培训逻辑 | 讲授分享（传知识） | 实践赋能（带改变）|

### 3. 讲师体系2.0：能力序列设计

**T序列（Trainer）**——传播贡献型
- 核心要求：**讲对 + 讲好**
- 进阶能力：引导能力 + 实操能力（带学员练、评）
- 星级（T0-T5）体现**贡献量**（授课次数/时长）

**M序列（Master）**——内容创造型
- 核心要求：**懂业务 + 懂消费者 + 有MVP成功案例 + 用AI解题**
- 有自己的内容产出，能被复制、被提炼
- 参照标杆：姑姑（TEMFD路径：讲课→输出内容→自媒体→知识库→课程研发）

> 序列 = 定义你是谁（能力方向）  
> 星级 = 定义你贡献了多少（执行量）

### 4. 2026年重点工作

| 工作项 | 说明 |
|------|------|
| **挖掘第一批M讲师** | 寻找懂消费者+懂业务+有实践+有内容输出的潜力讲师，进行陪跑 |
| **9月讲师节** | 推出第一批M序列讲师，向组织发出信号 |
| **能力模型共创** | 不先做制度，先找标杆，由标杆反推制度基础 |
| **TTD赋能走出去** | 花桥不开营时，支持到区域/城市做讲师赋能（重点支持花桥粘性高的城市）|
| **以课代培养** | 四步法：观摩课程→带练→自练→上台讲成 |

**M讲师筛选三方认可机制：**
1. 组织认可度
2. 学员认可度  
3. 培训伙伴认可度

## 四、关键结论与行动方向

1. **培训人不是被AI替代，而是被逼到更高价值位**——从"搭台子"到"运营改变"
2. **讲师体系从"规模化复制"转向"内容生产力建设"**，目标是3年内建成有内容生产力的讲师团队
3. **2026年核心动作**：先找第一批M讲师标杆，用标杆反推制度，不强制转型，"佛渡有缘人"
4. **城市培训伙伴**：关注本城市有实践、有内容、有意愿的潜力M讲师，推荐给燕姐陪跑
