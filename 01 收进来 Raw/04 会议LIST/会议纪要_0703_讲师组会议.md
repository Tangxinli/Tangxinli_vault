## 二、花桥基地挑战问题共创

### 2.1 产品端带来的挑战

- **产品一直在变**，不确定性导致讲师画像不稳定，无法及时匹配适合的老师
- 只能不断复用同一波"默认好老师"，不敢启用新老师
- BL2讲师画像相对清晰（大品牌主/多店店东/运营总），但ML和BL1画像不稳定
- **基地已明确立场：只筛选不培养**，培养是讲师组的事情

### 2.2 科研辅导弱

- 科研辅导不能给老师有效输入，老师对课产生抗拒
- 辅导缺乏验收机制（老师满意度打满分，但私下反馈不好）
- 科研伙伴缺少讲授经验沉淀和业务体感，跟老师聊不到一起
- 关校建议用 **AI辅助科研辅导**：AI做教练，讲师对着AI练习、获取反馈

### 2.3 讲师体验落差

- 花桥讲师体验与城市相比有落差（城市会送鲜花，花桥什么都没有）
- 连贺卡都没有了（过往每营都有定制卡片），**主要是没钱**
- 讲师上级对花桥认知不足，上级不支持讲师出来（业务指标压力大）

### 2.4 讲师本身挑战

- **AI对讲师冲击大**：很多老师跟不上AI，工作场景中AI机会并不多
- 学AI可能只是为了来花桥讲课，日常应用场景少
- 我们推AI赋能但没想清楚最终效果

### 2.5 讲师来源路径模糊

- 找老师都是定向邀约，没有常态化筛选机制
- 今年只有2月份一场认证，讲师零零散散进来
- 多个产品复用同一波老师，不合理

### 2.6 讲师品牌与激励

- 讲师荣誉感和激励感下降（贝壳币、文化T恤等过往激励力度强）
- 老师的上级没有被"看见"，讲师出不来

## 三、M序列讲师管理框架

### 3.1 M序列画像（初步共识）

| 能力维度 | 说明 |
|----------|------|
| 懂业务 | 找业务型讲师，城市推荐评选 |
| 懂消费者 | 走进城市，现场评估 |
| 懂AI | 通过AI赋能培训 |
| 有实践 | 绑定TGC、4×7 |
| 能生产 | 绑定TGC、4×7内容生产 |

### 3.2 运营机制

- **TGC**：生产内容
- **4×7**：运营机制，发现优秀→拆解优秀→让优秀可复制
- **AI赋能**：帮助讲师跟上趋势
- **基地认证**：筛选不培养

### 3.3 和城市联动培养（四层选择逻辑）

1. **选城市总**：看其是否重视赋能、业务、消费者、AI（重庆赵总、天津、杭州肖总）
2. **选客服负责人**：良好抓手和推动力
3. **选讲师底子**：城市有没有好讲师、是否重视讲师赋能
4. **选意愿度**：城市对这件事的拥抱程度

### 3.4 城市推进情况

| 城市 | 状态 | 备注 |
|------|------|------|
| 重庆 | ✅ 已跑通 | 赵总重视赋能，去年已做业主客户分离 |
| 深圳 | ❌ 失败 | 城市总和客服层面弱，只有讲师个体有意愿 |
| 天津 | 🔄 推进中 | AI和消费者贴得紧 |
| 成都 | 预排 | — |
| 杭州 | 预排 | 肖总在区域做业务培训标杆 |
| 南京 | 预排 | — |

### 3.5 供给路径

培养前置化 → 城市联动筛选 → 认证 → 引荐 → 分发到基地/北练/4×7/TDC → 产出内容补给M序列
