# 服务案例萃取

从服务案例录音及补充材料中，萃取双轨内容：服务故事 + 4×7框架拆解。

## 核心理念

萃取不是记录，是转化——把"只存在于录音里"的经验，变成可入库、可索引、可学习的内容。

两条轨道各有侧重：
- **服务故事**：让读者"感受到"——消费者叙事，重情感和转变
- **4×7框架**：让读者"学得会"——结构化拆解，重思维和行动

两条轨道共享同一份素材，但提炼角度不同。故事讲"发生了什么"，框架讲"为什么这样做"。

标签体系是索引入口：服务者可以通过消费者标签找到"遇到这类人怎么服务"，通过经纪人标签找到"想学这个能力找谁学"。经纪人核心能力标签对齐大S的8项底层能力模型（L3根因层）。

## 输入格式

接受以下任意组合：

- **录音文字稿**（必需）：服务案例的完整或部分录音转写
- **服务者复盘笔记**：经纪人对案例的回顾和思考
- **消费者反馈**：消费者的评价、感谢信、投诉记录
- **培训方向文档**：大S的培训期待、服务理念、变革方向（用于校准叙事角度和收获对齐）
- **案例集卷首语/方向文档**：已有案例集的理念定位（用于对齐内容方向）

### 文件处理

录音文字稿支持 .txt, .md, .docx, .pdf 格式。

```python
# PDF
import pdfplumber
with pdfplumber.open("path") as pdf:
    text = "\n".join(page.extract_text() or "" for page in pdf.pages)
```

```python
# Word
from docx import Document
doc = Document("path")
text = "\n".join(p.text for p in doc.paragraphs if p.text.strip())
```

## 第一遍：案例基本信息 + 标签体系

从输入中识别案例基本信息，并贴上标签。标签的目的是让服务者能快速索引：
- 按消费者标签找 → "遇到这类消费者怎么服务"
- 按经纪人标签找 → "想学这个能力找谁学"

### 基本信息

| 字段 | 说明 | 识别来源 |
|------|------|---------|
| 服务者姓名 | 姓名 | 录音/补充材料 |
| 服务者从业年限 | 年数 | 录音/补充材料 |
| 服务者团队/门店 | 所属组织 | 录音/补充材料 |
| 消费者类型标签 | 见下方消费者标签体系 | 录音判断 |
| 案例类型 | 买方 / 卖方 / 买卖双线 | 判断得出 |
| 决策阶段覆盖 | 哪些阶段有实质内容 | 录音判断 |
| 核心张力 | 这个案例最有价值的点 | AI判断 |
| 补充材料清单 | 附带了哪些额外材料 | 用户提供 |

### 消费者标签体系

四个维度，每个维度可多选：

| 维度 | 标签 | 说明 |
|------|------|------|
| 购房动机 | `首购` `改善` `学区` `养老` `投资` `离婚分割` `继承处置` | 消费者为什么要买房/卖房 |
| 决策风格 | `需求模糊` `反复犹豫` `强势主导` `依赖推荐` `信息过载` | 消费者做决定的方式 |
| 关系复杂度 | `独自决策` `夫妻共识` `代际参与` `多方博弈` | 谁参与了这个决定 |
| 情绪状态 | `焦虑紧迫` `信任困难` `期望过高` `情感依恋` | 消费者当时的情绪底色 |

### 经纪人标签体系

三个维度，每个维度可多选。核心能力标签对齐大S的8项底层能力模型（L3根因层），有深度梯度：

| 维度 | 标签 | 说明 |
|------|------|------|
| 核心能力（表层·可短期训练） | `信息提取力` `数据敏感度` `时间结构能力` | 知识与方法层——缺位最常见 |
| 核心能力（中层·需刻意练习） | `结构化思考` `承担判断的勇气` `情绪共感` | 思维与气量层——需反馈才能长 |
| 核心能力（深层·接近性格价值观） | `冲突中的中正` `诚实` | 人品与底色层——缺位最致命，不是培训问题 |
| 服务风格 | `陪伴型` `推动型` `专业权威型` `情感共鸣型` | 经纪人介入的方式 |
| 从业阶段 | `新锐(1-3年)` `成长期(3-5年)` `资深(5-10年)` `专家(10年+)` | 经验深度 |

**8项底层能力定义**（对齐大S模型）：
- **信息提取力**：从对话里听出三个未说出口的需求
- **结构化思考**：把杂乱信息组织成可推导的判断链
- **数据敏感度**：对价格、面积、单价、成交节奏有量级直觉
- **承担判断的勇气**：敢说"建议"和"不建议"，并接住反问
- **情绪共感**：读出客户犹豫背后的真实焦虑
- **时间结构能力**：把模糊的"再聊"变成有节点的路径
- **冲突中的中正**：业主买方利益冲突时不站偏
- **诚实**：敢说违背自身短期利益的话

### 标签识别原则

1. 标签从录音内容中识别，不硬贴——录音中看不出"情感依恋"就不贴
2. 每个维度最多选2个，宁缺毋滥
3. 核心能力标签必须对应4×7框架中有实质内容的格子——标签是框架的入口
4. 识别完成后先输出基本信息+标签概览，确认后再进入双轨萃取

## 第二遍轨道A：服务故事

### 1. 消费者叙事

从消费者的视角写故事，不是从经纪人的视角写服务过程。

**消费者叙事的定义**：写消费者的处境和转变。如果附带了培训方向文档，叙事角度应向其对齐——比如方向是"看见消费者"，叙事就侧重消费者被"看见"的转折；如果没有方向文档，默认视角是：写处境和转变，不写需求和工作流。

**三幕结构**：

**前幕 — 消费者的处境**
- 他遇到了什么？不是"需求"，是他的处境和感受
- 他的焦虑、困惑、犹豫、两难
- 他之前尝试了什么，为什么没解决
- 写处境，不写需求；写困境，不写痛点

**中幕 — 转变发生了**
- 服务者介入的关键时刻
- 从消费者眼中看到的变化：什么时候开始放心了、什么时候做了决定
- 写转变，不写动作；写"他感受到了什么"，不写"经纪人做了什么"
- 保留1-2个服务者的关键行为，但必须通过消费者的感受来呈现

**后幕 — 什么不同了**
- 消费者的状态变化：感受、决定、关系
- 用具体细节呈现变化，不用"非常满意"等空话
- 如果有消费者的原话，直接引用

**叙事原则**：
- 用消费者的语言，不用行业的术语
- 写"他在那一刻的感受"，不写"经纪人的服务策略"
- 允许留白——不是所有细节都要写完，关键是转折点
- 故事长度800-1200字，一个案例一个故事

### 2. 三层收获

每个故事提炼三层递进收获——从感受到行动，每层比上一层深一步，不能割裂。

**感受层 — 一句话**
- 这个故事让人感受到了什么
- 格式：一句金句，可独立传播，像绘本的道理
- 示例：*"真正让人安心的不是选项多，而是有人帮你看清"*

**认知层 — 一段话**
- 这个故事让人理解了什么以前没理解的东西
- 格式：2-4句话，说清"为什么"
- 示例：*"消费者说'我想再看看'的时候，不是在拖延，是在等一个让他放心的人替他做判断。蒋小娟没有急着推房源，而是先帮客户理清了'最不能接受什么'——这才是真正的需求发育。"*

**行动层 — 双视角行为指引**

行动层拆成两个视角，分别写给不同的读者：

#### 经纪人视角：服务消费者的行为指引

写给一线经纪人——"遇到类似情境，你可以这样做"。

- 格式：2-3条具体行为，编号列表
- 每条来自故事中的真实行为，不是通用建议
- 示例：
  1. 先重复消费者的原话，让他知道你听见了
  2. 把你的判断用"如果是我，我会…"的方式说出来
  3. 把选择权还给他，但缩到2个以内

#### 管理者视角：门店运营带教的行为指引

写给店东/商圈经理——"遇到这类案例、这类经纪人，你可以这样带/这样管"。

- 格式：2-3条具体行为，编号列表
- 侧重三个方向：识别消费者、配置资源、复盘带教
- 示例：
  1. 门店早会用5分钟讲这个案例的"需求翻译"动作，让大家演练怎么听出消费者没说出口的话
  2. 遇到"信息过载型"客户，优先匹配有"选项收敛"标签的经纪人
  3. 复盘时重点问：你在这个阶段看到了什么客户没看到的东西？

**收获原则**：
- 三层之间必须递进，不能感受说"温暖"认知说"要专业"行动说"多沟通"
- 行动层双视角的内容来自同一个案例，但站位不同——经纪人视角问"我该做什么"，管理者视角问"我怎么让团队会做"
- 如果有培训方向文档，三层收获应对齐方向理念
- 如果案例内容不足以支撑管理者视角行动指引，标注"本案管理者视角行动指引待补充"

### 3. 消费者原话

单独提取消费者在录音中的原话，为案例集"消费者声音"部分备料。

格式：

| 原话 | 语境 | 可用于 |
|------|------|--------|
| "我之前看了十几套房，越看越不知道该选哪个" | 描述自己之前的困惑 | 消费者声音·决策困境 |
| "她说'你其实不是要大房子，你是要让孩子上学方便'，我一下子就安心了" | 描述被理解的那一刻 | 消费者声音·被看见的转折 |

原则：
- 只提取消费者的原话，不提取经纪人的话
- 标注每句话的语境（他当时在说什么、对谁说）
- 标注"可用于"案例集的哪个位置
- 如果消费者原话很少，标注"本案消费者原话较少"
- 原话保持原样，不润色不修改

## 第二遍轨道B：4×7框架拆解

### 框架说明

4种思维维度（行）× 7个决策阶段（列）= 28格矩阵。

根据案例类型选择对应的7阶段：
- **买方案例**：动机形成 → 需求发育 → 聚焦收敛 → 精准匹配 → 签约成交 → 交付流程 → 持续服务
- **卖方案例**：动机形成 → 理解市场 → 确认方案 → 定价 → 售房追踪 → 市价成交 → 持续服务

### 四种思维维度

| 维度 | 核心定义 | 格子核心问题 |
|------|---------|------------|
| 理解 | 看到客户没有看到的，挖掘显性需求+隐性需求 | 在"XX阶段"，经纪人看到了客户的哪些显性需求和隐性需求？ |
| 判断 | 从专业出发，给出有立场、有依据的明确结论 | 基于理解，经纪人做出了什么专业判断？ |
| 路径 | 把判断变成有时间、有责任方、有反馈的具体行动 | 判断之后，采取了哪些有时间线、有责任人的具体行动？ |
| 立场 | 愿意牺牲个人短期利益，维护客户长期利益 | 经纪人内心秉持怎样的态度？真实目的是什么？ |

四个维度递进：理解（看到）→ 判断（想清）→ 路径（做到）→ 立场（站对）

### 填充原则

**核心原则：有内容就填，没内容就空。**

- 录音中有明确对应行为和思考的格子，填写内容
- 录音中没有覆盖的阶段或维度，用"——"表示，不硬凑
- 每格直接写案例实录——经纪人真实的想法、话语和行动
- 不写空泛总结，不写"经纪人积极沟通"这种泛泛描述

### 输出格式：一览大表

采用一张大表呈现，7个阶段为列，4个维度为行，案例内容一览无余。格式参照共创产出表格：

```
## 4×7 案例拆解一览

案例类型：[买方/卖方]
覆盖阶段：[列出有内容的阶段]

| | 1-动机形成 | 2-需求发育 | 3-聚焦收敛 | 4-精准匹配 | 5-签约成交 | 6-交付流程 | 7-持续服务 |
|---|---|---|---|---|---|---|---|
| **1-理解** | [内容] | [内容] | —— | [内容] | —— | —— | [内容] |
| **2-判断** | [内容] | [内容] | —— | [内容] | [内容] | —— | —— |
| **3-路径** | [内容] | —— | —— | [内容] | [内容] | —— | [内容] |
| **4-立场** | [内容] | —— | —— | —— | [内容] | —— | [内容] |
```

**阶段列头含定义描述**（第一行备注）：

```
| | 1-动机形成<br>我想买房子，买房的原因 | 2-需求发育<br>我想要买什么样的房子 | 3-聚焦收敛<br>需求排序，锁定方向 | 4-精准匹配<br>匹配房源、接受现实 | 5-签约成交<br>斡旋、决策、安全、解决问题 | 6-交付流程<br>物业交割、按揭贷款、过户 | 7-持续服务<br>客情维护 |
```

**维度行头含定义描述**：
- **1-理解**：看到显性需求，挖掘隐性需求
- **2-判断**：专业审视、感觉、经验
- **3-路径**：具体维护动作
- **4-立场**：经纪人态度、目的、内心真实想法

## 收尾：案例集编排提示

每个案例萃取完成后，输出编排建议，为下游案例集整合减轻压力。

### 编排建议包含：

1. **独特贡献**：这个案例在28格中哪几个格子有高质量内容，这是它不可替代的地方
2. **推荐位置**：适合放在案例集的哪个位置（卷首理念呼应 / 服务者案例主篇 / 消费者声音佐证 / 多案例交叉引用）
3. **消费者标签匹配**：按消费者标签，这个案例能回答"遇到XX型消费者怎么服务"的哪些问题
4. **经纪人标签匹配**：按经纪人标签，这个案例能回答"想学XX能力找谁"的哪些问题
5. **与已有案例的关联**：如果之前已萃取过其他案例，标注标签重叠或互补关系（如"与蒋小娟案例互补——蒋擅长信息提取力，本案侧重承担判断的勇气"）

### 跨案例标签索引（累积）

索引放在每个萃取文件里，每次萃取后更新。记录已萃取案例在每个标签上的分布：

```
## 消费者标签索引

| 标签 | 案例 | 数量 |
|------|------|------|
| 学区 | 蒋小娟、XXX | 2 |
| 反复犹豫 | 蒋小娟 | 1 |

## 经纪人标签索引

| 标签 | 案例 | 数量 |
|------|------|------|
| 信息提取力 | 蒋小娟 | 1 |
| 承担判断的勇气 | XXX | 1 |
```

这个索引随案例增加而增长，帮助识别：哪些标签已有足够案例支撑、哪些标签还缺案例、哪些标签过度集中。

## 生成规则

1. **基于录音内容萃取，不编造**。录音中没有的不写，不确定的标注"待确认"
2. **消费者叙事写处境，不写需求；写转变，不写动作**——从消费者的眼睛看，不是从经纪人的工作流看
3. **三层收获必须递进**：感受→认知→行动，每层比上一层深一步，不能割裂
4. **行动层双视角必须区分**：经纪人视角写给一线，管理者视角写给店东/商圈经理，站位不同，行为指引不同
5. **管理者视角行动指引聚焦三个方向**：识别消费者、配置资源、复盘带教
6. **4×7框架有内容就填，没内容就用"——"**——一览大表格式，7阶段为列4维度为行
7. **案例实录用原话和具体行为**，不写"经纪人积极沟通"这种泛泛描述
8. **如果有培训方向文档，三层收获应对齐方向理念**——收获不是通用的，是针对这个组织这个阶段需要的
9. **消费者原话只提取消费者的**，标注语境，不修改
10. **标签从录音内容中识别，不硬贴**——看不出"情绪共感"就不贴
11. **经纪人核心能力标签对齐大S 8项底层能力**——不是自己造标签，是用已有的根能力模型
12. **每个案例萃取完成后，输出编排提示**：独特贡献、推荐位置、标签匹配、与已有案例的关联
13. **跨案例标签索引放在每个萃取文件里**，累积更新
14. **中文撰写**，故事800-1200字，框架按实际内容填充
15. **案例基本信息中的标签写入frontmatter的consumer_tags和agent_tags字段**，方便后续Dataview查询和索引
